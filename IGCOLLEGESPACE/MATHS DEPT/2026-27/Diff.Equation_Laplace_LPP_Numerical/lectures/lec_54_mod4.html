📜 2. A Brief History
📌 From Archimedes to Modern Computers

The idea of approximating the area under a curve goes back to Archimedes (c. 287–212 BCE), who used the method of exhaustion to compute the area of a circle by inscribing and circumscribing polygons.

In the 17th century, Newton and Leibniz developed calculus, giving exact integration formulas for many functions. However, for functions that cannot be integrated analytically, and for data obtained from experiments, numerical approximations became necessary.

In the 18th century, mathematicians such as Thomas Simpson and Roger Cotes developed systematic quadrature rules based on interpolating polynomials. The trapezoidal rule and Simpson's rule are the most well-known of these classical methods.

With the advent of electronic computers in the 20th century, numerical integration became a standard computational tool in science and engineering.

📐 3. What is Numerical Integration?
📌 Definition and Need

Numerical integration (also called quadrature) is the process of computing the approximate value of a definite integral

\[ I = \int_a^b f(x)\,dx \]

using a finite set of numerical values of the integrand.

We need numerical integration in the following situations:

  • The antiderivative of \(f(x)\) cannot be expressed in closed form (e.g., \(e^{-x^2}\), \(\sin(x^2)\)).
  • The function is known only through a table of experimental data points.
  • The function is given by a complex algorithm or a computer simulation.
  • An exact analytic integration would be too cumbersome or impossible.
📊 4. The Idea of Tabular Data and Splitting into Intervals
📌 Tabulating the Function

In many practical problems, the function \(f(x)\) is given as a set of values at certain points, not as an explicit formula. For example:

\(x\)\(x_0\)\(x_1\)\(x_2\)\(\dots\)\(x_n\)
\(y = f(x)\)\(y_0\)\(y_1\)\(y_2\)\(\dots\)\(y_n\)

To apply numerical integration, we usually need the \(x\)-values to be equally spaced. We therefore split the interval \([a, b]\) into \(n\) equal subintervals of width

\[ h = \frac{b - a}{n} \]

The points of division are \(x_0 = a, x_1 = a + h, \dots, x_n = b\).

If the given data is not equally spaced, interpolation is first used to obtain values at equal intervals.

📋 5. Common Numerical Integration Methods

The most frequently used methods for numerical integration are:

  • Trapezoidal Rule — approximates the area by a series of trapezoids.
  • Simpson's 1/3 Rule — approximates the integrand by parabolic arcs.
  • Simpson's 3/8 Rule — uses cubic arcs.
  • Boole's Rule — uses quartic arcs.
  • Weddle's Rule — a composite rule based on six subintervals.
  • Gaussian Quadrature — chooses optimal points and weights (not equally spaced).
  • Romberg Integration — uses Richardson extrapolation on the trapezoidal rule.

In this course, we will focus on the Trapezoidal Rule and Simpson's 1/3 Rule, which are the two prescribed in the syllabus.

⚠️ 6. Points to Remember
🚨 Important Notes
  • The \(x\)-values must be equally spaced for the standard rules (Trapezoidal, Simpson's).
  • The step size \(h\) must be constant.
  • Simpson's 1/3 rule requires an even number of subintervals.
  • Increasing \(n\) (decreasing \(h\)) generally improves the accuracy.
