📐 2. Convergence of the Newton-Raphson Method
📌 Condition for Convergence

Write the iteration in the form \(x_{n+1} = \phi(x_n)\), where

\[ \phi(x) = x - \frac{f(x)}{f'(x)} \]

From the fixed-point theory, the iteration converges if in a neighbourhood of the root \(\xi\):

\[ |\phi'(x)| < 1 \]

Differentiating \(\phi(x)\):

\[ \phi'(x) = \frac{f(x)f''(x)}{[f'(x)]^2} \]

At the root \(\xi\), we have \(f(\xi) = 0\), so \(\phi'(\xi) = 0\). Since \(\phi'\) is continuous and vanishes at the root, we can always find a neighbourhood of \(\xi\) where \(|\phi'(x)| < 1\).

Hence the method converges provided the initial approximation \(x_0\) is chosen sufficiently close to the root \(\xi\), and \(f'(x) \neq 0\) in that neighbourhood.

⚡ 3. Rate (Order) of Convergence
📌 Quadratic Convergence

Let \(\xi\) be the exact root and \(x_n\) the \(n\)-th approximation. Define the error \(e_n = x_n - \xi\).

Expand \(f(x_n)\) by Taylor's series about \(\xi\), using \(f(\xi) = 0\):

\[ f(x_n) = f'(\xi)e_n + \tfrac{1}{2}f''(\xi)e_n^2 + \dots \]

Also expand \(f'(x_n)\):

\[ f'(x_n) = f'(\xi) + f''(\xi)e_n + \dots \]

The correction term is

\[ \frac{f(x_n)}{f'(x_n)} = e_n + \frac{f''(\xi)}{2f'(\xi)}e_n^2 + \dots \]

Substituting into the iteration \(x_{n+1} = x_n - f(x_n)/f'(x_n)\) and using \(x_{n+1} - \xi = e_{n+1}\):

\[ e_{n+1} = \frac{f''(\xi)}{2f'(\xi)} e_n^2 + \dots \]

Hence, for sufficiently small \(e_n\),

\[ e_{n+1} \approx K e_n^2, \qquad K = \frac{f''(\xi)}{2f'(\xi)} \]

This shows the Newton-Raphson method has second-order (quadratic) convergence — the number of correct decimal places roughly doubles each iteration.

Definition (Order of Convergence). A sequence \(\{x_n\}\) converges to \(\xi\) with order \(p\) if there exists a constant \(C \neq 0\) such that

\[ \lim_{n\to\infty} \frac{|x_{n+1}-\xi|}{|x_n-\xi|^p} = C \]

Here \(p = 2\) and \(C = |f''(\xi)/2f'(\xi)|\), so Newton-Raphson is of second order.

🚨 IMPORTANT REMARKS
  • If \(f'(x_n)\) becomes zero or very small, the method breaks down or diverges.
  • A poor initial guess may cause divergence even though the method is quadratically convergent locally.
  • For a repeated root, the convergence slows to linear unless a modified formula is used.
  • For trigonometric functions, keep the calculator in RADIAN mode.

Problem 1 (B5). Use the Newton-Raphson method to find a root of \(x^3 - 2x - 5 = 0\). CO4
✅ Solution:
Let \(f(x) = x^3 - 2x - 5\), so \(f'(x) = 3x^2 - 2\).
Since \(f(2) = -1\) and \(f(3) = 16\), choose \(x_0 = 2\).
Iteration 1: \(f(2) = -1\), \(f'(2) = 10\).
\[ x_1 = 2 - \frac{-1}{10} = 2.1 \]
Iteration 2: \(f(2.1) = 0.061\), \(f'(2.1) = 11.23\).
\[ x_2 = 2.1 - \frac{0.061}{11.23} = 2.094568 \]
Iteration 3: \(f(2.094568) \approx 0\), so the root is \(x \approx 2.0945\).

✅ Root ≈ \(2.0945\).

Problem 2 (B6). Find a root of \(x\sin x + \cos x = 0\). CO4
🚨 Use RADIAN mode for all trigonometric evaluations.
✅ Solution:
Let \(f(x) = x\sin x + \cos x\); then \(f'(x) = x\cos x\).
Choose \(x_0 = \pi \approx 3.1416\).
Iteration 1: \(f(\pi) = -1\), \(f'(\pi) = -\pi\).
\[ x_1 = \pi - \frac{-1}{-\pi} = \pi - \frac{1}{\pi} \approx 2.8233 \]
Iteration 2: \(f(2.8233) \approx -0.0662\), \(f'(2.8233) \approx -2.8233\).
\[ x_2 \approx 2.7986 \]
Iteration 3: \(f(2.7986) \approx -0.0006\), giving \(x_3 \approx 2.7984\).

✅ Root ≈ \(2.7984\).

Problem 3 (C4). Find a non-zero root of \(x^2 + 4\sin x = 0\). CO4
🚨 Use RADIAN mode for trigonometric evaluations.
✅ Solution:
Let \(f(x) = x^2 + 4\sin x\); then \(f'(x) = 2x + 4\cos x\).
Choose \(x_0 = -2\).
Iteration 1: \(f(-2) \approx 0.3628\), \(f'(-2) \approx -5.664\).
\[ x_1 = -2 - \frac{0.3628}{-5.664} \approx -1.9359 \]
Iteration 2: \(f(-1.9359) \approx 0.0291\), \(f'(-1.9359) \approx -5.488\).
\[ x_2 \approx -1.9306 \]
Iteration 3: \(f(-1.9306) \approx -0.0002\), so the root is \(x \approx -1.9338\).

✅ Non-zero root ≈ \(-1.9338\).

Problem 4 (C5). Find a non-zero root of \(\sin x = \frac{x}{2}\) between \(\frac{\pi}{2}\) and \(\pi\), correct to 3 decimal places. CO4
🚨 Use RADIAN mode for all trigonometric evaluations.
✅ Solution:
Let \(f(x) = \sin x - \frac{x}{2}\); then \(f'(x) = \cos x - \frac{1}{2}\).
Choose \(x_0 = \frac{\pi}{2} \approx 1.5708\).
Iteration 1: \(f(\pi/2) = 0.2146\), \(f'(\pi/2) = -0.5\).
\[ x_1 = 1.5708 + 0.4292 = 2.0000 \]
Iteration 2: \(f(2.0) \approx -0.0907\), \(f'(2.0) \approx -0.9161\).
\[ x_2 \approx 1.9010 \]
Iteration 3: \(f(1.9010) \approx -0.0042\), giving \(x_3 \approx 1.8959\).
Iteration 4: \(x_4 \approx 1.8955\).

✅ Root ≈ \(1.896\) (correct to 3 decimal places).

Problem 5 (C6). Find the root of \(4e^{-x}\sin x - 1 = 0\) between 0 and 0.5, correct to 3 decimal places. CO4
🚨 Use RADIAN mode for trigonometric evaluations.
✅ Solution:
Let \(f(x) = 4e^{-x}\sin x - 1\); then \(f'(x) = 4e^{-x}(\cos x - \sin x)\).
Choose \(x_0 = 0.2\).
Iteration 1: \(f(0.2) \approx -0.3494\), \(f'(0.2) \approx 2.5590\).
\[ x_1 \approx 0.3365 \]
Iteration 2: \(f(0.3365) \approx -0.0566\), \(f'(0.3365) \approx 1.7533\).
\[ x_2 \approx 0.3688 \]
Iteration 3: \(f(0.3688) \approx -0.0028\), giving \(x_3 \approx 0.3706\).
Iteration 4: \(f(0.3706) \approx -0.00001\).

✅ Root ≈ \(0.370\) (correct to 3 decimal places).

Problem 6 (C7). Find a double root of \(x^3 - x^2 - x + 1 = 0\). CO4
✅ Solution:
Let \(f(x) = x^3 - x^2 - x + 1\); then \(f'(x) = 3x^2 - 2x - 1\).
For a double root, use the generalized Newton formula \(x_{n+1} = x_n - 2f(x_n)/f'(x_n)\).
Choose \(x_0 = 0.8\).
Iteration 1: \(f(0.8) = 0.072\), \(f'(0.8) = -0.68\).
\[ x_1 = 0.8 - 2\frac{0.072}{-0.68} \approx 1.0118 \]
Iteration 2: \(f(1.0118) \approx 0.0002\), \(f'(1.0118) \approx 1.0235\).
\[ x_2 \approx 1.0000 \]

✅ Double root \(x = 1\).

Problem 7 (C8). Find a root of \(x^3 - 2x^2 + 3x - 5 = 0\) between 1 and 2, correct to 3 decimal places. CO4
✅ Solution:
Let \(f(x) = x^3 - 2x^2 + 3x - 5\); then \(f'(x) = 3x^2 - 4x + 3\).
Choose \(x_0 = 1.5\).
Iteration 1: \(f(1.5) = -1.625\), \(f'(1.5) = 3.75\).
\[ x_1 \approx 1.9333 \]
Iteration 2: \(f(1.9333) \approx 0.5127\), \(f'(1.9333) \approx 6.4904\).
\[ x_2 \approx 1.8543 \]
Iteration 3: \(f(1.8543) \approx 0.0470\), giving \(x_3 \approx 1.8463\).
Iteration 4: \(x_4 \approx 1.8438\).

✅ Root ≈ \(1.844\) (correct to 3 decimal places).
