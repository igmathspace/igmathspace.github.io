📐 2. Derivation from Quadratic Interpolation
📌 Fitting a Parabola Through Three Points

Consider three equally spaced points \(x_0, x_1 = x_0 + h, x_2 = x_0 + 2h\) with ordinates \(y_0, y_1, y_2\).

Instead of a straight line (as in the trapezoidal rule), we fit a quadratic polynomial through these three points:

\[ f(x) \approx a_0 + a_1(x - x_1) + a_2(x - x_1)(x - x_0) \]

Using the Lagrange form or the Newton forward-difference form, the interpolating quadratic is

\[ P_2(x) = y_0 + \frac{x - x_0}{h}\Delta y_0 + \frac{(x - x_0)(x - x_1)}{2h^2}\Delta^2 y_0 \]

where \(\Delta y_0 = y_1 - y_0\) and \(\Delta^2 y_0 = y_2 - 2y_1 + y_0\).

Integrating \(P_2(x)\) from \(x_0\) to \(x_2\) (with the substitution \(x = x_0 + ph\), \(dx = h\,dp\)):

\[ \int_{x_0}^{x_2} f(x)\,dx \approx h\int_0^2 \left[ y_0 + p\,\Delta y_0 + \frac{p(p-1)}{2}\Delta^2 y_0 \right] dp \]
\[ = h\left[ 2y_0 + 2\Delta y_0 + \frac{1}{3}\Delta^2 y_0 \right] \]

Substituting \(\Delta y_0 = y_1 - y_0\) and \(\Delta^2 y_0 = y_2 - 2y_1 + y_0\) and simplifying:

\[ = \frac{h}{3}\left( y_0 + 4y_1 + y_2 \right) \]

This is Simpson's 1/3 rule for two subintervals (three ordinates).

📌 Composite Simpson's 1/3 Rule

To integrate over \([a, b]\), divide into an even number \(n\) of equal subintervals (so there are an odd number of ordinates). Applying the two-subinterval rule repeatedly and summing:

\[ \boxed{ \int_a^b f(x)\,dx \approx \frac{h}{3}\Big[ (y_0 + y_n) + 4(y_1 + y_3 + \dots) + 2(y_2 + y_4 + \dots) \Big] } \]

More compactly:

\[ I_S = \frac{h}{3}\left[ y_0 + y_n + 4\sum_{\text{odd }i} y_i + 2\sum_{\text{even }i} y_i \right] \]

The odd-indexed ordinates are multiplied by 4, the even-indexed (interior) ordinates by 2, and the two end ordinates by 1.

📏 3. Geometric Interpretation
📌 Area Under Parabolic Arcs

The trapezoidal rule approximates the curve by straight-line segments. Simpson's 1/3 rule approximates the curve by parabolic arcs, each passing through three consecutive data points.

Since a parabola can capture curvature, Simpson's rule is generally much more accurate than the trapezoidal rule for the same step size.

📋 4. Error and Accuracy

The error in the composite Simpson's 1/3 rule is

\[ E_S = -\frac{(b-a)}{180}\,h^4\,f^{(4)}(\xi), \quad a < \xi < b \]

The rule is exact for polynomials up to degree 3 (even though it is derived from a quadratic). The error is of order \(O(h^4)\), so halving \(h\) reduces the error by a factor of 16.

⚠️ 5. Points to Remember
🚨 Important Notes
  • The number of subintervals \(n\) must be even.
  • The step size \(h\) must be constant.
  • The pattern of coefficients is \(1, 4, 2, 4, 2, \dots, 4, 1\).
  • If \(n\) is odd, apply Simpson's 1/3 to the first \(n-1\) subintervals and trapezoidal to the last subinterval.
  • Always use RADIAN mode for trigonometric functions.

Problem 1 (A2). Write Simpson's \(\frac{1}{3}\) rule to find \(\int_{x_0}^{x_n} y\,dx\). CO4
✅ Solution:
Simpson's 1/3 rule (with \(n\) even) is
\[ \int_{x_0}^{x_n} y\,dx \approx \frac{h}{3}\Big[ (y_0 + y_n) + 4(y_1 + y_3 + \dots) + 2(y_2 + y_4 + \dots) \Big] \]
where \(h = (x_n - x_0)/n\) and \(y_i = f(x_i)\).
Problem 2 (B3). Evaluate \(I = \int_0^1 \sqrt{1 - x^2}\,dx\) using Simpson's rule. CO4
✅ Solution:
Take \(h = 0.25\), so \(n = 4\) (even). The ordinates are:
\(x\)00.250.500.751.00
\(y = \sqrt{1-x^2}\)1.00000.96820.86600.66140.0000
Apply Simpson's 1/3 rule:
\[ I \approx \frac{0.25}{3}\Big[ (1.0000 + 0.0000) + 4(0.9682 + 0.6614) + 2(0.8660) \Big] \]
\[ = \frac{0.25}{3}\Big[ 1.0000 + 4(1.6296) + 1.7320 \Big] = \frac{0.25}{3}\Big[ 1.0000 + 6.5184 + 1.7320 \Big] \]
\[ = \frac{0.25}{3}(9.2504) \approx 0.7709 \]

✅ \(I \approx 0.7709\). (Exact value \(\pi/4 \approx 0.7854\); better than the trapezoidal value \(0.7489\).)

Problem 3 (B7). Evaluate \(I = \int_0^{\frac{\pi}{2}} \sqrt{\sin x}\,dx\) using Simpson's \(\frac{1}{3}\) rule with \(h = \frac{\pi}{2}\). CO4
🚨 Note: with \(h = \pi/2\), \(n = 1\) (odd), so Simpson's 1/3 rule cannot be applied directly over the whole interval. Taking a smaller \(h\) is the correct approach.
✅ Solution (with \(h = \pi/4\), \(n = 2\)):
The ordinates are (RADIAN mode):
\(x\)0\(\pi/4\)\(\pi/2\)
\(y = \sqrt{\sin x}\)0.00000.84091.0000
Apply Simpson's 1/3 rule with \(h = \pi/4\):
\[ I \approx \frac{\pi/4}{3}\Big[ 0.0000 + 4(0.8409) + 1.0000 \Big] \]
\[ = \frac{\pi}{12}\Big[ 1.0000 + 3.3636 \Big] = \frac{\pi}{12}(4.3636) \approx 1.1424 \]

✅ \(I \approx 1.1424\).

Problem 4 (C1). Use Simpson's \(\frac{1}{3}\) rule to compute \(I = \int_0^1 \frac{1}{1+x}\,dx\) correct to three decimal places with (i) \(h = 0.25\) (ii) \(h = 0.125\). CO4
✅ Solution:
Case (i), \(h = 0.25\) (\(n = 4\)):
\(x\)00.250.500.751.00
\(y = \frac{1}{1+x}\)1.00000.80000.66670.57140.5000
\[ I \approx \frac{0.25}{3}\Big[ (1.0000 + 0.5000) + 4(0.8000 + 0.5714) + 2(0.6667) \Big] \]
\[ = \frac{0.25}{3}\Big[ 1.5000 + 5.4856 + 1.3334 \Big] = \frac{0.25}{3}(8.3190) \approx 0.6933 \]
Case (ii), \(h = 0.125\) (\(n = 8\)):
\(x\)00.1250.2500.3750.5000.6250.7500.8751.000
\(y\)1.00000.88890.80000.72730.66670.61540.57140.53330.5000
\[ I \approx \frac{0.125}{3}\Big[ (1.0000 + 0.5000) + 4(0.8889 + 0.7273 + 0.6154 + 0.5333) + 2(0.8000 + 0.6667 + 0.5714) \Big] \]
\[ = \frac{0.125}{3}\Big[ 1.5000 + 4(2.7649) + 2(2.0381) \Big] = \frac{0.125}{3}\Big[ 1.5000 + 11.0596 + 4.0762 \Big] \]
\[ = \frac{0.125}{3}(16.6358) \approx 0.6931 \]

✅ (i) \(I \approx 0.6933\) (ii) \(I \approx 0.6931\). Exact: \(\ln 2 = 0.6931\).

Problem 5 (C2). Estimate the value of \(\int_1^3 \frac{1}{x}\,dx\) by Simpson's rule with 4 strips and 8 strips respectively. Determine the error in each case. CO4
✅ Solution:
The exact value is \(\int_1^3 \frac{1}{x}\,dx = \ln 3 \approx 1.0986\).
With 4 strips (\(h = 0.5\)):
\(x\)1.01.52.02.53.0
\(y = 1/x\)1.00000.66670.50000.40000.3333
\[ I \approx \frac{0.5}{3}\Big[ (1.0000 + 0.3333) + 4(0.6667 + 0.4000) + 2(0.5000) \Big] \]
\[ = \frac{0.5}{3}\Big[ 1.3333 + 4.2668 + 1.0000 \Big] = \frac{0.5}{3}(6.6001) \approx 1.1000 \]
Error \(\approx 1.1000 - 1.0986 = 0.0014\).
With 8 strips (\(h = 0.25\)):
\(x\)1.001.251.501.752.002.252.502.753.00
\(y\)1.00000.80000.66670.57140.50000.44440.40000.36360.3333
\[ I \approx \frac{0.25}{3}\Big[ (1.0000 + 0.3333) + 4(0.8000 + 0.5714 + 0.4444 + 0.3636) + 2(0.6667 + 0.5000 + 0.4000) \Big] \]
\[ = \frac{0.25}{3}\Big[ 1.3333 + 4(2.1794) + 2(1.5667) \Big] = \frac{0.25}{3}\Big[ 1.3333 + 8.7176 + 3.1334 \Big] \]
\[ = \frac{0.25}{3}(13.1843) \approx 1.0987 \]
Error \(\approx 1.0987 - 1.0986 = 0.0001\).

✅ 4 strips: \(I \approx 1.1000\), error \(\approx 0.0014\); 8 strips: \(I \approx 1.0987\), error \(\approx 0.0001\).
