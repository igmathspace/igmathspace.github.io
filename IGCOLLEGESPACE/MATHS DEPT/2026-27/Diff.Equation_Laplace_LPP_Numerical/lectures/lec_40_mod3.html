📌 2. Key Definitions (§2.14)
Solution

A set of variables \(x_1, x_2, \dots, x_{n+m}\) is called a solution to a linear programming problem if it satisfies the constraint equations (in standard form).

Feasible solution

A set of variables \(x_1, \dots, x_{n+m}\) is called a feasible solution if it satisfies the constraint equations and the non-negativity restrictions \(x_j \ge 0\).

Basic solution

A solution obtained by setting any \(n\) variables (out of \(m+n\) total variables) equal to zero and solving for the remaining \(m\) variables (provided the determinant of the coefficients of those \(m\) variables is non-zero).

The \(m\) variables are called basic variables; the \(n\) variables that are set to zero are called non-basic variables. The number of basic solutions is at most \[ \binom{m+n}{m} = \frac{(m+n)!}{m!\,n!}. \]

Basic feasible solution (BFS)

A basic solution that also satisfies the non-negativity restrictions — i.e., all variables are \(\ge 0\). Every basic feasible solution of a problem is an extreme point of the convex set of feasible solutions, and conversely every extreme point is a basic feasible solution.

Non-degenerate BFS

A BFS in which all the \(m\) basic variables are strictly positive (\(>0\)) and the \(n\) non-basic variables are zero.

Degenerate BFS

A BFS in which one or more of the \(m\) basic variables is equal to zero.

Optimal basic feasible solution

The basic feasible solution that also optimises the objective function.

📐 3. Fundamental Theorem of Linear Programming
Statement

The optimum value of the objective function of a linear programming problem, if it exists, occurs at one of the extreme points (vertices) of the convex set of feasible solutions — equivalently, at one of the basic feasible solutions of the problem.

Why this matters for the simplex method:

The feasible region is a convex set with a finite number of extreme points. Since the objective is linear, any interior feasible solution is a convex combination of extreme points, so its value lies between the values attained at those extreme points. Hence the optimum, if it exists, must be attained at an extreme point — which, by the equivalence noted above, is a BFS.

The simplex method exploits this: it starts from one BFS and moves from one BFS to a better one, never visiting interior points, until no further improvement is possible.

⚠️ CAUTION! The fundamental theorem applies to LPPs whose optimum is finite. For an unbounded LPP, the optimum does not exist; for an infeasible LPP, there is no BFS at all.

Problem 1. Define the following: (i) basic solution, (ii) basic feasible solution, (iii) degenerate solution, (iv) non-degenerate solution, (v) optimal feasible solution. CO3
✅ Answer:
(i) Basic solution: a solution obtained by setting any \(n\) variables (out of \(m+n\)) equal to zero and solving for the remaining \(m\) variables, provided the coefficient matrix of those \(m\) variables is non-singular.
(ii) Basic feasible solution: a basic solution in which all \(m+n\) variables are non-negative.
(iii) Degenerate BFS: a BFS in which one or more of the \(m\) basic variables has the value zero.
(iv) Non-degenerate BFS: a BFS in which all \(m\) basic variables are strictly positive.
(v) Optimal BFS: the basic feasible solution that also optimises the objective function.

✅ These are the key definitions underpinning the simplex method.

Problem 2. Find all the basic solutions to the system: \(x_1 + 2x_2 + 3x_3 = 4,\; 2x_1 + 3x_2 + 5x_3 = 7\). Identify which are basic feasible, which are non-degenerate basic feasible, and which is the optimal basic feasible. CO3
✅ Step-by-step:
Step 1: Here \(m + n = 3\), \(m = 2\), so \(n = 1\) non-basic variable at a time. Total basic solutions \(= \binom{3}{1} = 3\).
Step 2: Set \(x_1 = 0\) (basic variables \(x_2, x_3\)):
\(2x_2 + 3x_3 = 4\), \(3x_2 + 5x_3 = 7\).
Multiply first by 3, second by 2, then subtract: \(6x_2 + 9x_3 - 6x_2 - 10x_3 = 12 - 14 \Rightarrow -x_3 = -2 \Rightarrow x_3 = 2\).
Then \(2x_2 + 6 = 4 \Rightarrow x_2 = -1\). Basic solution: \((0, -1, 2)\). Infeasible (one negative variable).
Step 3: Set \(x_2 = 0\) (basic variables \(x_1, x_3\)):
\(x_1 + 3x_3 = 4\), \(2x_1 + 5x_3 = 7\).
Multiply first by 2: \(2x_1 + 6x_3 = 8\); subtract second: \(x_3 = 1\). Then \(x_1 = 4 - 3 = 1\). Basic solution: \((1, 0, 1)\). Basic feasible and non-degenerate.
Step 4: Set \(x_3 = 0\) (basic variables \(x_1, x_2\)):
\(x_1 + 2x_2 = 4\), \(2x_1 + 3x_2 = 7\).
Multiply first by 2 and subtract: \(x_2 = 1\); then \(x_1 = 4 - 2 = 2\). Basic solution: \((2, 1, 0)\). Basic feasible and non-degenerate.
Step 5: Objective at the two BFS:
\(Z = x_1 + 3x_2 + 3x_3\). At \((1,0,1)\): \(Z = 1 + 0 + 3 = 4\). At \((2,1,0)\): \(Z = 2 + 3 + 0 = 5\).
Step 6: Optimal BFS is \((2, 1, 0)\) with \(Z_{\max} = 5\).

✅ All basic solutions: \((0,-1,2)\) [infeasible], \((1,0,1)\) [non-degenerate BFS], \((2,1,0)\) [optimal BFS].

Problem 3. Find all the basic feasible solutions of the equations \(2x_1 + 6x_2 + 2x_3 + x_4 = 3,\; 6x_1 + 4x_2 + 4x_3 + 6x_4 = 2\). Show that all basic feasible solutions are degenerate. CO3
✅ Step-by-step:
Step 1: Here \(m = 2\), total variables \(= 4\), so \(n = 2\) non-basic at a time. Total basic solutions \(= \binom{4}{2} = 6\).
Step 2: Set \(x_3 = x_4 = 0\) (basic \(x_1, x_2\)):
\(2x_1 + 6x_2 = 3\), \(6x_1 + 4x_2 = 2\). Solving: \(x_1 = 0\), \(x_2 = 1/2\). BFS: \((0, 1/2, 0, 0)\) — degenerate (basic variable \(x_1 = 0\)).
Step 3: Set \(x_2 = x_4 = 0\) (basic \(x_1, x_3\)):
\(2x_1 + 2x_3 = 3\), \(6x_1 + 4x_3 = 2\). Solving: \(x_1 = -2\), \(x_3 = 7/2\). Infeasible.
Step 4: Set \(x_2 = x_3 = 0\) (basic \(x_1, x_4\)):
\(2x_1 + x_4 = 3\), \(6x_1 + 6x_4 = 2\). Solving: \(x_1 = 8/3\), \(x_4 = -7/3\). Infeasible.
Step 5: Set \(x_1 = x_4 = 0\) (basic \(x_2, x_3\)):
\(6x_2 + 2x_3 = 3\), \(4x_2 + 4x_3 = 2\). Solving: \(x_2 = 1/2\), \(x_3 = 0\). BFS: \((0, 1/2, 0, 0)\) — degenerate (basic variable \(x_3 = 0\)).
Step 6: Set \(x_1 = x_3 = 0\) (basic \(x_2, x_4\)):
\(6x_2 + x_4 = 3\), \(4x_2 + 6x_4 = 2\). Solving: \(x_2 = 1/2\), \(x_4 = 0\). BFS: \((0, 1/2, 0, 0)\) — degenerate (basic variable \(x_4 = 0\)).
Step 7: Set \(x_1 = x_2 = 0\) (basic \(x_3, x_4\)):
\(2x_3 + x_4 = 3\), \(4x_3 + 6x_4 = 2\). Solving: \(x_3 = 2\), \(x_4 = -1\). Infeasible.
Step 8: Basic feasible solutions are \((0, 1/2, 0, 0)\) [appearing multiple times]. In every BFS at least one basic variable is zero → all BFS are degenerate.

✅ Only basic feasible solution is \((0, 1/2, 0, 0)\); it is degenerate (more than one basis gives the same point).

Problem 4. Use the fundamental theorem of LPP to argue that the LPP \(\max Z = 3x_1 + 4x_2\) s.t. \(x_1 + x_2 \le 450,\; 2x_1 + x_2 \le 600,\; x_1, x_2 \ge 0\) must have its optimum at one of its basic feasible solutions. Then list all BFS and find the optimum. CO3
✅ Step-by-step:
Step 1: Standard form: \(x_1 + x_2 + s_1 = 450\), \(2x_1 + x_2 + s_2 = 600\), all \(\ge 0\). Here \(m = 2\), \(m + n = 4\), so \(n = 2\).
Step 2: The fundamental theorem says the optimum (if finite) occurs at a BFS. Total basic solutions \(= \binom{4}{2} = 6\).
Step 3: Set \(x_1 = x_2 = 0\) (basis \(s_1, s_2\)): \(s_1 = 450\), \(s_2 = 600\). BFS: \((0, 0, 450, 600)\), \(Z = 0\).
Step 4: Set \(x_1 = s_1 = 0\) (basis \(x_2, s_2\)): \(x_2 = 450\), \(s_2 = 600 - 450 = 150\). BFS: \((0, 450, 0, 150)\), \(Z = 1800\).
Step 5: Set \(x_1 = s_2 = 0\) (basis \(x_2, s_1\)): \(x_2 = 600\), \(s_1 = 450 - 600 = -150\). Infeasible.
Step 6: Set \(x_2 = s_1 = 0\) (basis \(x_1, s_2\)): \(x_1 = 450\), \(s_2 = 600 - 900 = -300\). Infeasible.
Step 7: Set \(x_2 = s_2 = 0\) (basis \(x_1, s_1\)): \(2x_1 = 600 \Rightarrow x_1 = 300\), \(s_1 = 450 - 300 = 150\). BFS: \((300, 0, 150, 0)\), \(Z = 900\).
Step 8: Set \(s_1 = s_2 = 0\) (basis \(x_1, x_2\)): \(x_1 + x_2 = 450\), \(2x_1 + x_2 = 600\). Solving: \(x_1 = 150\), \(x_2 = 300\). BFS: \((150, 300, 0, 0)\), \(Z = 1650\).
Step 9: Among the four BFS, \(Z\) values are \(0, 1800, 900, 1650\). The maximum is \(1800\) at \((0, 450, 0, 150)\).

✅ By the fundamental theorem, checking the BFS suffices. Optimum: \(x_1 = 0\), \(x_2 = 450\), \(Z_{\max} = 1800\).

📋 6. Quick Summary
  • Basic solution: set \(n\) variables to zero; solve for the remaining \(m\).
  • BFS: basic solution with all variables \(\ge 0\); equal to an extreme point.
  • Degenerate BFS: some basic variable equals zero.
  • Fundamental theorem: the optimum of an LPP (if finite) occurs at a BFS.
  • Number of basic solutions: \(\binom{m+n}{m}\) — finite; this is why the simplex only needs to check a handful of candidates.
