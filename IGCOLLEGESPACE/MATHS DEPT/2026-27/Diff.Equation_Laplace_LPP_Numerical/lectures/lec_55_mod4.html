📐 2. Derivation of the Trapezoidal Rule
📌 Single Interval Derivation

Consider the integral \(\int_{x_0}^{x_1} f(x)\,dx\) over one subinterval of width \(h = x_1 - x_0\).

Approximate \(f(x)\) by a straight line (linear interpolation) through the points \((x_0, y_0)\) and \((x_1, y_1)\):

\[ f(x) \approx y_0 + \frac{y_1 - y_0}{h}(x - x_0) \]

Integrating this linear approximation from \(x_0\) to \(x_1\):

\[ \int_{x_0}^{x_1} f(x)\,dx \approx \int_{x_0}^{x_1} \left[ y_0 + \frac{y_1 - y_0}{h}(x - x_0) \right] dx \]
\[ = h y_0 + \frac{y_1 - y_0}{h} \cdot \frac{h^2}{2} = h y_0 + \frac{h}{2}(y_1 - y_0) \]
\[ = \frac{h}{2}(y_0 + y_1) \]

This is the trapezoidal rule for one interval.

📌 Composite Trapezoidal Rule

Divide \([a, b]\) into \(n\) equal subintervals of width \(h = (b-a)/n\), with points \(x_0, x_1, \dots, x_n\).

Applying the single-interval rule to each subinterval and summing:

\[ \int_{x_0}^{x_n} y\,dx \approx \frac{h}{2}\Big[ y_0 + 2(y_1 + y_2 + \dots + y_{n-1}) + y_n \Big] \]

Equivalently:

\[ \boxed{ \int_a^b f(x)\,dx \approx \frac{h}{2}\left( y_0 + 2\sum_{i=1}^{n-1} y_i + y_n \right) } \]
📏 3. Geometric Interpretation
📌 Area of Trapezoids

The trapezoidal rule approximates the area under the curve \(y = f(x)\) by the sum of the areas of trapezoids.

On each subinterval \([x_{i-1}, x_i]\), the region bounded by the curve, the \(x\)-axis, and the vertical lines \(x = x_{i-1}\), \(x = x_i\) is approximated by a trapezoid with parallel sides \(y_{i-1}\) and \(y_i\), and height \(h\).

The area of this trapezoid is \(\frac{h}{2}(y_{i-1} + y_i)\). Summing over all subintervals gives the trapezoidal rule.

📋 4. Error and Accuracy

The error in the composite trapezoidal rule is

\[ E_T = -\frac{(b-a)}{12}h^2 f''(\xi), \quad a < \xi < b \]

This shows the rule is exact for linear functions (since \(f'' = 0\)) and has order \(O(h^2)\).

⚠️ 5. Points to Remember
🚨 Important Notes
  • The step size \(h\) must be constant.
  • The rule works for any number of subintervals \(n\).
  • The accuracy improves as \(h\) decreases (i.e., as \(n\) increases).
  • The formula uses the two end ordinates once and all interior ordinates twice.

Problem 1 (A1). Write the trapezoidal rule to find \(\int_{x_0}^{x_n} y\,dx\). CO4
✅ Solution:
The trapezoidal rule is
\[ \int_{x_0}^{x_n} y\,dx \approx \frac{h}{2}\Big[ y_0 + 2(y_1 + y_2 + \dots + y_{n-1}) + y_n \Big] \]
where \(h = (x_n - x_0)/n\) and \(y_i = f(x_i)\).
Problem 2 (A3). Write the trapezoidal rule to find \(\int_{x_0}^{x_n} y\,dx\) for \(n = 1\). CO4
✅ Solution:
For \(n = 1\), there are only two ordinates \(y_0\) and \(y_1\), and
\[ \int_{x_0}^{x_1} y\,dx \approx \frac{h}{2}(y_0 + y_1) \]
where \(h = x_1 - x_0\).
Problem 3 (B6). State the trapezoidal rule for finding an approximate area under a given curve. A curve is given by the points \((0, 23)\), \((0.5, 19)\), \((1.0, 14)\), \((1.5, 11)\), \((2.0, 12.5)\), \((2.5, 16)\). Estimate the area bounded by the curve, the \(x\)-axis and the extreme ordinates. CO4
✅ Solution:
The trapezoidal rule states that
\[ \int_{x_0}^{x_n} y\,dx \approx \frac{h}{2}\left[ y_0 + 2(y_1 + y_2 + \dots + y_{n-1}) + y_n \right] \]
Arrange the data in a table:
\(x\)00.51.01.52.02.5
\(y\)2319141112.516
The step size is \(h = 0.5\) and \(n = 5\). Apply the trapezoidal rule:
\[ A \approx \frac{0.5}{2}\Big[ 23 + 2(19 + 14 + 11 + 12.5) + 16 \Big] \]
\[ = 0.25\Big[ 23 + 2(56.5) + 16 \Big] = 0.25\Big[ 23 + 113 + 16 \Big] = 0.25 \times 152 \]
\[ A \approx 38 \]

✅ Area \(\approx 38\) square units.

Problem 4 (B1). Find, from the following table, the area bounded by the curve and the \(x\)-axis from \(x = 7.47\) to \(x = 7.52\).
Table: \(x\): 7.47, 7.48, 7.49, 7.50, 7.51, 7.52; \(f(x)\): 1.93, 1.95, 1.98, 2.01, 2.03, 2.06. CO4
✅ Solution:
Arrange the data in a table with \(h = 0.01\):
\(x\)7.477.487.497.507.517.52
\(f(x)\)1.931.951.982.012.032.06
Apply the trapezoidal rule:
\[ A \approx \frac{0.01}{2}\Big[ 1.93 + 2(1.95 + 1.98 + 2.01 + 2.03) + 2.06 \Big] \]
\[ = 0.005\Big[ 1.93 + 2(7.97) + 2.06 \Big] = 0.005\Big[ 1.93 + 15.94 + 2.06 \Big] \]
\[ = 0.005 \times 19.93 = 0.09965 \]

✅ Area \(\approx 0.0997\) square units.

Problem 5 (B4). Evaluate \(I = \int_0^\pi x \sin x\,dx\) using the trapezoidal rule with five ordinates. CO4
✅ Solution:
Five ordinates means \(n = 4\) subintervals over \([0, \pi]\), so \(h = \frac{\pi - 0}{4} = \frac{\pi}{4}\).
The mesh points are \(x_0 = 0,\; x_1 = \pi/4,\; x_2 = \pi/2,\; x_3 = 3\pi/4,\; x_4 = \pi\).
Compute the ordinates \(y_i = x_i \sin x_i\) (RADIAN mode):
\(y_0 = 0 \cdot \sin 0 = 0\)
\(y_1 = \frac{\pi}{4}\sin\frac{\pi}{4} = \frac{\pi}{4} \times \frac{\sqrt{2}}{2} \approx 0.5554\)
\(y_2 = \frac{\pi}{2}\sin\frac{\pi}{2} = \frac{\pi}{2} \times 1 \approx 1.5708\)
\(y_3 = \frac{3\pi}{4}\sin\frac{3\pi}{4} = \frac{3\pi}{4} \times \frac{\sqrt{2}}{2} \approx 1.6661\)
\(y_4 = \pi \sin\pi = 0\)
Apply the trapezoidal rule:
\[ I \approx \frac{\pi/4}{2}\Big[ 0 + 2(0.5554 + 1.5708 + 1.6661) + 0 \Big] \]
\[ = \frac{\pi}{8} \times 2(3.7923) = \frac{\pi}{8} \times 7.5846 \approx 2.9785 \]

✅ \(I \approx 2.9785\).
