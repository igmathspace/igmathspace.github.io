🎯 1. Learning Outcomes (CO2)
  • Define the Laplace transform as an improper integral
  • Identify application areas in engineering and science
  • Derive the Laplace transform of constant and power functions
  • Apply the general formula \(\mathcal{L}\{t^n\} = \frac{n!}{s^{n+1}}\)
📌 2. Definition of Laplace Transform
Let \( f(t) \) be a function defined for \( t \ge 0 \). The Laplace Transform of \( f(t) \) is denoted by \( \mathcal{L}\{f(t)\} \) or \( F(s) \) and is defined as: \[ \boxed{ \mathcal{L}\{f(t)\} = F(s) = \int_{0}^{\infty} e^{-st} f(t) \, dt } \] where:
  • \( s \) is a complex variable
  • The integral is an improper integral (limit \( b \to \infty \))
  • The transform exists when the integral converges (typically \( s > 0 \))
⚙️ 3. Application Areas
• Control systems
• Electrical circuits (RLC)
• Mechanical vibration
• Signal processing
• Communication systems
• Heat conduction / wave equations
• Chemical kinetics
⚡ Key advantage: converts differential equations into algebraic equations.
📐 4. Standard Results – Step-by-Step Derivations
R1: \(\mathcal{L}\{1\}\)
\[ \mathcal{L}\{1\} = \int_{0}^{\infty} e^{-st} \cdot 1 \, dt = \left[ \frac{-e^{-st}}{s} \right]_{0}^{\infty} \]
\[ = \left( 0 \right) - \left( \frac{-1}{s} \right) = \frac{1}{s} \]
\(s>0\)
R2: \(\mathcal{L}\{a\}\)   (constant \(a\))
\[ \mathcal{L}\{a\} = \int_{0}^{\infty} e^{-st} \cdot a \, dt = a \int_{0}^{\infty} e^{-st} dt = a \cdot \frac{1}{s} \]
\(s>0\)
R3: \(\mathcal{L}\{t\}\)
\[ \mathcal{L}\{t\} = \int_{0}^{\infty} e^{-st} \, t \, dt \quad \text{(integration by parts)} \]
let \(u = t\), \(dv = e^{-st}dt\) → \(du = dt\), \(v = -\dfrac{e^{-st}}{s}\)
\[ = \left[ -\frac{t e^{-st}}{s} \right]_{0}^{\infty} + \frac{1}{s} \int_{0}^{\infty} e^{-st} dt \]
\[ = 0 + \frac{1}{s} \cdot \frac{1}{s} = \frac{1}{s^2} \]
\(s>0\)
R4: \(\mathcal{L}\{t^2\}\)
\[ \mathcal{L}\{t^2\} = \int_{0}^{\infty} e^{-st} t^2 \, dt \]
let \(u = t^2\), \(dv = e^{-st}dt\) → \(du = 2t\,dt\), \(v = -\dfrac{e^{-st}}{s}\)
\[ = \left[ -\frac{t^2 e^{-st}}{s} \right]_{0}^{\infty} + \frac{2}{s} \int_{0}^{\infty} e^{-st} t \, dt \]
\[ = 0 + \frac{2}{s} \cdot \mathcal{L}\{t\} = \frac{2}{s} \cdot \frac{1}{s^2} = \frac{2}{s^3} \]
\(s>0\)
R5 (general): \(\mathcal{L}\{t^n\}\)   \(n \in \mathbb{N}\)
\[ \mathcal{L}\{t^n\} = \int_{0}^{\infty} e^{-st} t^n \, dt \]
using integration by parts recursively:
\[ \mathcal{L}\{t^n\} = \frac{n}{s} \,\mathcal{L}\{t^{\,n-1}\} \]
repeat until \(\mathcal{L}\{1\} = \dfrac{1}{s}\):
\[ = \frac{n}{s} \cdot \frac{n-1}{s} \cdots \frac{1}{s} \cdot \frac{1}{s} = \frac{n(n-1)\cdots 1}{s^{\,n+1}} \]
\[ \boxed{ \mathcal{L}\{t^n\} = \frac{n!}{s^{\,n+1}} } \]
\(s>0\)   \(0! = 1\)

📚 6. Workout Examples

Problems based on the definition and standard results. Click Answer to see step-by-step solution.

1. State the definition of Laplace transform. CO2
✅ Definition: The Laplace transform of a function \( f(t) \) defined for \( t \ge 0 \) is: \[ \mathcal{L}\{f(t)\} = \int_{0}^{\infty} e^{-st} f(t) \, dt \] where \( s \) is a complex variable and the integral converges for \( s > 0 \).
2. Find \(\mathcal{L}\{5\}\) using the integral definition. CO2
✅ Step-by-step: \[ \mathcal{L}\{5\} = \int_{0}^{\infty} e^{-st} \cdot 5 \, dt = 5 \int_{0}^{\infty} e^{-st} dt = 5 \cdot \frac{1}{s} = \frac{5}{s}, \quad s>0 \]
3. Derive \(\mathcal{L}\{t\}\) using integration by parts. CO2
✅ Step-by-step: \[ \mathcal{L}\{t\} = \int_{0}^{\infty} e^{-st} t \, dt \] Let \( u = t \), \( dv = e^{-st}dt \) → \( du = dt \), \( v = -\frac{e^{-st}}{s} \) \[ = \left[ -\frac{t e^{-st}}{s} \right]_{0}^{\infty} + \frac{1}{s} \int_{0}^{\infty} e^{-st} dt = 0 + \frac{1}{s} \cdot \frac{1}{s} = \frac{1}{s^2} \]
4. Find \(\mathcal{L}\{t^3\}\) using the general formula. CO2
✅ Solution: Using \(\mathcal{L}\{t^n\} = \frac{n!}{s^{n+1}}\) with \( n=3 \): \[ \mathcal{L}\{t^3\} = \frac{3!}{s^{4}} = \frac{6}{s^4}, \quad s>0 \]
📋 7. Quick Summary
  • Definition: \(\mathcal{L}\{f(t)\} = \int_0^\infty e^{-st} f(t) dt\)
  • Main use: Convert ODEs into algebraic equations
  • Power function: \(\mathcal{L}\{t^n\} = \frac{n!}{s^{n+1}}\)
  • Constant: \(\mathcal{L}\{a\} = \frac{a}{s}\)
