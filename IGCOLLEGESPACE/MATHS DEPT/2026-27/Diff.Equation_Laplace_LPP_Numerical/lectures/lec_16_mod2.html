📌 Module II | Laplace Transforms
📖 Topic: Standard Results – Exponential, Sine, Cosine, Hyperbolic Functions
📚 Textbook: Advanced Engineering Mathematics – E. Kreyszig | Section 6.1
👨‍🏫 Faculty: Gafoor I 🎯 CO2: Understand Laplace Transform, Linearity, first shifting theorem ⏱️ Lecture duration: 1 Hour
🎯 1. Learning Outcomes (CO2)
  • Derive Laplace transforms of \(e^{at}\), \(\sin(at)\), \(\cos(at)\), \(\sinh(at)\), \(\cosh(at)\)
  • Use standard integral formulas to evaluate Laplace transforms
  • Apply these results in solving ODEs and evaluating integrals
📌 2. Recall: Definition of Laplace Transform
\[ \boxed{ \mathcal{L}\{f(t)\} = F(s) = \int_{0}^{\infty} e^{-st} f(t) \, dt } \]

where \( s \) is a complex variable and the integral converges for appropriate values of \( s \).

💡 3. Prior Knowledge – Standard Integral Formulas

We will use the following standard integral results:

(i) \(\displaystyle \int e^{ax} \sin bx \, dx = \dfrac{e^{ax}}{a^2 + b^2} \left[ a \sin bx - b \cos bx \right] + c\)
(ii) \(\displaystyle \int e^{ax} \cos bx \, dx = \dfrac{e^{ax}}{a^2 + b^2} \left[ a \cos bx + b \sin bx \right] + c\)

✅ These are standard integration formulas, often derived using integration by parts. We will apply them directly.

📊 4. Standard Results – Laplace Transform Pairs
  • \(e^{at}\) \(\mathcal{L}\) \(\longrightarrow\) \(\dfrac{1}{s-a}\) \(s>a\)
  • \(e^{-at}\) \(\mathcal{L}\) \(\longrightarrow\) \(\dfrac{1}{s+a}\) \(s>-a\)
  • \(\sin(at)\) \(\mathcal{L}\) \(\longrightarrow\) \(\dfrac{a}{s^2+a^2}\) \(s>0\)
  • \(\cos(at)\) \(\mathcal{L}\) \(\longrightarrow\) \(\dfrac{s}{s^2+a^2}\) \(s>0\)
  • \(\sinh(at)\) \(\mathcal{L}\) \(\longrightarrow\) \(\dfrac{a}{s^2-a^2}\) \(s>|a|\)
  • \(\cosh(at)\) \(\mathcal{L}\) \(\longrightarrow\) \(\dfrac{s}{s^2-a^2}\) \(s>|a|\)
📐 5. Step-by-Step Derivations from Definition
R1: \(\mathcal{L}\{e^{at}\}\)
\(\mathcal{L}\{e^{at}\} = \displaystyle \int_{0}^{\infty} e^{-st} e^{at} \, dt\)
\(= \displaystyle \int_{0}^{\infty} e^{-(s-a)t} \, dt\)
\(= \left[ \dfrac{-e^{-(s-a)t}}{s-a} \right]_{0}^{\infty}\)
\(= 0 - \left( \dfrac{-1}{s-a} \right) = \dfrac{1}{s-a}, \quad s>a\)
\(s>a\)
R2: \(\mathcal{L}\{e^{-at}\}\)
\(\mathcal{L}\{e^{-at}\} = \displaystyle \int_{0}^{\infty} e^{-st} e^{-at} \, dt\)
\(= \displaystyle \int_{0}^{\infty} e^{-(s+a)t} \, dt\)
\(= \left[ \dfrac{-e^{-(s+a)t}}{s+a} \right]_{0}^{\infty}\)
\(= \dfrac{1}{s+a}, \quad s>-a\)
\(s>-a\)
R3: \(\mathcal{L}\{\sin(at)\}\)
Using integral formula (i) with \(a \to -s\) and \(b \to a\):
\(\mathcal{L}\{\sin(at)\} = \displaystyle \int_{0}^{\infty} e^{-st} \sin(at) \, dt\)
\(= \left[ \dfrac{e^{-st}}{s^2 + a^2} \bigl( -s \sin(at) - a \cos(at) \bigr) \right]_{0}^{\infty}\)
\(= \left[ \dfrac{-s \sin(at) - a \cos(at)}{s^2 + a^2} \cdot e^{-st} \right]_{0}^{\infty}\)
\(= \left( 0 \right) - \left( \dfrac{-s \cdot 0 - a \cdot 1}{s^2 + a^2} \cdot 1 \right)\)
\(= \dfrac{a}{s^2 + a^2}, \quad s>0\)
\(s>0\)
R4: \(\mathcal{L}\{\cos(at)\}\)
Using integral formula (ii) with \(a \to -s\) and \(b \to a\):
\(\mathcal{L}\{\cos(at)\} = \displaystyle \int_{0}^{\infty} e^{-st} \cos(at) \, dt\)
\(= \left[ \dfrac{e^{-st}}{s^2 + a^2} \bigl( -s \cos(at) + a \sin(at) \bigr) \right]_{0}^{\infty}\)
\(= \left[ \dfrac{-s \cos(at) + a \sin(at)}{s^2 + a^2} \cdot e^{-st} \right]_{0}^{\infty}\)
\(= \left( 0 \right) - \left( \dfrac{-s \cdot 1 + a \cdot 0}{s^2 + a^2} \cdot 1 \right)\)
\(= \dfrac{s}{s^2 + a^2}, \quad s>0\)
\(s>0\)
R5: \(\mathcal{L}\{\sinh(at)\}\)
Using definition \(\sinh(at) = \dfrac{e^{at} - e^{-at}}{2}\):
\(\mathcal{L}\{\sinh(at)\} = \dfrac{1}{2} \left( \mathcal{L}\{e^{at}\} - \mathcal{L}\{e^{-at}\} \right)\)
\(= \dfrac{1}{2} \left( \dfrac{1}{s-a} - \dfrac{1}{s+a} \right)\)
\(= \dfrac{1}{2} \left( \dfrac{2a}{s^2 - a^2} \right)\)
\(= \dfrac{a}{s^2 - a^2}, \quad s>|a|\)
\(s>|a|\)
R6: \(\mathcal{L}\{\cosh(at)\}\)
Using definition \(\cosh(at) = \dfrac{e^{at} + e^{-at}}{2}\):
\(\mathcal{L}\{\cosh(at)\} = \dfrac{1}{2} \left( \mathcal{L}\{e^{at}\} + \mathcal{L}\{e^{-at}\} \right)\)
\(= \dfrac{1}{2} \left( \dfrac{1}{s-a} + \dfrac{1}{s+a} \right)\)
\(= \dfrac{1}{2} \left( \dfrac{2s}{s^2 - a^2} \right)\)
\(= \dfrac{s}{s^2 - a^2}, \quad s>|a|\)
\(s>|a|\)
📚 6. Workout Examples

Problems based on the derived results. Click Answer to see step-by-step solution.

1. Find \(\mathcal{L}\{e^{4t}\}\) using the definition. CO2
✅ Solution:
\(\mathcal{L}\{e^{4t}\} = \displaystyle \int_{0}^{\infty} e^{-st} e^{4t} dt\)
\(= \displaystyle \int_{0}^{\infty} e^{-(s-4)t} dt\)
\(= \dfrac{1}{s-4}, \quad s>4\)
2. Find \(\mathcal{L}\{\sin(3t)\}\) using the integral formula. CO2
✅ Solution:
\(\mathcal{L}\{\sin(3t)\} = \displaystyle \int_{0}^{\infty} e^{-st} \sin(3t) dt\)
\(= \left[ \dfrac{e^{-st}}{s^2+9} \bigl( -s \sin(3t) - 3 \cos(3t) \bigr) \right]_{0}^{\infty}\)
\(= 0 - \left( \dfrac{-3}{s^2+9} \right) = \dfrac{3}{s^2+9}\)
3. Find \(\mathcal{L}\{\cosh(2t)\}\). CO2
✅ Solution:
\(\mathcal{L}\{\cosh(2t)\} = \dfrac{1}{2} \left( \mathcal{L}\{e^{2t}\} + \mathcal{L}\{e^{-2t}\} \right)\)
\(= \dfrac{1}{2} \left( \dfrac{1}{s-2} + \dfrac{1}{s+2} \right)\)
\(= \dfrac{s}{s^2-4}, \quad s>2\)
4. Find \(\mathcal{L}\{5\sin(2t) - 3\cos(2t)\}\). CO2
✅ Solution:
\(\mathcal{L}\{5\sin(2t) - 3\cos(2t)\} = 5\mathcal{L}\{\sin(2t)\} - 3\mathcal{L}\{\cos(2t)\}\)
\(= 5 \cdot \dfrac{2}{s^2+4} - 3 \cdot \dfrac{s}{s^2+4}\)
\(= \dfrac{10 - 3s}{s^2+4}\)
📋 7. Quick Summary
  • Exponential: \(\mathcal{L}\{e^{at}\} = \dfrac{1}{s-a}\)
  • Sine: \(\mathcal{L}\{\sin(at)\} = \dfrac{a}{s^2+a^2}\)
  • Cosine: \(\mathcal{L}\{\cos(at)\} = \dfrac{s}{s^2+a^2}\)
  • Hyperbolic sine: \(\mathcal{L}\{\sinh(at)\} = \dfrac{a}{s^2-a^2}\)
  • Hyperbolic cosine: \(\mathcal{L}\{\cosh(at)\} = \dfrac{s}{s^2-a^2}\)
