📖 Topic: Simplex Iterations – Entering Variable, Leaving Variable (Ratio Test)
📚 Textbook: Operations Research – Gupta & Hira | §2.16 (Iterations)
👨‍🏫 Faculty: Gafoor I 🎯 CO3: Perform simplex iterations correctly ⏱️ Lecture duration: 1 Hour
🎯 1. Learning Outcomes (CO3)
  • Identify the entering variable using the \(c_j - Z_j\) row
  • Identify the leaving variable using the minimum ratio test
  • Locate the key column, key row and key element
  • Build the new simplex tableau by elementary row operations
  • Recognise when the solution is optimal, unbounded, or when degeneracy may occur
📌 2. Recap — Tableau Layout

At each stage of the simplex method we maintain a tableau of the form

\(c_B\)Basis\(b\)\(x_1\)\(x_2\)...\(s_1\)...Ratio
\(c_1\)\(c_2\)...0...
...........................
\(Z_j\)...............
\(c_j - Z_j\)...............
📐 3. Selection of the Entering (Incoming) Variable
Rule — Maximisation

Compute the row \(c_j - Z_j\). If all entries are \(\le 0\), the current BFS is optimal and we stop. Otherwise, mark the column with the largest positive \(c_j - Z_j\); the variable heading that column enters the solution. This column is called the key column (or pivot column).

Rule — Minimisation

If all entries of \(c_j - Z_j\) are \(\ge 0\), the current BFS is optimal. Otherwise, mark the column with the most negative \(c_j - Z_j\); that variable enters.

Why? The value \(c_j - Z_j\) represents the net increase in the objective function per unit increase of the variable \(x_j\) in the current solution. A positive value means we can improve the objective by introducing that variable. Choosing the largest positive value gives the steepest per-unit improvement and so reduces the number of iterations.

📐 4. Selection of the Leaving (Outgoing) Variable — Minimum Ratio Test
Rule

Once the entering variable is chosen (say \(x_k\)), compute for every row \(i\):

\[ \theta_i = \frac{b_i}{a_{ik}}, \quad a_{ik} > 0. \]

Only rows with a strictly positive coefficient \(a_{ik}\) in the key column are considered. The row with the minimum non-negative ratio is the key row (pivot row). The basic variable in that row leaves the basis. The element at the intersection of key row and key column is the key element (pivot element).

Why? As \(x_k\) increases from 0, the basic variables change according to \(x_{Bi} = b_i - a_{ik}\, x_k\). To keep all basic variables \(\ge 0\), \(x_k\) cannot exceed \(b_i / a_{ik}\). The first constraint that becomes tight determines how far we can push \(x_k\); hence the minimum ratio.

⚠️ CAUTION! If all \(a_{ik} \le 0\) in the key column, no leaving variable exists — the solution is unbounded. If two or more rows tie for the minimum ratio, the solution becomes degenerate; either row may be chosen, and cycling is possible in pathological cases.
🔄 5. Pivot Operations — Building the New Tableau
Row operations
  1. Update basis: replace the leaving variable by the entering variable in the Basis column. Update \(c_B\) accordingly.
  2. Make the key element 1: divide every element of the key row by the key element.
  3. Make all other elements of the key column zero: for each other row, subtract (appropriate multiple of the new key row) from it.
  4. Recompute the \(Z_j\) and \(c_j - Z_j\) rows for the new tableau.
  5. Test optimality again. Repeat until all \(c_j - Z_j \le 0\) (max) or \(\ge 0\) (min).

📋 8. Quick Summary
  • Entering: largest positive \(c_j - Z_j\) (max) or most negative (min).
  • Leaving: minimum ratio \(b_i / a_{ik}\) among rows with \(a_{ik} > 0\).
  • Key element: intersection of key row and key column; pivot around it.
  • Pivot: divide key row by key element; make other entries in key column zero.
  • Optimality: stop when \(c_j - Z_j \le 0\) (max) or \(\ge 0\) (min).
  • Unbounded: stop if the key column has no positive entries.
