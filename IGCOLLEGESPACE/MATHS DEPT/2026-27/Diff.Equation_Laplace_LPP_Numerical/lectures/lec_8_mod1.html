⚡ General Method & Golden Rule for Integrating Factors
⚡ General Method for Finding Integrating Factors

For a non-exact ODE:

\[ P(x, y) \, dx + Q(x, y) \, dy = 0 \]

We multiply by \(F(x, y)\) to get:

\[ FP \, dx + FQ \, dy = 0 \]

The new equation is exact if:

\[ \frac{\partial}{\partial y}(FP) = \frac{\partial}{\partial x}(FQ) \]

By the product rule:

\[ F_y P + F P_y = F_x Q + F Q_x \]
🥇 Golden Rule: "If you cannot solve your problem, try to solve a simpler one."
Look for an integrating factor depending on only one variable.
📐 Theorem 1: Integrating Factor \(F(x)\) (function of x only)

If the expression:

\[ R = \frac{1}{Q} \left( \frac{\partial P}{\partial y} - \frac{\partial Q}{\partial x} \right) \]

depends only on x (and not on y), then the ODE has an integrating factor:

\[ F(x) = \exp\left( \int R(x) \, dx \right) \]
Derivation: Let \(F = F(x)\). Then \(F_y = 0\) and \(F_x = F' = dF/dx\).
Substituting: \(F P_y = F' Q + F Q_x\) → \(\frac{1}{F} \frac{dF}{dx} = \frac{1}{Q}(P_y - Q_x) = R\). Integrating gives \(F(x) = \exp(\int R \, dx)\).
📐 Theorem 2: Integrating Factor \(F^*(y)\) (function of y only)

If the expression:

\[ R^* = \frac{1}{P} \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) \]

depends only on y (and not on x), then the ODE has an integrating factor:

\[ F^*(y) = \exp\left( \int R^*(y) \, dy \right) \]
Derivation: Let \(F^* = F^*(y)\). Then \(F^*_x = 0\) and \(F^*_y = dF^*/dy\).
\(F^* P_y + F^*_y P = F^* Q_x\) → \(\frac{1}{F^*} \frac{dF^*}{dy} = \frac{1}{P}(Q_x - P_y) = R^*\). Integrating gives \(F^*(y) = \exp(\int R^* \, dy)\).
🏆 Theorem 1 and Theorem 2 together are termed as the GOLDEN RULE for finding integrating factors.
📌 Summary of the Golden Rule:
  • Check \(F(x)\): Compute \(R = \frac{1}{Q}(P_y - Q_x)\). If \(R\) depends only on \(x\), then \(F(x) = e^{\int R \, dx}\).
  • Check \(F(y)\): Compute \(R^* = \frac{1}{P}(Q_x - P_y)\). If \(R^*\) depends only on \(y\), then \(F(y) = e^{\int R^* \, dy}\).
  • If neither works, try inspection or look for an integrating factor that depends on both variables.
📋 Step-by-Step Procedure
Step 1: Check exactness. Compute \(P_y\) and \(Q_x\). If equal → already exact.
Step 2: Try Theorem 1 (\(F(x)\)). Compute \(R = (1/Q)(P_y - Q_x)\). If \(R\) depends only on \(x\), find \(F(x) = e^{\int R dx}\).
Step 3: Try Theorem 2 (\(F(y)\)). Compute \(R^* = (1/P)(Q_x - P_y)\). If \(R^*\) depends only on \(y\), find \(F(y) = e^{\int R^* dy}\).
✅ After multiplying by the integrating factor, always verify that the new equation is exact before proceeding.
📖 Worked Example: IVP with Integrating Factor

Problem: Solve the IVP:

\[ (e^{x+y} + y e^y) \, dx + (x e^y - 1) \, dy = 0, \qquad y(0) = -1 \]
Step 1 (exactness): \(P = e^{x+y} + y e^y\), \(Q = x e^y - 1\). \(P_y = e^{x+y} + e^y + y e^y\), \(Q_x = e^y\). Not exact.
Step 2 (F(x)): \(R = (1/Q)(P_y - Q_x) = (e^{x+y} + y e^y)/(x e^y - 1)\) depends on both → fails.
Step 3 (F(y)): \(R^* = (1/P)(Q_x - P_y) = -1\) depends only on y → works. \(F^*(y) = e^{-y}\).
Step 4 (multiply): \((e^x + y) dx + (x - e^{-y}) dy = 0\). Check: \(M_y = 1\), \(N_x = 1\) → exact.
Step 5 (solve): \(u = \int (e^x + y) dx = e^x + xy + k(y)\). Then \(u_y = x + k'(y) = x - e^{-y}\) → \(k(y) = e^{-y}\). General solution: \(e^x + xy + e^{-y} = C\).
Step 6 (IC): \(y(0) = -1\) → \(1 + 0 + e = 1+e\) → \(C = 1+e\). Particular: \(e^x + xy + e^{-y} = 1+e\).
📝 Problems from the Text
In the following problems, a function \(F(x, y)\) is given. Check whether this \(F\) can form an integrating factor.
Prob. 13: \(e^{-y} dx + e^{-x}(-e^{-y} + 1) dy = 0\),   \(F = e^{x+y}\) CO1
✅ Solution: Multiply: \(e^x dx + (-1 + e^y) dy = 0\). \(M = e^x\), \(N = -1+e^y\). \(M_y = 0 = N_x\) → exact. \(u = e^x - y + e^y = C\).
Prob. 14: \((a+1)y \, dx + (b+1)x \, dy = 0\), \(y(1)=1\), \(F = x^a y^b\) CO1
✅ Solution: Multiply: \((a+1)x^a y^{b+1} dx + (b+1)x^{a+1} y^b dy = 0\). \(M_y = (a+1)(b+1)x^a y^b\), \(N_x = (b+1)(a+1)x^a y^b\) → exact. \(u = x^{a+1} y^{b+1} = C\). IC gives \(C=1\). Particular: \(x^{a+1} y^{b+1} = 1\).
⚠️ Common Mistakes to Avoid
MistakeCorrection
Forgetting to check exactness before shortcutAlways verify \(M_y = N_x\) first.
Including \(x\)-terms in \(N_1(y)\)Only terms with no \(x\) go into \(N_1(y)\).
Omitting the constant \(C\)Always write \(u(x,y) = C\).
Forgetting to verify the integrating factor worksAfter multiplying, check exactness.
Confusing \(F(x)\) with \(F(y)\) conditions\(R\) must depend only on \(x\); \(R^*\) only on \(y\).
📋 Quick Summary
  • Exact ODE form: \(M \, dx + N \, dy = 0\)
  • Exactness condition: \(\partial M/\partial y = \partial N/\partial x\)
  • Shortcut solution: \(\int M \, dx + \int N_1(y) \, dy = C\)
  • \(N_1(y)\) = purely \(y\)-terms from \(N\)
  • Integrating factor \(F(x)\): \(F(x) = \exp\left(\int \frac{1}{Q}(P_y - Q_x) \, dx\right)\)
  • Integrating factor \(F(y)\): \(F(y) = \exp\left(\int \frac{1}{P}(Q_x - P_y) \, dy\right)\)
  • 🏆 Theorem 1 and Theorem 2 together are the GOLDEN RULE.
