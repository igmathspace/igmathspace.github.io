📖 Exact ODEs – Condition, Method & Solutions
📚 Kreyszig §1.4 (Exact ODEs)
👨‍🏫 Faculty: Gafoor I  |  🎯 CO1: Solve exact differential equations
🎯 Learning Outcomes (CO1)
  • Identify an exact differential equation using the exactness condition
  • Apply the method of solution for exact ODEs
  • Use the shortcut technique (Integrate M + Integrate N₁(y))
  • Solve exact ODEs with initial conditions
📌 Standard Form of a First-Order ODE
Any first-order ODE can be written in differential form: \[ M(x, y)\,dx + N(x, y)\,dy = 0 \] where \(M\) and \(N\) are functions of \(x\) and \(y\).
✅ Condition for Exactness
The ODE \(M\,dx + N\,dy = 0\) is called exact if there exists a function \(u(x, y)\) such that: \[ du = M\,dx + N\,dy \quad \Longleftrightarrow \quad \frac{\partial u}{\partial x} = M,\; \frac{\partial u}{\partial y} = N \] By Clairaut's theorem (equality of mixed partials), the necessary and sufficient condition is: \[ \boxed{\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}} \]
📝 Method of Solution (Standard)
Step-by-step procedure:
  1. Check exactness: Verify \(\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\).
  2. Integrate \(M\) w.r.t. \(x\): \(u = \int M\,dx + \phi(y)\).
  3. Differentiate w.r.t. \(y\): \(\frac{\partial u}{\partial y} = \frac{\partial}{\partial y}\left(\int M\,dx\right) + \phi'(y) = N\).
  4. Solve for \(\phi'(y)\) and integrate to get \(\phi(y)\).
  5. General solution: \(u(x, y) = C\).
⚡ Shortcut Technique (Your Method)

Given \(M\,dx + N\,dy = 0\) is exact, the solution is:

\[ \boxed{\int M\,dx + \int N_1(y)\,dy = C} \]
  • ✅ In \(\int M\,dx\), treat \(y\) as constant.
  • ✅ \(N_1(y)\) = all terms in \(N(x,y)\) that are independent of \(x\) (purely \(y\)-terms).
  • ✅ \(C\) is the arbitrary constant.

👉 This shortcut skips the \(\phi(y)\) step and is mathematically rigorous!

📖 Worked Example (Shortcut Technique)
Example: Solve \((2xy + e^x)\,dx + (x^2 + 3y^2)\,dy = 0\)

Step 1: Check exactness
\(M = 2xy + e^x \Rightarrow M_y = 2x\)
\(N = x^2 + 3y^2 \Rightarrow N_x = 2x\)
Since \(M_y = N_x\), the ODE is exact.

Step 2: Apply shortcut
\(\int M\,dx = \int (2xy + e^x)\,dx = x^2y + e^x\)
\(N_1(y)\) = terms in \(N\) with no \(x\): \(3y^2\)
\(\int N_1(y)\,dy = \int 3y^2\,dy = y^3\)

Step 3: Solution \[ x^2y + e^x + y^3 = C \]
📚 Workout Examples (From Question Bank)

Problems on exact differential equations from KU3DSCMAT211 QB – Module 1, Section 2.

A1. Check whether \(-y\,dx + x\,dy = 0\) is exact. CO1
✅ Solution:
\(M = -y,\; N = x\)
\(\frac{\partial M}{\partial y} = -1,\; \frac{\partial N}{\partial x} = 1\)
Since \(-1 \neq 1\), the ODE is not exact.
B1. Solve \(\cos(x+y)\,dx + (3y^2 + 2y + \cos(x+y))\,dy = 0\) CO1
✅ Solution (Shortcut method):
\(M = \cos(x+y),\; N = 3y^2 + 2y + \cos(x+y)\)

Check exactness:
\(M_y = -\sin(x+y)\)
\(N_x = -\sin(x+y)\)
✅ Exact.

Apply shortcut:
\(\int M\,dx = \int \cos(x+y)\,dx = \sin(x+y)\)
\(N_1(y)\) = terms in \(N\) with no \(x\): \(3y^2 + 2y\)
\(\int N_1(y)\,dy = y^3 + y^2\)

Solution: \[ \sin(x+y) + y^3 + y^2 = C \]
B2. Solve IVP: \((\cos y \sinh x + 1)\,dx - \sin y \cosh x\,dy = 0,\; y(1)=2\) CO1
✅ Solution:
\(M = \cos y \sinh x + 1,\; N = -\sin y \cosh x\)

Check exactness:
\(M_y = -\sin y \sinh x\)
\(N_x = -\sin y \sinh x\)
✅ Exact.

Shortcut:
\(\int M\,dx = \int (\cos y \sinh x + 1)\,dx = \cos y \cosh x + x\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
\(\int 0\,dy = 0\)

General solution: \[ \cos y \cosh x + x = C \] Apply IC \(y(1)=2\):
\(\cos 2 \cdot \cosh 1 + 1 = C\)
\(C = \cosh 1 \cos 2 + 1\)
Particular solution: \[ \cos y \cosh x + x = \cosh 1 \cos 2 + 1 \]
B3. Solve \(-y\,dx + x\,dy = 0\) CO1
✅ Solution:
This ODE is not exact (as shown in A1).
However, it can be solved as a separable ODE:
\(-y\,dx + x\,dy = 0 \Rightarrow x\,dy = y\,dx \Rightarrow \frac{dy}{y} = \frac{dx}{x}\)
\(\ln|y| = \ln|x| + C \Rightarrow y = Cx\)
(This is not an exact ODE solution; it's separable.)
B4. Solve \(2x \tan y\,dx + \sec^2 y\,dy = 0\) CO1
✅ Solution:
\(M = 2x \tan y,\; N = \sec^2 y\)

Check exactness:
\(M_y = 2x \sec^2 y\)
\(N_x = 0\)
❌ Not exact! (So shortcut doesn't apply directly.)
This is actually separable:
\(2x \tan y\,dx = -\sec^2 y\,dy\)
\(\frac{2x}{1}\,dx = -\frac{\sec^2 y}{\tan y}\,dy\)
\(2x\,dx = -\frac{1}{\sin y \cos y}\,dy\)
Integrate: \(x^2 = -\ln|\tan y| + C\)
\(\Rightarrow \ln|\tan y| + x^2 = C\)
(Not exact, but solved as separable.)
C7(a). Check exactness and solve: \(3(y+1)\,dx = 2x\,dy\) CO1
✅ Solution:
Rewrite: \(3(y+1)\,dx - 2x\,dy = 0\)
\(M = 3(y+1),\; N = -2x\)

Check exactness:
\(M_y = 3,\; N_x = -2\)
❌ Not exact.

This is separable:
\(3(y+1)\,dx = 2x\,dy\)
\(\frac{3}{2x}\,dx = \frac{1}{y+1}\,dy\)
\(\frac{3}{2}\ln|x| = \ln|y+1| + C\)
\((y+1)^2 = C x^3\)
C7(b). Solve \(e^{3y}(dx + 3x\,dy) = 0\) CO1
✅ Solution:
\(e^{3y}\,dx + 3x e^{3y}\,dy = 0\)
\(M = e^{3y},\; N = 3x e^{3y}\)

Check exactness:
\(M_y = 3e^{3y},\; N_x = 3e^{3y}\)
✅ Exact.

Shortcut:
\(\int M\,dx = \int e^{3y}\,dx = x e^{3y}\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
Solution: \[ x e^{3y} = C \]
C7(c). Define an exact differential equation. CO1
✅ Definition:
A first-order ODE \(M(x,y)\,dx + N(x,y)\,dy = 0\) is called exact if its left-hand side is the total differential of some function \(u(x,y)\).
That is, there exists \(u(x,y)\) such that: \[ du = \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy = M\,dx + N\,dy \] Equivalently, the condition \(\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\) must hold.
⚠️ Common Mistakes to Avoid
MistakeCorrection
Forgetting to check exactness before applying the shortcutAlways verify \(\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\) first.
Including \(x\)-terms in \(N_1(y)\)Only terms with no \(x\) go into \(N_1(y)\).
Omitting the constant \(C\) in the final solutionAlways write \(u(x,y) = C\).
📋 Quick Summary
  • Exact ODE form: \(M\,dx + N\,dy = 0\)
  • Condition: \(\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\)
  • Shortcut solution: \(\int M\,dx + \int N_1(y)\,dy = C\)
  • \(N_1(y)\) = purely \(y\)-terms from \(N\)
