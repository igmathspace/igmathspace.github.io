🎯 1. Learning Outcomes (CO4)
  • Apply the bisection algorithm step-by-step to various equations
  • Record iterations in a standard tableau and track the bracketing interval
  • Determine the number of iterations required for a given accuracy
  • Recognise the effect of trigonometric functions (and set calculators to Radian mode)
🚨 IMPORTANT WARNING: CALCULATOR MODE
For any equation involving trigonometric functions (such as \(\sin x\) or \(\cos x\)), you MUST ensure your scientific calculator is set to RADIAN MODE. Calculating functions in the wrong mode will result in completely incorrect values for \(f(x)\) and an incorrect interval.
