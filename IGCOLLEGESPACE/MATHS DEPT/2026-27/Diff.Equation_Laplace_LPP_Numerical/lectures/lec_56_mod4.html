📐 2. The Composite Trapezoidal Rule
📌 Formula for \(n\) Subintervals

Divide \([a, b]\) into \(n\) equal subintervals of width \(h = (b-a)/n\). Let \(y_i = f(x_i)\) at the mesh points \(x_0 = a, x_1, \dots, x_n = b\). The composite trapezoidal rule is

\[ \boxed{ \int_a^b f(x)\,dx \approx \frac{h}{2}\left[ y_0 + 2(y_1 + y_2 + \dots + y_{n-1}) + y_n \right] } \]

Equivalently:

\[ I_T = \frac{h}{2}\left( y_0 + 2\sum_{i=1}^{n-1} y_i + y_n \right) \]

The end ordinates \(y_0\) and \(y_n\) appear once; every interior ordinate appears twice.

📏 3. Error Analysis
📌 Error Term

The error in the composite trapezoidal rule is the sum of the errors over the individual subintervals. For a function with continuous second derivative,

\[ E_T = -\frac{(b-a)}{12}\,h^2\,f''(\xi), \quad a < \xi < b \]

Since \(h = (b-a)/n\), this can also be written as

\[ E_T = -\frac{(b-a)^3}{12n^2}\,f''(\xi) \]

The error is of order \(O(h^2)\): halving \(h\) quarters the error. It also vanishes if \(f''(x) = 0\) on \([a, b]\), i.e., the rule is exact for linear functions.

Bounding the Error. If \(M_2 = \max_{[a,b]} |f''(x)|\), then the error satisfies

\[ |E_T| \le \frac{(b-a)}{12}\,h^2\,M_2 = \frac{(b-a)^3}{12n^2}\,M_2 \]

To achieve an accuracy \(\epsilon\), we need

\[ \frac{(b-a)^3}{12n^2}\,M_2 \le \epsilon \quad \Longrightarrow \quad n \ge \sqrt{\frac{(b-a)^3 M_2}{12\epsilon}} \]
⚠️ 4. Points to Remember
🚨 Important Notes
  • The step size \(h\) must be constant.
  • The rule works for any \(n\) (unlike Simpson's 1/3, which needs even \(n\)).
  • Doubling \(n\) reduces the error by a factor of \(4\) (assuming \(f''\) is roughly constant).
  • The error formula involves \(f''\), so an estimate of \(M_2\) is needed to bound the error in advance.

Problem 1 (B4). Evaluate \(I = \int_0^\pi x \sin x\,dx\) using the trapezoidal rule with five ordinates. CO4
✅ Solution:
Five ordinates means \(n = 4\) subintervals, so \(h = \pi/4\).
Compute the ordinates \(y_i = x_i \sin x_i\) (RADIAN mode):
\(x_i\)0\(\pi/4\)\(\pi/2\)\(3\pi/4\)\(\pi\)
\(y_i\)00.55541.57081.66610
Apply the composite trapezoidal rule:
\[ I \approx \frac{\pi/4}{2}\Big[ 0 + 2(0.5554 + 1.5708 + 1.6661) + 0 \Big] \]
\[ = \frac{\pi}{8} \times 7.5846 \approx 2.9785 \]

✅ \(I \approx 2.9785\).

Problem 2 (B3). Evaluate \(I = \int_0^1 \sqrt{1 - x^2}\,dx\) using the trapezoidal rule. CO4
✅ Solution:
Take \(h = 0.25\), so \(n = 4\) subintervals. The mesh points and ordinates are:
\(x\)00.250.500.751.00
\(y = \sqrt{1-x^2}\)1.00000.96820.86600.66140.0000
Apply the composite trapezoidal rule:
\[ I \approx \frac{0.25}{2}\Big[ 1.0000 + 2(0.9682 + 0.8660 + 0.6614) + 0.0000 \Big] \]
\[ = 0.125\Big[ 1.0000 + 2(2.4956) \Big] = 0.125\Big[ 1.0000 + 4.9912 \Big] \]
\[ = 0.125 \times 5.9912 \approx 0.7489 \]

✅ \(I \approx 0.7489\). (The exact value is \(\pi/4 \approx 0.7854\).)

Problem 3 (B5). Evaluate \(\int_{-2}^{2} \frac{x}{5 + 2x}\,dx\) using the trapezoidal rule with five ordinates. CO4
✅ Solution:
Five ordinates means \(n = 4\) subintervals over \([-2, 2]\), so \(h = \frac{2 - (-2)}{4} = 1\).
The mesh points and ordinates are:
\(x\)−2−1012
\(y = \dfrac{x}{5+2x}\)\(\frac{-2}{1} = -2\)\(\frac{-1}{3} \approx -0.3333\)0\(\frac{1}{7} \approx 0.1429\)\(\frac{2}{9} \approx 0.2222\)
Apply the composite trapezoidal rule:
\[ I \approx \frac{1}{2}\Big[ -2 + 2(-0.3333 + 0 + 0.1429) + 0.2222 \Big] \]
\[ = 0.5\Big[ -2 + 2(-0.1904) + 0.2222 \Big] = 0.5\Big[ -2 - 0.3808 + 0.2222 \Big] \]
\[ = 0.5 \times (-2.1586) \approx -1.0793 \]

✅ \(I \approx -1.0793\).

Problem 4. Estimate the error in \(\int_0^1 \frac{1}{1+x}\,dx\) using the trapezoidal rule with \(h = 0.25\). Compare with the exact value. CO4
✅ Solution:
Take \(h = 0.25\), so \(n = 4\). The ordinates of \(y = 1/(1+x)\) are:
\(x\)00.250.500.751.00
\(y\)1.00000.80000.66670.57140.5000
Apply the composite trapezoidal rule:
\[ I_T \approx \frac{0.25}{2}\Big[ 1.0000 + 2(0.8000 + 0.6667 + 0.5714) + 0.5000 \Big] \]
\[ = 0.125\Big[ 1.5000 + 2(2.0381) \Big] = 0.125 \times 5.5762 \approx 0.6970 \]
The exact value is \(\ln 2 \approx 0.6931\). Hence the actual error is \(I_T - I = 0.6970 - 0.6931 = 0.0039\).
Bound: here \(f(x) = 1/(1+x)\), so \(f''(x) = 2/(1+x)^3\), and \(M_2 = \max|f''| = 2\) on \([0,1]\). Then
\[ |E_T| \le \frac{(1-0)^3}{12 \times 4^2} \times 2 = \frac{2}{192} \approx 0.0104 \]
The actual error \(0.0039\) is indeed within this bound.

✅ \(I_T \approx 0.6970\), actual error \(\approx 0.0039\), bound \(\approx 0.0104\).

Problem 5. For \(\int_0^1 \frac{1}{1+x}\,dx\), find the minimum number of subintervals needed for the trapezoidal rule to be accurate to \(0.0005\). CO4
✅ Solution:
We have \(f''(x) = 2/(1+x)^3\) and \(M_2 = 2\) on \([0,1]\).
The error bound is
\[ |E_T| \le \frac{(b-a)^3 M_2}{12 n^2} = \frac{2}{12 n^2} = \frac{1}{6 n^2} \]
Require \(\frac{1}{6n^2} \le 0.0005\):
\[ n^2 \ge \frac{1}{6 \times 0.0005} = \frac{1}{0.003} \approx 333.33 \]
\[ n \ge \sqrt{333.33} \approx 18.26 \]
Hence we need \(n \ge 19\) subintervals (take \(n = 20\) for convenience with \(h = 0.05\)).

✅ Minimum \(n = 19\) (practically \(n = 20\)).
