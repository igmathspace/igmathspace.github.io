🎯 1. Learning Outcomes (CO3)
  • Use the extreme point enumeration approach on a bounded feasible region
  • Use the iso-profit line approach to locate the optimum graphically
  • Identify multiple optimal solutions when the iso-profit line is parallel to a binding edge
  • Determine the optimal basic feasible solution from the corner points
📐 2. Two Methods to Find the Optimum
Method 1: Extreme point enumeration
  1. Plot all constraints and find the feasible region.
  2. List all its corner points (vertices).
  3. Evaluate the objective function \(Z\) at each corner.
  4. The corner with the largest \(Z\) (for maximisation) is optimal.
Method 2: Iso-profit line
  1. Set \(Z = 0\) (or any convenient value) and plot the line \(c_1 x_1 + c_2 x_2 = Z\).
  2. Move this line parallel to itself in the direction of increasing \(Z\) (for maximisation).
  3. The last point of the feasible region touched by this moving line is the optimum.
  4. If the moving line coincides with an edge, every point on that edge is optimal (multiple optima).
⚠️ CAUTION! In maximisation, move the iso-profit line outward (away from origin). In minimisation, move it inward (towards origin). Also, if the feasible region is unbounded, the "last touch" may not exist — then the LP may be unbounded.

Problem 1. Maximise \(Z = 3x_1 + 4x_2\), subject to \(x_1 + x_2 \le 450,\; 2x_1 + x_2 \le 600,\; x_1, x_2 \ge 0\). CO3
✅ Step-by-step (extreme point enumeration):
Step 1: Line \(x_1 + x_2 = 450\) passes through \((450, 0)\) and \((0, 450)\).
Step 2: Line \(2x_1 + x_2 = 600\) passes through \((300, 0)\) and \((0, 600)\).
Step 3: Solving the two line equations simultaneously: subtract → \(x_1 = 150\); then \(x_2 = 300\). Corner point \(D(150, 300)\).
Step 4: Corner points of feasible region: \(O(0,0)\), \(C(0, 450)\), \(D(150, 300)\), \(E(300, 0)\).
Step 5: Evaluate \(Z = 3x_1 + 4x_2\):
\(Z(O) = 0\), \(Z(C) = 1800\), \(Z(D) = 450 + 1200 = 1650\), \(Z(E) = 900\).
Step 6: Maximum is \(Z = 1800\) at \(C(0, 450)\).
Fig. 35.1 — Feasible region of Problem 1; iso-profit line at \(Z=1800\) touches \(C(0,450)\)

✅ \(x_1 = 0,\; x_2 = 450,\; Z_{\max} = 1800\).

Problem 2. Identify the feasible region \(x + y \le 3,\; x \ge 0,\; y \ge 0\). Hence find the optimal \(Z = 2x + y\). CO3
✅ Step-by-step:
Step 1: Line \(x + y = 3\) passes through \((3,0)\) and \((0,3)\).
Step 2: First quadrant and below the line: corners \(O(0,0)\), \(A(3,0)\), \(B(0,3)\).
Step 3: Evaluate \(Z = 2x + y\):
\(Z(O) = 0\), \(Z(A) = 6\), \(Z(B) = 3\).
Step 4: Maximum is \(Z = 6\) at \(A(3,0)\).
Step 5: Iso-profit check: \(Z = 2x + y\). At \(Z = 6\), line \(2x + y = 6\) passes through \(A(3,0)\) and \((0,6)\); moving outward from origin, the last point of the region is \(A\).
Fig. 35.2 — Feasible region of Problem 2; iso-profit line \(2x+y=6\) touches \(A(3,0)\)

✅ \(x = 3,\; y = 0,\; Z_{\max} = 6\).

Problem 3. Find the maximum value of \(Z = 2x_1 + 3x_2\), subject to \(x_1 + x_2 \le 30,\; x_2 \ge 3,\; x_2 \le 12,\; x_1 - x_2 \ge 0,\; 0 \le x_1 \le 20\). CO3
✅ Step-by-step:
Step 1: Corner points of the feasible pentagon (from Lecture 34 Fig. 34.3): \(A(3,3)\), \(B(12,12)\), \(C(18,12)\), \(D(20,10)\), \(E(20,3)\).
Step 2: Evaluate \(Z = 2x_1 + 3x_2\):
\(Z(A) = 15\), \(Z(B) = 60\), \(Z(C) = 72\), \(Z(D) = 70\), \(Z(E) = 49\).
Step 3: Maximum at \(C(18,12)\): \(Z = 72\).
Step 4: Iso-profit check: The line \(2x_1 + 3x_2 = 72\) passes through \(C(18,12)\) and touches the pentagon only at this vertex — the iso-profit line is not parallel to any edge. Unique optimum.
Fig. 35.3 — Feasible pentagon of Problem 3; optimum at \(C(18,12)\), \(Z_{\max}=72\)

✅ \(x_1 = 18,\; x_2 = 12,\; Z_{\max} = 72\).

Problem 4. Find the maximum of \(z = 5x - 2y\), subject to \(2x + 3y \ge 1,\; x, y \ge 0\). CO3
✅ Step-by-step:
Step 1: The feasible region \(2x + 3y \ge 1,\; x,y \ge 0\) is unbounded (see Fig. 34.2).
Step 2: Corner points: \(A(1/2, 0)\) and \(B(0, 1/3)\).
Step 3: Evaluate \(z\): \(z(A) = 5/2 = 2.5\), \(z(B) = -2/3 \approx -0.667\).
Step 4: The objective \(z = 5x - 2y\) can be made arbitrarily large by taking \(x\) large with \(y\) fixed. So the maximum does not exist — the LP is unbounded.

✅ The problem has an unbounded solution (no finite maximum).

📋 5. Quick Summary
  • Extreme point enumeration: evaluate \(Z\) at every corner; pick largest.
  • Iso-profit method: slide the line \(c_1x_1+c_2x_2=Z\) outward; last touch = optimum.
  • Parallel edge: if iso-profit line coincides with an edge, multiple optima along that edge.
  • Unbounded region: maximum may not exist → LP unbounded.
