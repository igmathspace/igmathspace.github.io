📐 2. Applications of Numerical Integration
📌 Common Engineering Applications
  • Area under curves: \(A = \int_a^b y\,dx\) — used in surveying, physics, and economics.
  • Volume of solids of revolution: \(V = \pi \int_a^b y^2\,dx\) — used in mechanical and civil engineering.
  • Work done by a variable force: \(W = \int_a^b F(x)\,dx\).
  • Distance travelled from velocity data: \(s = \int_{t_1}^{t_2} v(t)\,dt\).
  • Centre of gravity, moment of inertia, and other centroid calculations.
  • Total charge/current from varying electrical signals.

When the integrand is known only from tabulated experimental data, these integrals must be evaluated numerically using the trapezoidal or Simpson's rules.

📏 3. Choosing the Right Rule

Use the Trapezoidal Rule when:

  • The number of subintervals \(n\) is any positive integer (odd or even).
  • The data has natural limits and \(n\) cannot easily be made even.
  • A quick, rough estimate is sufficient.

Use Simpson's 1/3 Rule when:

  • The number of subintervals \(n\) is even.
  • Higher accuracy is required (the error is \(O(h^4)\) versus \(O(h^2)\) for the trapezoidal rule).
  • The function is smooth (continuous fourth derivative).

Problem 1 (B6). A curve is given by the points \((0, 23)\), \((0.5, 19)\), \((1.0, 14)\), \((1.5, 11)\), \((2.0, 12.5)\), \((2.5, 16)\). Estimate the area bounded by the curve, the \(x\)-axis and the extreme ordinates using the trapezoidal rule. CO4
✅ Solution:
Arrange the data with \(h = 0.5\):
\(x\)00.51.01.52.02.5
\(y\)2319141112.516
Apply the trapezoidal rule:
\[ A \approx \frac{0.5}{2}\Big[ 23 + 2(19 + 14 + 11 + 12.5) + 16 \Big] = 0.25(152) = 38 \]

✅ Area \(\approx 38\) square units.

Problem 2 (B2). A solid of revolution is formed by rotating about the \(x\)-axis the area between the \(x\)-axis, the lines \(x = 0\) and \(x = 1\), and a curve through the points \((0, 1)\), \((0.25, 0.9896)\), \((0.5, 0.9589)\), \((0.75, 0.9089)\), \((1, 0.8415)\). Estimate the volume using Simpson's 1/3 rule, giving the answer to three decimal places. CO4
✅ Solution:
The volume is \(V = \pi \int_0^1 y^2\,dx\). First tabulate \(y^2\):
\(x\)00.250.500.751.00
\(y^2\)1.00000.97930.91950.82610.7081
Here \(n = 4\) (even) and \(h = 0.25\). Apply the composite Simpson's 1/3 rule:
\[ \int_0^1 y^2\,dx \approx \frac{0.25}{3}\Big[ (1.0000 + 0.7081) + 4(0.9793 + 0.8261) + 2(0.9195) \Big] \]
\[ = \frac{0.25}{3}\Big[ 1.7081 + 7.2216 + 1.8390 \Big] = \frac{0.25}{3}(10.7687) \approx 0.8974 \]
Therefore, the volume is \(V = \pi \times 0.8974 \approx 2.8192\).

✅ Volume \(\approx 2.819\) cubic units.

Problem 3 (B1). Find, from the following table, the area bounded by the curve and the \(x\)-axis from \(x = 7.47\) to \(x = 7.52\).
Table: \(x\): 7.47, 7.48, 7.49, 7.50, 7.51, 7.52; \(f(x)\): 1.93, 1.95, 1.98, 2.01, 2.03, 2.06. CO4
✅ Solution:
The step size is \(h = 0.01\). With \(n = 5\) (odd), Simpson's 1/3 rule cannot be used directly, so we use the trapezoidal rule:
\[ A \approx \frac{0.01}{2}\Big[ 1.93 + 2(1.95 + 1.98 + 2.01 + 2.03) + 2.06 \Big] \]
\[ = 0.005\Big[ 1.93 + 15.94 + 2.06 \Big] = 0.005 \times 19.93 = 0.09965 \]

✅ Area \(\approx 0.0997\) square units.

Problem 4 (C2). Estimate \(\int_1^3 \frac{1}{x}\,dx\) by Simpson's rule with 4 strips and 8 strips. Determine the error in each case. CO4
✅ Solution:
The exact value is \(\ln 3 \approx 1.0986\).
With 4 strips (\(h = 0.5\)): the ordinates are \(1.0000, 0.6667, 0.5000, 0.4000, 0.3333\).
\[ I \approx \frac{0.5}{3}\Big[ (1.0000 + 0.3333) + 4(0.6667 + 0.4000) + 2(0.5000) \Big] \approx 1.1000 \]
Error \(\approx 0.0014\).
With 8 strips (\(h = 0.25\)): the ordinates are \(1.0000, 0.8000, 0.6667, 0.5714, 0.5000, 0.4444, 0.4000, 0.3636, 0.3333\).
\[ I \approx \frac{0.25}{3}\Big[ (1.0000 + 0.3333) + 4(2.1794) + 2(1.5667) \Big] \approx 1.0987 \]
Error \(\approx 0.0001\).

✅ Halving \(h\) reduced the error by roughly a factor of 16, confirming the \(O(h^4)\) error behaviour.

Problem 5 (B5). Evaluate \(\int_{-2}^{2} \frac{x}{5 + 2x}\,dx\) using the trapezoidal rule with five ordinates. CO4
✅ Solution:
Five ordinates means \(n = 4\) over \([-2, 2]\), so \(h = 1\). The ordinates are:
\(x\)−2−1012
\(y\)−2.0000−0.333300.14290.2222
Apply the trapezoidal rule:
\[ I \approx \frac{1}{2}\Big[ -2 + 2(-0.3333 + 0 + 0.1429) + 0.2222 \Big] \]
\[ = 0.5\Big[ -2 - 0.3808 + 0.2222 \Big] = 0.5 \times (-2.1586) \approx -1.0793 \]

✅ \(I \approx -1.0793\).

📖 5. Module IV Review — Complete Summary

🔢 Root Finding (Bisection)

  • Requires a bracketing interval \([a,b]\) with \(f(a)f(b) < 0\).
  • Iteration: \(x_{n+1} = (a+b)/2\).
  • Linear convergence, but always converges.
  • Number of iterations: \(n \ge \log\big((b-a)/\epsilon\big)/\log 2\).

⚡ Root Finding (Newton–Raphson)

  • Iteration: \(x_{n+1} = x_n - f(x_n)/f'(x_n)\).
  • Quadratic convergence for simple roots.
  • Fails if \(f'(x_n) = 0\) or is very small.
  • For multiple roots, use \(x_{n+1} = x_n - p\,f/f'\).

📏 Numerical Integration (Trapezoidal)

  • \(I \approx \frac{h}{2}\big[y_0 + 2(y_1+\dots+y_{n-1}) + y_n\big]\).
  • Error \(O(h^2)\), exact for linear functions.
  • Works for any \(n\).

📐 Numerical Integration (Simpson's 1/3)

  • \(I \approx \frac{h}{3}\big[(y_0+y_n) + 4(\text{odd } y_i) + 2(\text{even } y_i)\big]\).
  • Error \(O(h^4)\), exact for cubics.
  • Requires \(n\) even.
