📖 Topic: Standard Form of LPP – Slack, Surplus, Artificial Variables
📚 Textbook: Operations Research – Gupta & Hira | §2.12-2 (Standard Form)
👨‍🏫 Faculty: Gafoor I 🎯 CO3: Understand the standard form and how to reach it ⏱️ Lecture duration: 1 Hour
🎯 1. Learning Outcomes (CO3)
  • Define the standard form of an LPP and list its four characteristics
  • Introduce slack variables in \((\le)\) constraints and surplus variables in \((\ge)\) constraints
  • Introduce artificial variables to handle \((\ge)\) and \((=)\) constraints
  • Convert any LPP to standard form using elementary transformations
📌 2. Definition of Standard Form
Definition

The general LPP can always be put in the following form, called the standard form:

\[ \begin{aligned} \text{Maximise (or minimise) } Z &= \sum_{j=1}^{n} c_j x_j\\ \text{subject to } \sum_{j=1}^{n} a_{ij} x_j &= b_i, \quad i = 1, 2, \dots, m,\\ x_j &\ge 0, \quad j = 1, 2, \dots, n,\\ b_i &\ge 0, \quad i = 1, 2, \dots, m. \end{aligned} \]
📐 3. Four Characteristics of Standard Form
The four conditions
  1. All variables are non-negative.
  2. The right-hand side of each constraint is non-negative (\(b_i \ge 0\)).
  3. All constraints are expressed as equations (with the \(=\) sign).
  4. The objective function may be of maximisation or minimisation type.
🔄 4. Slack, Surplus and Artificial Variables
Slack variable (for \(\le\) constraints)

A non-negative variable added to the left-hand side of a \((\le)\) constraint to convert it into an equation:

\[ a_1 x_1 + a_2 x_2 \le b \;\Longrightarrow\; a_1 x_1 + a_2 x_2 + s_1 = b, \quad s_1 \ge 0. \]

\(s_1\) represents the unused (idle) amount of the resource. Its contribution to the objective is zero (zero profit or zero cost).

Surplus variable (for \(\ge\) constraints)

A non-negative variable subtracted from the left-hand side of a \((\ge)\) constraint to convert it into an equation:

\[ p_1 x_1 + p_2 x_2 \ge q \;\Longrightarrow\; p_1 x_1 + p_2 x_2 - s_2 = q, \quad s_2 \ge 0. \]

\(s_2\) represents the surplus of the left side over the right side (i.e. a negative slack). Its contribution to the objective is also zero.

Artificial variable (for \(\ge\) and \(=\) constraints)

A fictitious non-negative variable added to \((\ge)\) and \((=)\) constraints to provide an initial basic feasible solution:

\[ p_1 x_1 + p_2 x_2 - s_2 + A_1 = q, \quad A_1 \ge 0. \]

Artificial variables have no physical meaning. They are penalised heavily in the objective (\(-M\) per unit for maximisation, \(+M\) per unit for minimisation) so that the simplex drives them to zero.

⚠️ CAUTION! Slack and surplus variables are real admissible variables — they are treated in the model just like the decision variables. Artificial variables are fictitious — they are added merely to bootstrap the simplex and must eventually leave the basis.
📊 5. Elementary Transformations to Standard Form
Rule 1 — Unrestricted variables

If \(x_j\) is unrestricted, put \(x_j = x_j' - x_j''\) with \(x_j', x_j'' \ge 0\).

Rule 2 — Negative RHS

If \(b_i < 0\), multiply both sides by \(-1\) (this reverses the direction of the inequality).

Rule 3 — Inequality → equality

Add a slack to \((\le)\); subtract a surplus from \((\ge)\). Equality constraints require neither.

Rule 4 — Artificial variables

Add a non-negative artificial variable to every \((\ge)\) and \((=)\) constraint that has no natural unit column (i.e. no slack with +1 coefficient).

Problem 1. Define the objective function of a linear programming problem. CO3
✅ Answer:
The objective function of a linear programming problem is the mathematical expression in the decision variables \(x_1, x_2, \ldots, x_n\) that measures the effectiveness of the decision — typically profit, revenue, cost, or loss.
It is a linear function of the form \(Z = c_1 x_1 + c_2 x_2 + \cdots + c_n x_n\), where the constants \(c_j\) are called the objective function coefficients.
The objective function is maximised (for profit/revenue) or minimised (for cost/loss) subject to the constraints of the problem.

✅ It defines "what is to be optimised".

Problem 2. Define a slack variable with an example. CO3
✅ Answer:
A slack variable is a non-negative variable added to the left-hand side of a \((\le)\) constraint to convert it into an equation.
Example: The constraint \(2x_1 + 3x_2 \le 10\) becomes
\(2x_1 + 3x_2 + s_1 = 10, \quad s_1 \ge 0,\)
where \(s_1\) is the slack variable, representing the amount of the resource that remains unused.
Slack variables contribute zero to the objective function.

✅ Slack = "unused" capacity.

Problem 3. Define a surplus variable with an example. CO3
✅ Answer:
A surplus variable is a non-negative variable subtracted from the left-hand side of a \((\ge)\) constraint to convert it into an equation.
Example: \(2x_1 + 3x_2 \ge 10\) becomes
\(2x_1 + 3x_2 - s_2 = 10, \quad s_2 \ge 0,\)
where \(s_2\) is the surplus variable, representing the amount by which the LHS exceeds the RHS.
It is also called the "negative slack". Its contribution to the objective is zero.

✅ Surplus = "excess over minimum required".

Problem 4. Express the following LPP in standard form: Maximise \(Z = 7x_1 + 5x_2\), subject to \(2x_1 + 3x_2 \le 20,\; 3x_1 + x_2 \ge 10,\; x_1, x_2 \ge 0\). CO3
✅ Step-by-step:
Step 1: Objective is already maximisation.
Step 2: Constraint 1 is \((\le)\); add a slack variable \(s_1 \ge 0\): \(2x_1 + 3x_2 + s_1 = 20\).
Step 3: Constraint 2 is \((\ge)\); subtract a surplus \(s_2 \ge 0\): \(3x_1 + x_2 - s_2 = 10\).
Step 4: To start the simplex, we need an artificial variable \(A_1 \ge 0\) in the second constraint: \(3x_1 + x_2 - s_2 + A_1 = 10\).
Step 5: In the objective, the artificial variable gets a large penalty \(-M\) per unit (since we are maximising).
Final standard form:
\(\begin{aligned}\text{Maximise } Z = &\; 7x_1 + 5x_2 + 0s_1 + 0s_2 - M A_1\\\text{s.t. } & 2x_1 + 3x_2 + s_1 = 20,\\ & 3x_1 + x_2 - s_2 + A_1 = 10,\\ & x_1, x_2, s_1, s_2, A_1 \ge 0.\end{aligned}\)

✅ 2 variables → 5 admissible variables (2 decision + 1 slack + 1 surplus + 1 artificial).

Problem 5. Express the following in standard form: Maximise \(Z = 3x_1 + 2x_2 + 5x_3\), subject to \(2x_1 + 3x_2 - 2x_3 \le 40,\; 4x_1 - 2x_2 + x_3 \le 24,\; x_1 - 5x_2 - 6x_3 \ge 2,\; x_1 \ge 0\). CO3
✅ Step-by-step:
Step 1: Objective is maximisation.
Step 2: \(x_1 \ge 0\) but \(x_2, x_3\) are unrestricted. Put \(x_2 = x_2' - x_2''\), \(x_3 = x_3' - x_3''\) with \(x_2', x_2'', x_3', x_3'' \ge 0\).
Step 3: Substitute \(x_2 = x_2' - x_2''\) and \(x_3 = x_3' - x_3''\) in all expressions:
Objective: \(Z = 3x_1 + 2x_2' - 2x_2'' + 5x_3' - 5x_3''\).
Constraint 1: \(2x_1 + 3x_2' - 3x_2'' - 2x_3' + 2x_3'' \le 40\).
Constraint 2: \(4x_1 - 2x_2' + 2x_2'' + x_3' - x_3'' \le 24\).
Constraint 3: \(x_1 - 5x_2' + 5x_2'' - 6x_3' + 6x_3'' \ge 2\).
Step 4: Add slack to \((\le)\) constraints and surplus + artificial to the \((\ge)\) constraint:
Constraint 1 + \(s_1 = 40\); Constraint 2 + \(s_2 = 24\); Constraint 3 − \(s_3\) + \(A_1 = 2\).
Final standard form:
\(\begin{aligned}\text{Maximise } Z = &\; 3x_1 + 2x_2' - 2x_2'' + 5x_3' - 5x_3'' + 0s_1 + 0s_2 + 0s_3 - M A_1\\\text{s.t. } & 2x_1 + 3x_2' - 3x_2'' - 2x_3' + 2x_3'' + s_1 = 40,\\ & 4x_1 - 2x_2' + 2x_2'' + x_3' - x_3'' + s_2 = 24,\\ & x_1 - 5x_2' + 5x_2'' - 6x_3' + 6x_3'' - s_3 + A_1 = 2,\\ & \text{all variables} \ge 0.\end{aligned}\)

✅ 3 original variables → 8 admissible variables (1 + 2 + 2 decision + 2 slack + 1 surplus + 1 artificial).

Problem 6. Find the initial basic feasible solution of the LPP: Maximise \(Z = 3x_1 + 4x_2\), subject to \(x_1 + x_2 \le 450,\; 2x_1 + x_2 \le 600,\; x_1, x_2 \ge 0\). CO3
✅ Step-by-step:
Step 1: Introduce slack variables \(s_1, s_2 \ge 0\) for the two \((\le)\) constraints.
Standard form:
Maximise \(Z = 3x_1 + 4x_2 + 0s_1 + 0s_2\)
s.t. \(x_1 + x_2 + s_1 = 450\),
\(2x_1 + x_2 + s_2 = 600\),
\(x_1, x_2, s_1, s_2 \ge 0\).
Step 2: Set the decision variables to zero: \(x_1 = 0, x_2 = 0\).
Step 3: Then \(s_1 = 450\) (slack of M₁) and \(s_2 = 600\) (slack of M₂).
Step 4: This is the initial basic feasible solution: \(x_1 = 0, x_2 = 0, s_1 = 450, s_2 = 600\), with \(Z = 0\).
Step 5: The basic variables are \(s_1\) and \(s_2\); the non-basic variables are \(x_1\) and \(x_2\). Physically, neither product is produced; all capacity is idle; profit is zero.

✅ I.B.F.S.: \((x_1, x_2, s_1, s_2) = (0, 0, 450, 600)\), \(Z = 0\).

📋 8. Quick Summary
  • Standard form: all constraints are equations; all variables non-negative; RHS non-negative; objective may be max or min.
  • Slack variable: + on \((\le)\), represents unused capacity, contributes 0 to objective.
  • Surplus variable: − on \((\ge)\), represents excess over minimum required, contributes 0 to objective.
  • Artificial variable: + on \((\ge)\) and \((=)\), fictitious, penalised with \(-M\) (max) or \(+M\) (min); drives to zero in final solution.
  • Reformulated LPP: the standard-form problem after introducing slack/surplus/artificial variables — ready for the simplex tableau.
