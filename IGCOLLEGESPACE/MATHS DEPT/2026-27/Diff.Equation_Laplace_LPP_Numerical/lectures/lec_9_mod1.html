📚 Kreyszig §1.5 (Linear ODEs) – First-Order Linear Differential Equations
📌 Definition of Linear ODE

A first-order ODE is said to be linear if it can be brought into the form:

\[ y' + p(x)y = r(x) \]

and nonlinear if it cannot be brought into this form.

Key Features:
  • The equation is linear in both the unknown function \(y\) and its derivative \(y' = dy/dx\)
  • \(p(x)\) and \(r(x)\) may be any given functions of \(x\)
  • If the independent variable is time, we write \(t\) instead of \(x\)
📐 Standard Form: If the first term is \(f(x)y'\) (instead of \(y'\)), divide the equation by \(f(x)\) to get the standard form with \(y'\) as the first term.

Example: \(y' \cos x + y \sin x = x\) is a linear ODE. Its standard form is: \[ y' + y \tan x = x \sec x \]
Terminology:
  • \(r(x)\) is called the input
  • \(y(x)\) is called the output or the response to the input
📝 Examples of Linear ODEs

The following table shows various linear ODEs with their standard form and identified \(p(x)\) and \(q(x)\):

Example 1: \(y' + 2xy = e^{-x^2}\)
\(p(x) = 2x\), \(q(x) = e^{-x^2}\)
Example 2: \(y' - 3y = \sin x\)
\(p(x) = -3\), \(q(x) = \sin x\)
Example 3: \(y' + \frac{1}{x}y = x^2\)
\(p(x) = \frac{1}{x}\), \(q(x) = x^2\)
Example 4: \(y' + y\tan x = \sec x\)
\(p(x) = \tan x\), \(q(x) = \sec x\)
Example 5: \(y' - 2xy = x\)
\(p(x) = -2x\), \(q(x) = x\)
Example 6: \(y' + 3y = e^{2x}\)
\(p(x) = 3\), \(q(x) = e^{2x}\)
Example 7: \(y' - \frac{2}{x}y = x^3\)
\(p(x) = -\frac{2}{x}\), \(q(x) = x^3\)
Example 8: \(y' + y\cos x = \sin 2x\)
\(p(x) = \cos x\), \(q(x) = \sin 2x\)
Example 9: \(y' + \frac{3}{x}y = \ln x\)
\(p(x) = \frac{3}{x}\), \(q(x) = \ln x\)
Example 10: \(y' + y = e^{-x}\cos x\)
\(p(x) = 1\), \(q(x) = e^{-x}\cos x\)
🏷️ Homogeneous Linear ODE

When \(r(x) = 0\) for all \(x\) in the interval, the ODE becomes:

\[ y' + p(x)y = 0 \]

This is called homogeneous.

Solution Steps:
1 Separate variables: \(\frac{dy}{y} = -p(x)dx\)
2 Integrate: \(\ln|y| = -\int p(x)dx + c\)
3 Take exponents: \(y(x) = ce^{-\int p(x)dx}\)
Result: \[ \boxed{y(x) = ce^{-\int p(x)dx}} \]
🏷️ Nonhomogeneous Linear ODE

When \(r(x)\) is not everywhere zero, the ODE is called nonhomogeneous:

\[ y' + p(x)y = r(x) \]
Solution Steps (Integrating Factor Method):
1 Compute \(h = \int p(x)dx\)
2 Find integrating factor: \(F = e^h\)
3 Multiply the ODE by \(F\): \((e^h y)' = r e^h\)
4 Integrate: \(e^h y = \int r e^h dx + c\)
5 Divide by \(e^h\): \(y = e^{-h}(\int e^h r dx + c)\)
Result: \[ \boxed{y(x) = e^{-h} \left( \int e^h r \, dx + c \right), \quad h = \int p(x)dx} \]
📐 Structure of the Solution

The solution formula can be written as:

\[ y(x) = e^{-h}\int e^{h} r\,dx + ce^{-h} \]
💡 Interpretation: \[ \text{Total Output} = \text{Response to the Input } r + \text{Response to the Initial Data} \]
🚀 Shortcut Method for Solving Linear ODEs

📋 Step-by-Step Shortcut

1 Rewrite the equation in the form \(y' + p(x)y = q(x)\) and identify \(p(x)\) and \(q(x)\) with their signs.
2 Find the Integrating Factor:
\[ \boxed{\text{I.F} = e^{\int p(x)\,dx}} \]
3 Finalize the solution using the ready-made frame:
\[ \boxed{y \times \text{I.F} = \int (q(x) \times \text{I.F})\,dx} \]
📝 Note: Here \(y\) is the dependent variable and \(x\) is the independent variable. As per the variable names, the solution frame has to change accordingly.

For example, if the equation is in terms of \(t\): \[ \frac{dy}{dt} + p(t)y = q(t) \] Then: \[ \boxed{y \times \text{I.F} = \int (q(t) \times \text{I.F})\,dt} \] where \(\text{I.F} = e^{\int p(t)\,dt}\).
📋 Summary
Type Form Solution
Homogeneous Linear \(y' + p(x)y = 0\) \(y = ce^{-\int p(x)dx}\)
Nonhomogeneous Linear \(y' + p(x)y = r(x)\) \(y = e^{-h}(\int e^h r\,dx + c)\), \(h = \int p(x)dx\)
📌 Quick Reference: The Shortcut
\[ \boxed{\text{I.F} = e^{\int p(x)\,dx}} \]
\[ \boxed{y \times \text{I.F} = \int (q(x) \times \text{I.F})\,dx} \]
⚠️ Remember: Always identify \(p(x)\) and \(q(x)\) with their correct signs before applying the formula.
⚠️ Common Mistakes to Avoid
Mistake Correction
Forgetting to divide by the coefficient of \(y'\) Always rewrite as \(y' + p(x)y = q(x)\)
Incorrect sign of \(p(x)\) Pay careful attention to signs
Omitting the constant of integration \(c\) Always include \(c\) in the final solution
Forgetting to multiply \(q(x)\) by I.F before integrating Formula: \(y \times \text{I.F} = \int (q \times \text{I.F})\,dx\)
Not changing the solution frame when variables change If equation is in \(t\), use \(t\) instead of \(x\)
