🎯 1. Learning Outcomes (CO3)
  • Apply the full 9-step simplex algorithm to solve a maximisation LPP
  • Construct the initial tableau, iterate until the optimality test passes, and read off the optimum
  • Interpret the final tableau (basic variables, \(Z_{\max}\), slack values)
  • Detect unbounded solutions from the key column
📐 2. The Simplex Algorithm — 9 Steps
Step 1 — Check the objective type

Verify that the objective function is of the maximisation type. If it is a minimisation problem, convert it to maximisation by multiplying the objective by \(-1\).

Step 2 — Convert to standard form

Introduce slack (for \(\le\)) or surplus (for \(\ge\)) variables and convert all constraints to equations.

Step 3 — Find the initial basic feasible solution (IBFS)

Identify a starting set of basic variables. For a standard \(\le\)-type LPP, the slack variables form the initial basis, with the decision variables set to zero.

Step 4 — Construct the initial simplex tableau

Build the tableau using the layout below:

  • Column 1: Basic variables
  • Column 2: Cost of basic variables (\(c_B\))
  • Column 3: Value of basic variable (\(x_B\))
  • Columns 4 to second-last: All variables, including slack/surplus
  • Last column: Ratio (\(x_{B_j} / x_{j}\))

The top row of the body holds the cost coefficients \(c_j\) of every variable.

Step 5 — Compute net evaluations

Compute \[ Z_j = \sum_i c_{Bi}\, a_{ij}, \qquad \text{net evaluation} = Z_j - c_j \] where \(c_{Bi}\) are the cost coefficients of the basic variables, and \(a_{ij}\) are the tableau entries in the \(j\)-th variable column.

Step 6 — Optimality check

If all net evaluations \(Z_j - c_j\) are non-negative, the current solution is optimal — stop. Otherwise go to Step 7.

Step 7 — Entering variable

Find the column with the most negative net evaluation \(Z_j - c_j\). The variable in that column enters the basis. That column is called the key column.

Step 8 — Leaving variable (ratio test)

For each row, compute \[ \text{Ratio} = \frac{x_{B_j}}{x_j} \] where \(x_{B_j}\) is the entry in the value-of-basic-variable column (column 3) and \(x_j\) is the corresponding entry in the key column. Only positive entries of \(x_j\) are used. The row with the smallest non-negative ratio is the key row; its basic variable leaves the basis. The intersection of the key row and key column is the key element.

If all entries of the key column are non-positive, no ratio can be computed — the solution is unbounded; stop.

Step 9 — Pivot to the next tableau

Construct the next tableau using row operations:

  • Divide the key row by the key element so that the key element becomes \(1\).
  • For every other row, subtract (appropriate multiple of the new key row) so that the key column entry becomes \(0\).
  • Update the basis column, \(c_B\), and the \(x_B\) column.
  • Return to Step 5.

📋 5. Quick Summary
  • Steps 1–4: convert to max, introduce slacks/surplus, find IBFS, build initial tableau.
  • Steps 5–6: compute \(Z_j - c_j\), check optimality.
  • Step 7: most negative \(Z_j - c_j\) → entering variable.
  • Step 8: minimum \(x_{B_j}/x_j\) over positive key-column entries → leaving variable; all non-positive means unbounded.
  • Step 9: pivot (key row → 1, key column → zeros) and repeat.
