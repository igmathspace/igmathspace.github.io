🎯 1. Learning Outcomes (CO3)
  • Apply the iso-cost line (or corner-point) method for minimisation LPPs
  • Recognise and describe the three special cases: unbounded solution, infeasible solution and multiple (alternate) optimal solutions
  • Draw conclusions about the LPP from the geometry of the feasible region
  • Verify uniqueness, boundedness and feasibility from the graphical picture
📐 2. Minimisation by Graphical Method
Procedure
  1. Formulate the LPP and plot the constraints.
  2. Identify the feasible region (usually \(a_1 x_1 + a_2 x_2 \ge b\) and \(x_j \ge 0\), so the region extends outward from the line).
  3. List the corner points.
  4. Evaluate \(Z\) at every corner (extreme-point enumeration) and pick the smallest.
  5. Alternatively, use the iso-cost line: set \(Z = 0\) and slide the line towards the origin; the last point of the feasible region touched gives the minimum.
⚠️ CAUTION! For a minimisation LPP with \(\ge\)-type constraints the feasible region is often unbounded. The minimum is still finite provided the iso-cost line "last touch" exists. If the iso-cost line can be pushed arbitrarily towards the origin without meeting the region, the problem is infeasible; if it can be pushed to \(-\infty\), the problem has no finite minimum (unbounded below).
📊 3. Special Cases
Case A — Multiple (alternate) optimal solutions

When the iso-profit/iso-cost line is parallel to one of the binding constraints, every point on that edge of the feasible region is optimal. Two conditions:

  1. The objective function is parallel to a constraint forming the boundary of the feasible region.
  2. That constraint is active at the optimum (both sides equal).
Case B — Unbounded solution

The feasible region is not bounded in some direction, and the objective can be made arbitrarily large (maximisation) or arbitrarily small (minimisation) within the region. The problem has no finite optimum.

Case C — Infeasible solution

The constraints are inconsistent — there is no point \((x_1, x_2)\) satisfying all of them. Infeasibility depends only on the constraints, not on the objective function.

Case D — Single (unique) solution

When the constraints reduce the feasible region to a single point — e.g. the intersection of two equality constraints with matching feasibility — the LPP has a unique solution (the point itself).

Problem 1 (Minimisation). Find the minimum value of \(z = 5x - 2y\), subject to \(2x + 3y \ge 1,\; x, y \ge 0\). CO3
✅ Step-by-step:
Step 1: Plot \(2x + 3y = 1\). Intercepts: \((1/2, 0)\) and \((0, 1/3)\).
Step 2: Since the constraint is \(\ge\), the feasible region lies above the line in the first quadrant — an unbounded region.
Step 3: Only two corner points: \(A(1/2, 0)\) and \(B(0, 1/3)\).
Step 4: Evaluate \(z = 5x - 2y\): \(z(A) = 5/2 = 2.5\), \(z(B) = -2/3 \approx -0.667\).
Step 5: Since \(z\) is linear and the region is unbounded above, the minimum occurs at a corner. Checking the boundary \(y = (1-2x)/3\): \(z = 5x - 2(1-2x)/3 = (19x - 2)/3\), which increases with \(x \ge 0\), so the minimum is at \(B\).
Fig. 36.1 — Unbounded feasible region; iso-cost line touches \(B(0, \tfrac{1}{3})\) giving \(z_{\min} = -2/3\)

✅ \(x = 0,\; y = 1/3,\; z_{\min} = -2/3\). The region is unbounded but the minimum is finite.

Problem 2 (Bounded minimisation). Find the minimum value of \(z = -x_1 + 2x_2\), subject to \(-x_1 + 3x_2 \le 10,\; x_1 + x_2 \le 6,\; x_1 - x_2 \le 2,\; x_1, x_2 \ge 0\). CO3
✅ Step-by-step:
Step 1: Plot the three lines: \(-x_1 + 3x_2 = 10\), \(x_1 + x_2 = 6\), \(x_1 - x_2 = 2\). All \(\le\)-type, so feasible region is towards origin.
Step 2: Corner points of feasible region: \(O(0,0)\), \(A(0, 10/3)\), \(B(2,4)\) (intersection of lines 1 & 2), \(C(4,2)\) (lines 2 & 3), \(D(2,0)\).
Step 3: Evaluate \(z = -x_1 + 2x_2\):
\(z(O) = 0\), \(z(A) = 20/3\), \(z(B) = 6\), \(z(C) = 0\), \(z(D) = -2\).
Step 4: Minimum is \(z = -2\) at \(D(2,0)\).
Fig. 36.2 — Feasible pentagon of Problem 2; minimum at \(D(2,0)\) with \(z = -2\)

✅ \(x_1 = 2,\; x_2 = 0,\; z_{\min} = -2\).

Problem 3 (Alternate optima). Maximise \(Z = 2x_1 + 3x_2\), subject to \(x_1 + x_2 \le 30,\; x_2 \ge 3,\; x_2 \le 12,\; x_1 - x_2 \ge 0,\; 0 \le x_1 \le 20\). What is the optimal \(Z\)? CO3
✅ Step-by-step:
Step 1: Feasible pentagon corners: \(A(3,3)\), \(B(12,12)\), \(C(18,12)\), \(D(20,10)\), \(E(20,3)\) (see Fig. 35.3 of Lecture 35).
Step 2: Evaluate \(Z = 2x_1 + 3x_2\) at each corner:
\(Z(A) = 15\), \(Z(B) = 60\), \(Z(C) = 72\), \(Z(D) = 70\), \(Z(E) = 49\).
Step 3: The unique maximum is \(Z = 72\) at \(C(18,12)\) — the iso-profit line \(2x_1 + 3x_2 = 72\) is not parallel to any edge of the pentagon, so the optimum is unique.
Step 4: If the objective had instead been \(Z = x_1 + x_2\) (parallel to \(x_1 + x_2 = 30\)), then both \(B\) and \(C\) would give \(Z = 24\) and the whole edge \(BC\) would be optimal.

✅ \(x_1 = 18,\; x_2 = 12,\; Z_{\max} = 72\), unique optimum. (If \(Z = x_1 + x_2\), multiple optima would occur on edge \(BC\).)

Problem 4 (Infeasible solution). Maximise \(Z = 3x_1 + 4x_2\), subject to \(x_1 - x_2 \ge 0,\; 2.5x_1 - x_2 \le -3,\; x_1, x_2 \ge 0\). Show that the solution does not exist. CO3
✅ Step-by-step:
Step 1: \(x_1 - x_2 \ge 0\) ⇔ \(x_1 \ge x_2\) — the region below the line \(x_2 = x_1\).
Step 2: \(2.5x_1 - x_2 \le -3\) ⇔ \(x_2 \ge 2.5x_1 + 3\) — the region above the line \(x_2 = 2.5x_1 + 3\) (whose \(x_2\)-intercept is \(3\)).
Step 3: But for any \(x_1 \ge 0\), the second constraint forces \(x_2 \ge 3\), while the first forces \(x_2 \le x_1\), hence \(x_1 \ge x_2 \ge 3\). So \(x_1 \ge 3\).
Step 4: Yet the second constraint also requires \(x_2 \ge 2.5x_1 + 3 \ge 2.5(3) + 3 = 10.5\). Combined with the first, \(x_1 \ge x_2 \ge 10.5\). But then we would need \(x_2 \ge 2.5(10.5) + 3 = 29.25\), and so on. The two constraints are inconsistent — one wants \(x_2 \le x_1\), the other \(x_2\) much larger than \(x_1\).
Step 5: The feasible region in the first quadrant is empty. Hence the LPP has no feasible solution.
Fig. 36.3 — Infeasible LPP; the two half-planes do not overlap in the first quadrant

✅ No feasible solution exists — the constraint set is inconsistent.

Problem 5 (Unbounded solution). Maximise \(Z = -x_1 + 2x_2\), subject to \(x_1 - x_2 \le -1,\; -0.5x_1 + x_2 \le 2,\; x_1, x_2 \ge 0\). CO3
✅ Step-by-step:
Step 1: Rewrite the first constraint: \(-x_1 + x_2 \ge 1\), i.e. \(x_2 \ge x_1 + 1\).
Step 2: Second constraint: \(x_2 \le 0.5x_1 + 2\).
Step 3: The feasible region is the strip between the lines \(x_2 = x_1 + 1\) and \(x_2 = 0.5x_1 + 2\), for \(x_1 \ge 0\). It extends indefinitely to the right (as \(x_1\) grows, both bounds grow, and the strip is unbounded).
Step 4: Corners of the feasible region: \(A(0,1)\), \(B(0,2)\), \(C(2,3)\) (intersection of the two lines). \(Z(A) = 2\), \(Z(B) = 4\), \(Z(C) = -2+6 = 4\).
Step 5: However, \(Z = -x_1 + 2x_2\). On the upper edge \(x_2 = 0.5x_1 + 2\): \(Z = -x_1 + 2(0.5x_1 + 2) = 4\) — constant! On the lower edge \(x_2 = x_1 + 1\): \(Z = -x_1 + 2(x_1 + 1) = x_1 + 2\), which grows without bound as \(x_1 \to \infty\).
Step 6: Therefore \(Z\) can be made arbitrarily large. The LPP has an unbounded solution — no finite maximum.
Step 7: Note: the feasible region is unbounded and the objective grows unboundedly along one edge. (Contrast with Problem 1, where the region was unbounded but the objective was bounded below by a corner.)

✅ The LPP has an unbounded solution (no finite maximum).

  4. Explain, with an example, when a linear programming problem has (i) multiple optimal solutions, (ii) an unbounded solution, (iii) no feasible solution. (6 marks)
  5. Maximise \(Z = -x_1 + 2x_2\) subject to \(x_1 - x_2 \le -1,\; -0.5x_1 + x_2 \le 2,\; x_1, x_2 \ge 0\). Determine whether the problem has a finite optimum and justify your conclusion graphically. (6 marks)
  6. Give a 2-variable LPP whose feasible region is a single point, and explain why the solution is unique. (6 marks)
📋 6. Quick Summary
  • Minimisation: slide the iso-cost line toward the origin; last touch of the feasible region = minimum.
  • Multiple optima: iso-profit/cost line parallel to an active edge of the feasible region.
  • Unbounded: feasible region unbounded and objective unbounded in some direction → no finite optimum.
  • Infeasible: constraints inconsistent → empty feasible region.
  • Single solution: feasible region reduces to one point.
