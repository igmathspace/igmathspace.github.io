📖 Integrating Factors – Introduction & Proof of three examples
🎯 Introduction: The Idea of Integrating Factors

Consider the non-exact ODE:

\[ -y \, dx + x \, dy = 0 \]

If we multiply by \(1/x^2\), we get an exact equation:

\[ \frac{-y \, dx + x \, dy}{x^2} = -\frac{y}{x^2} \, dx + \frac{1}{x} \, dy = d\left(\frac{y}{x}\right) = 0 \]

Integration gives: \(\frac{y}{x} = C\) → \(y = Cx\).

💡 Definition: A function \(F(x, y)\) that multiplies a non-exact ODE to make it exact is called an integrating factor.
📐 Proof: Three other integrating factors for \(-y \, dx + x \, dy = 0\)

We verify that each of the following is an integrating factor.

1. \(F = \frac{1}{y^2}\)
Multiply the ODE by \(F\): \[ \frac{-y}{y^2} dx + \frac{x}{y^2} dy = -\frac{1}{y} dx + \frac{x}{y^2} dy = 0 \] Let \(M = -\frac{1}{y}\), \(N = \frac{x}{y^2}\).
Check exactness: \(M_y = \frac{1}{y^2}\), \(N_x = \frac{1}{y^2}\) → ✅ exact.
Moreover, \(d(x/y) = \frac{1}{y} dx - \frac{x}{y^2} dy = 0\), so the equation is \( -d(x/y) = 0\). verified
2. \(F = \frac{1}{xy}\)
Multiply: \[ \frac{-y}{xy} dx + \frac{x}{xy} dy = -\frac{1}{x} dx + \frac{1}{y} dy = 0 \] Let \(M = -\frac{1}{x}\), \(N = \frac{1}{y}\).
\(M_y = 0\), \(N_x = 0\) → ✅ exact.
Also, \(-d(\ln(x/y)) = -(\frac{1}{x}dx - \frac{1}{y}dy) = -\frac{1}{x}dx + \frac{1}{y}dy = 0\). Verified. verified
3. \(F = \frac{1}{x^2 + y^2}\)
Multiply: \[ \frac{-y}{x^2+y^2} dx + \frac{x}{x^2+y^2} dy = 0 \] Let \(M = -\frac{y}{x^2+y^2}\), \(N = \frac{x}{x^2+y^2}\).
Check exactness: \[ M_y = -\frac{x^2 - y^2}{(x^2+y^2)^2}, \quad N_x = \frac{y^2 - x^2}{(x^2+y^2)^2} \] Since \(M_y = N_x\) → ✅ exact.
And \(d(\arctan(x/y)) = \frac{-y\,dx + x\,dy}{x^2+y^2} = 0\). Verified. verified
🥇 Observation: An ODE can have many integrating factors. The choice depends on the form of the equation.
