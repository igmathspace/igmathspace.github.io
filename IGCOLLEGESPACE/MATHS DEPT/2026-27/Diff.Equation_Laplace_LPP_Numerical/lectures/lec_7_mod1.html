📖 Integrating Factors – Finding Integrating Factor (Function of x or y only)
📚 Kreyszig §1.4 (Exact ODEs) – Integrating Factors
🎯 Introduction: The Idea of Integrating Factors

Consider the non-exact ODE:

\[ -y \, dx + x \, dy = 0 \]

If we multiply by \(1/x^2\), we get an exact equation:

\[ \frac{-y \, dx + x \, dy}{x^2} = -\frac{y}{x^2} \, dx + \frac{1}{x} \, dy = d\left(\frac{y}{x}\right) = 0 \]

Integration gives: \(\frac{y}{x} = C\) → \(y = Cx\).

💡 Definition: A function \(F(x, y)\) that multiplies a non-exact ODE to make it exact is called an integrating factor.
Other Integrating Factors for \(-y \, dx + x \, dy = 0\):
\(F = 1/y^2\) gives \(d(x/y) = 0\)
\(F = 1/(xy)\) gives \(-d(\ln(x/y)) = 0\)
\(F = 1/(x^2 + y^2)\) gives \(d(\arctan(x/y)) = 0\)
⚡ General Method for Finding Integrating Factors

For a non-exact ODE:

\[ P(x, y) \, dx + Q(x, y) \, dy = 0 \]

We multiply by \(F(x, y)\) to get:

\[ FP \, dx + FQ \, dy = 0 \]

The new equation is exact if:

\[ \frac{\partial}{\partial y}(FP) = \frac{\partial}{\partial x}(FQ) \]

By the product rule:

\[ F_y P + F P_y = F_x Q + F Q_x \]
🥇 Golden Rule: "If you cannot solve your problem, try to solve a simpler one."
Look for an integrating factor depending on only one variable.
📐 Theorem 1: Integrating Factor \(F(x)\) (Function of x only)

If the expression:

\[ R = \frac{1}{Q} \left( \frac{\partial P}{\partial y} - \frac{\partial Q}{\partial x} \right) \]

depends only on x (and not on y), then the ODE has an integrating factor:

\[ F(x) = \exp\left( \int R(x) \, dx \right) \]
Derivation: Let \(F = F(x)\). Then \(F_y = 0\) and \(F_x = F' = dF/dx\).
Substituting into the exactness condition: \[ F P_y = F' Q + F Q_x \] Dividing by \(FQ\): \[ \frac{1}{F} \frac{dF}{dx} = \frac{1}{Q} \left( \frac{\partial P}{\partial y} - \frac{\partial Q}{\partial x} \right) = R \] Integrating gives \(F(x) = \exp(\int R \, dx)\).
📐 Theorem 2: Integrating Factor \(F^*(y)\) (Function of y only)

If the expression:

\[ R^* = \frac{1}{P} \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) \]

depends only on y (and not on x), then the ODE has an integrating factor:

\[ F^*(y) = \exp\left( \int R^*(y) \, dy \right) \]
Derivation: Let \(F^* = F^*(y)\). Then \(F^*_x = 0\) and \(F^*_y = dF^*/dy\).
\[ F^* P_y + F^*_y P = F^* Q_x \] Dividing by \(F^*P\): \[ \frac{1}{F^*} \frac{dF^*}{dy} = \frac{1}{P} \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) = R^* \] Integrating gives \(F^*(y) = \exp(\int R^* \, dy)\).
🏆 Theorem 1 and Theorem 2 together are termed as the GOLDEN RULE for finding integrating factors.
📌 Summary of the Golden Rule:
  • Check \(F(x)\): Compute \(R = \frac{1}{Q}(P_y - Q_x)\). If \(R\) depends only on \(x\), then \(F(x) = e^{\int R \, dx}\).
  • Check \(F(y)\): Compute \(R^* = \frac{1}{P}(Q_x - P_y)\). If \(R^*\) depends only on \(y\), then \(F(y) = e^{\int R^* \, dy}\).
  • If neither works, try inspection or look for an integrating factor that depends on both variables.
📋 Step-by-Step Procedure
Step 1: Check exactness. Compute \(\partial P/\partial y\) and \(\partial Q/\partial x\).
If they are equal → the ODE is already exact. Solve directly.
Step 2: Try Theorem 1 (\(F(x)\)).
Compute \(R = (1/Q)(P_y - Q_x)\).
If R depends only on x, calculate \(F(x) = e^{\int R \, dx}\).
Multiply the ODE by F(x) and solve the resulting exact equation.
Step 3: Try Theorem 2 (\(F(y)\)).
Compute \(R^* = (1/P)(Q_x - P_y)\).
If \(R^*\) depends only on y, calculate \(F^*(y) = e^{\int R^* \, dy}\).
Multiply the ODE by \(F^*(y)\) and solve the resulting exact equation.
✅ After multiplying by the integrating factor, always verify that the new equation is exact before proceeding to solve.
📖 Worked Example: IVP with Integrating Factor

Problem: Solve the initial value problem:

\[ (e^{x+y} + y e^y) \, dx + (x e^y - 1) \, dy = 0, \qquad y(0) = -1 \]
Step 1: Check Exactness
\(P = e^{x+y} + y e^y\),   \(Q = x e^y - 1\)
\(P_y = e^{x+y} + e^y + y e^y\)
\(Q_x = e^y\)
\(P_y \neq Q_x\) → Not exact.
Step 2: Try Theorem 1 (\(F(x)\))
\(R = (1/Q)(P_y - Q_x) = (e^{x+y} + y e^y)/(x e^y - 1)\)
This depends on both x and y → Theorem 1 fails.
Step 3: Try Theorem 2 (\(F(y)\))
\(R^* = (1/P)(Q_x - P_y) = -1\)
This depends only on y → Theorem 2 works!
\(F^*(y) = e^{\int -1 \, dy} = e^{-y}\)
Step 4: Multiply and Solve
Multiply the ODE by \(e^{-y}\):
\((e^x + y) \, dx + (x - e^{-y}) \, dy = 0\)

Check Exactness:
\(M = e^x + y\),   \(N = x - e^{-y}\)
\(M_y = 1\),   \(N_x = 1\) → ✅ Exact.
Step 5: Find \(u(x, y)\)
\(u = \int M \, dx = \int (e^x + y) \, dx = e^x + xy + k(y)\)
\(\partial u/\partial y = x + dk/dy = N = x - e^{-y}\)
\(dk/dy = -e^{-y}\) → \(k(y) = e^{-y}\)

General Solution: \[ e^x + xy + e^{-y} = C \]
Step 6: Apply Initial Condition
\(y(0) = -1\):
\(e^0 + 0 + e^{1} = 1 + e\)
\(C = 1 + e\)

Particular Solution: \[ e^x + xy + e^{-y} = 1 + e \]
📝 Problems from the Text (Image)
In the following problems, a function \(F(x, y)\) is given. Check whether this \(F\) can form an integrating factor of the given differential equation.
Prob. 13: \(e^{-y} dx + e^{-x}(-e^{-y} + 1) dy = 0\),   \(F = e^{x+y}\) CO1
✅ Solution:
Given: \(P = e^{-y}\), \(Q = e^{-x}(-e^{-y} + 1)\)
Integrating factor: \(F = e^{x+y}\)

Multiply the ODE by \(F\):
\(e^{x+y} \cdot e^{-y} \, dx + e^{x+y} \cdot e^{-x}(-e^{-y} + 1) \, dy = 0\)
\(e^x \, dx + (e^y)(-e^{-y} + 1) \, dy = 0\)
\(e^x \, dx + (-1 + e^y) \, dy = 0\)

Now: \(M = e^x\), \(N = -1 + e^y\)
\(M_y = 0\), \(N_x = 0\) → ✅ Exact

\(u = \int M \, dx = \int e^x \, dx = e^x + k(y)\)
\(\partial u/\partial y = dk/dy = N = -1 + e^y\)
\(k(y) = -y + e^y\)

Solution: \[ e^x - y + e^y = C \]
Prob. 14: \((a+1)y \, dx + (b+1)x \, dy = 0\),   \(y(1) = 1\),   \(F = x^a y^b\) CO1
✅ Solution:
Given: \(P = (a+1)y\), \(Q = (b+1)x\)
Integrating factor: \(F = x^a y^b\)

Multiply the ODE by \(F\):
\((a+1) x^a y^{b+1} \, dx + (b+1) x^{a+1} y^b \, dy = 0\)

Now: \(M = (a+1) x^a y^{b+1}\), \(N = (b+1) x^{a+1} y^b\)
\(M_y = (a+1)(b+1) x^a y^b\)
\(N_x = (b+1)(a+1) x^a y^b\) → ✅ Exact

\(u = \int M \, dx = \int (a+1) x^a y^{b+1} \, dx = x^{a+1} y^{b+1} + k(y)\)
\(\partial u/\partial y = (b+1) x^{a+1} y^b + dk/dy = N = (b+1) x^{a+1} y^b\)
\(dk/dy = 0\) → \(k(y) = 0\) (or constant)

General Solution: \[ x^{a+1} y^{b+1} = C \]
Apply initial condition: \(y(1) = 1\):
\(1^{a+1} \cdot 1^{b+1} = 1 = C\)

Particular Solution: \[ x^{a+1} y^{b+1} = 1 \]
⚠️ Common Mistakes to Avoid
MistakeCorrection
Forgetting to check exactness before applying the shortcut Always verify \(\partial M/\partial y = \partial N/\partial x\) first.
Including \(x\)-terms in \(N_1(y)\) Only terms with no \(x\) go into \(N_1(y)\).
Omitting the constant \(C\) in the final solution Always write \(u(x,y) = C\).
Forgetting to verify the integrating factor works After multiplying, check that the new equation is exact.
Confusing \(F(x)\) with \(F(y)\) conditions \(R\) must depend only on \(x\); \(R^*\) must depend only on \(y\).
📋 Quick Summary
  • Exact ODE form: \(M \, dx + N \, dy = 0\)
  • Exactness condition: \(\partial M/\partial y = \partial N/\partial x\)
  • Shortcut solution: \(\int M \, dx + \int N_1(y) \, dy = C\)
  • \(N_1(y)\) = purely \(y\)-terms from \(N\)
  • Integrating factor \(F(x)\): \(F(x) = \exp\left(\int \frac{1}{Q}(P_y - Q_x) \, dx\right)\)
  • Integrating factor \(F(y)\): \(F(y) = \exp\left(\int \frac{1}{P}(Q_x - P_y) \, dy\right)\)
  • 🏆 Theorem 1 and Theorem 2 together are the GOLDEN RULE for finding integrating factors.
