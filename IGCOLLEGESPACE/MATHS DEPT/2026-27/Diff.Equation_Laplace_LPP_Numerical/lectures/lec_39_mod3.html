📚 Textbook: Operations Research – Gupta & Hira | §2.12-2 (Conversion)

🎯 1. Learning Outcomes (CO3)
  • Apply the four conversion rules systematically to any LPP
  • Convert LPPs with mixed constraints — \((\le)\), \((\ge)\), and equality \((=)\) — into standard form
  • Convert LPPs with unrestricted (free) variables into standard form
  • Handle negative right-hand sides and their effect on inequality direction
  • Write the resulting reformulated LPP (the standard-form model)
📐 2. Quick Recap — Four Rules of Conversion
Rule 1 — Unrestricted variable

If a variable \(x_j\) is unrestricted in sign, write \(x_j = x_j' - x_j''\) with \(x_j' \ge 0, x_j'' \ge 0\).

Rule 2 — Negative RHS

If \(b_i < 0\), multiply the constraint by \(-1\); this flips the inequality direction.

Rule 3 — Inequality → equation
  • For \((\le)\): add a slack variable \(s \ge 0\).
  • For \((\ge)\): subtract a surplus variable \(s \ge 0\).
  • Equality \((=)\) constraints stay as they are.
Rule 4 — Artificial variable

Add a non-negative artificial variable \(A \ge 0\) to every \((\ge)\) or \((=)\) constraint to provide an initial basis. Assign penalty \(-M\) (max) or \(+M\) (min) in the objective.

⚠️ CAUTION! The order of applying rules matters. Always:
1. Handle unrestricted variables first — this affects every constraint they appear in.
2. Handle negative RHS next.
3. Then convert each inequality / equality.
4. Finally, add artificials where needed.

Problem 1. Express in standard form: Maximise \(Z = 7x_1 + 5x_2\), subject to \(2x_1 + 3x_2 \le 20,\; 3x_1 + x_2 \ge 10,\; x_1, x_2 \ge 0\). CO3
✅ Step-by-step:
Step 1: Objective is maximisation. No change needed for objective type.
Step 2: Constraint 1 (\(2x_1 + 3x_2 \le 20\)) is \((\le)\) type. Add slack \(s_1 \ge 0\): \(2x_1 + 3x_2 + s_1 = 20\).
Step 3: Constraint 2 (\(3x_1 + x_2 \ge 10\)) is \((\ge)\) type. Subtract surplus \(s_2 \ge 0\): \(3x_1 + x_2 - s_2 = 10\).
Step 4: Constraint 2 has no natural unit column, so add artificial \(A_1 \ge 0\): \(3x_1 + x_2 - s_2 + A_1 = 10\).
Step 5: Artificial variables get \(-M\) penalty (max problem). Slack and surplus get 0.
Standard form:
\(\begin{aligned}\text{Max } Z = &\; 7x_1 + 5x_2 + 0s_1 + 0s_2 - MA_1\\\text{s.t. } & 2x_1 + 3x_2 + s_1 = 20,\\ & 3x_1 + x_2 - s_2 + A_1 = 10,\\ & x_1, x_2, s_1, s_2, A_1 \ge 0.\end{aligned}\)

✅ Complete: 5 variables, 2 equality constraints, all RHS \(\ge 0\).

Problem 2. Express in standard form: Maximise \(Z = 3x_1 + 5x_2 - 2x_3\), subject to \(x_1 + 2x_2 - x_3 \ge -4,\; -5x_1 + 6x_2 + 7x_3 \ge 5,\; 2x_1 + x_2 + 3x_3 = 10,\; x_1, x_2 \ge 0,\; x_3\) unrestricted. CO3
✅ Step-by-step:
Step 1: \(x_3\) is unrestricted. By Rule 1, put \(x_3 = x_3' - x_3''\), with \(x_3', x_3'' \ge 0\).
Step 2: Substitute \(x_3 = x_3' - x_3''\) everywhere:
Objective: \(Z = 3x_1 + 5x_2 - 2x_3' + 2x_3''\).
C1: \(x_1 + 2x_2 - x_3' + x_3'' \ge -4\).
C2: \(-5x_1 + 6x_2 + 7x_3' - 7x_3'' \ge 5\).
C3: \(2x_1 + x_2 + 3x_3' - 3x_3'' = 10\).
Step 3: C1 has RHS \(= -4\) (negative). Multiply by \(-1\) (Rule 2): \(-x_1 - 2x_2 + x_3' - x_3'' \le 4\).
Step 4: C2 is \((\ge)\) with positive RHS. Subtract surplus \(s_2 \ge 0\): \(-5x_1 + 6x_2 + 7x_3' - 7x_3'' - s_2 = 5\).
Step 5: Convert all constraints to equations:
C1 (now \(\le\)): add slack \(s_1\): \(-x_1 - 2x_2 + x_3' - x_3'' + s_1 = 4\).
C2 (already \(\ge\)): add surplus and artificial: \(-5x_1 + 6x_2 + 7x_3' - 7x_3'' - s_2 + A_2 = 5\).
C3 (already \(=\)): add artificial only: \(2x_1 + x_2 + 3x_3' - 3x_3'' + A_3 = 10\).
Step 6: Standard form:
\(\begin{aligned}\text{Max } Z = &\; 3x_1 + 5x_2 - 2x_3' + 2x_3'' + 0s_1 + 0s_2 - MA_2 - MA_3\\\text{s.t. } & -x_1 - 2x_2 + x_3' - x_3'' + s_1 = 4,\\ & -5x_1 + 6x_2 + 7x_3' - 7x_3'' - s_2 + A_2 = 5,\\ & 2x_1 + x_2 + 3x_3' - 3x_3'' + A_3 = 10,\\ & x_1, x_2, x_3', x_3'', s_1, s_2, A_2, A_3 \ge 0.\end{aligned}\)

✅ Three original constraints → 3 equations; two artificial variables \(A_2, A_3\) added for the \(\ge\) and \(=\) constraints.

Problem 3. Express in standard form: Maximise \(Z = 3x_1 + 2x_2 + 5x_3\), subject to \(2x_1 + 3x_2 - 2x_3 \le 40,\; 4x_1 - 2x_2 + x_3 \le 24,\; x_1 - 5x_2 - 6x_3 \ge 2,\; x_1 \ge 0\). CO3
✅ Step-by-step:
Step 1: Only \(x_1 \ge 0\); \(x_2\) and \(x_3\) are unrestricted. Put \(x_2 = x_2' - x_2''\), \(x_3 = x_3' - x_3''\) with \(x_2', x_2'', x_3', x_3'' \ge 0\).
Step 2: Substitute \(x_2\) and \(x_3\) in objective and all constraints.
Step 3: C1: \(2x_1 + 3x_2' - 3x_2'' - 2x_3' + 2x_3'' \le 40\) — add slack \(s_1 \ge 0\):
\(2x_1 + 3x_2' - 3x_2'' - 2x_3' + 2x_3'' + s_1 = 40\).
Step 4: C2: \(4x_1 - 2x_2' + 2x_2'' + x_3' - x_3'' \le 24\) — add slack \(s_2 \ge 0\):
\(4x_1 - 2x_2' + 2x_2'' + x_3' - x_3'' + s_2 = 24\).
Step 5: C3: \(x_1 - 5x_2' + 5x_2'' - 6x_3' + 6x_3'' \ge 2\) — subtract surplus \(s_3 \ge 0\), add artificial \(A_1 \ge 0\):
\(x_1 - 5x_2' + 5x_2'' - 6x_3' + 6x_3'' - s_3 + A_1 = 2\).
Step 6: Standard form:
\(\begin{aligned}\text{Max } Z = &\; 3x_1 + 2x_2' - 2x_2'' + 5x_3' - 5x_3'' + 0s_1 + 0s_2 + 0s_3 - MA_1\\\text{s.t. } & 2x_1 + 3x_2' - 3x_2'' - 2x_3' + 2x_3'' + s_1 = 40,\\ & 4x_1 - 2x_2' + 2x_2'' + x_3' - x_3'' + s_2 = 24,\\ & x_1 - 5x_2' + 5x_2'' - 6x_3' + 6x_3'' - s_3 + A_1 = 2,\\ & \text{all variables} \ge 0.\end{aligned}\)

✅ 3 original variables become 5 (after splitting the two unrestricted ones); 3 slack/surplus + 1 artificial added.

Problem 4. Reformulate into standard form: Minimise \(Z = 2x_1 + 3x_2\), subject to \(2x_1 - 3x_2 - x_3 = -4,\; 3x_1 + 4x_2 - x_4 = -6,\; 2x_1 + 5x_2 + x_5 = 10,\; 4x_1 - 3x_2 + x_6 = 18\), with \(x_3, x_4, x_5, x_6 \ge 0\). CO3
✅ Step-by-step:
Step 1: \(x_3, x_4, x_5, x_6\) are already non-negative (they are given as slack-type variables). The decision variables \(x_1, x_2\) are unrestricted.
Step 2: Split \(x_1 = y_1 - y_2\), \(x_2 = y_3 - y_4\) with \(y_1, y_2, y_3, y_4 \ge 0\).
Step 3: Rename \(x_3 = y_5\), \(x_4 = y_6\), \(x_5 = y_7\), \(x_6 = y_8\) to keep all variables non-negative.
Step 4: Substitute into constraints. Note constraints 1 and 2 have negative RHS, so multiply each by \(-1\) first (Rule 2):
From C1: \(-2x_1 + 3x_2 + x_3 = 4\).
From C2: \(-3x_1 - 4x_2 + x_4 = 6\).
C3: \(2x_1 + 5x_2 + x_5 = 10\).
C4: \(4x_1 - 3x_2 + x_6 = 18\).
Step 5: Substitute \(x_1 = y_1 - y_2\), \(x_2 = y_3 - y_4\):
C1: \(-2y_1 + 2y_2 + 3y_3 - 3y_4 + y_5 = 4\).
C2: \(-3y_1 + 3y_2 - 4y_3 + 4y_4 + y_6 = 6\).
C3: \(2y_1 - 2y_2 + 5y_3 - 5y_4 + y_7 = 10\).
C4: \(4y_1 - 4y_2 - 3y_3 + 3y_4 + y_8 = 18\).
Step 6: All four constraints are now equalities. However, C1, C2, C3, C4 have unit coefficients on \(y_5, y_6, y_7, y_8\) respectively, so these variables already form a starting basis — artificial variables not needed.
Step 7: Objective becomes: Minimise \(Z = 2y_1 - 2y_2 + 3y_3 - 3y_4\).
Standard form:
\(\begin{aligned}\text{Min } Z = &\; 2y_1 - 2y_2 + 3y_3 - 3y_4\\\text{s.t. } & -2y_1 + 2y_2 + 3y_3 - 3y_4 + y_5 = 4,\\ & -3y_1 + 3y_2 - 4y_3 + 4y_4 + y_6 = 6,\\ & 2y_1 - 2y_2 + 5y_3 - 5y_4 + y_7 = 10,\\ & 4y_1 - 4y_2 - 3y_3 + 3y_4 + y_8 = 18,\\ & y_1, \dots, y_8 \ge 0.\end{aligned}\)

✅ Negative RHS handled; unrestricted decision variables replaced; no artificials needed since the slack-type variables already provide an identity basis.

Problem 5 (Standard matrix form). Express the LPP in standard matrix form: Maximise \(Z = 4x_1 + 2x_2 + 6x_3\), subject to \(2x_1 + 3x_2 + 2x_3 \ge 6,\; 3x_1 + 4x_2 = 8,\; 6x_1 - 4x_2 + x_3 \le 10,\; x_1, x_2, x_3 \ge 0\). CO3
✅ Step-by-step:
Step 1: Add slack \(s_1 \ge 0\) to C1? No — C1 is \((\ge)\), so subtract surplus \(s_1\): \(2x_1 + 3x_2 + 2x_3 - s_1 = 6\).
Step 2: C2 is equality: \(3x_1 + 4x_2 = 8\) (no slack/surplus; artificial needed for starting basis).
Step 3: C3 is \((\le)\): add slack \(s_3 \ge 0\): \(6x_1 - 4x_2 + x_3 + s_3 = 10\).
Step 4: Add artificial \(A_1 \ge 0\) to C1 and \(A_2 \ge 0\) to C2 for a starting basis:
C1: \(2x_1 + 3x_2 + 2x_3 - s_1 + A_1 = 6\).
C2: \(3x_1 + 4x_2 + A_2 = 8\).
Step 5: Standard form:
\(\begin{aligned}\text{Max } Z = &\; 4x_1 + 2x_2 + 6x_3 + 0s_1 + 0s_3 - MA_1 - MA_2\\\text{s.t. } & 2x_1 + 3x_2 + 2x_3 - s_1 + A_1 = 6,\\ & 3x_1 + 4x_2 + A_2 = 8,\\ & 6x_1 - 4x_2 + x_3 + s_3 = 10,\\ & \text{all variables} \ge 0.\end{aligned}\)
Step 6: Matrix form. Define
\(\mathbf{c} = (4, 2, 6, 0, 0, -M, -M)\), \(\mathbf{x} = (x_1, x_2, x_3, s_1, s_3, A_1, A_2)^T\),
\(\mathbf{A} = \begin{pmatrix} 2 & 3 & 2 & -1 & 0 & 1 & 0\\ 3 & 4 & 0 & 0 & 0 & 0 & 1\\ 6 & -4 & 1 & 0 & 1 & 0 & 0 \end{pmatrix}\), \(\mathbf{b} = \begin{pmatrix} 6\\ 8\\ 10 \end{pmatrix}\).
Then the LPP is: Max \(Z = \mathbf{c}\mathbf{x}\), subject to \(\mathbf{A}\mathbf{x} = \mathbf{b}\), \(\mathbf{x} \ge 0\).

✅ Standard matrix form: \(\max\, Z = \mathbf{c}\mathbf{x}\), \(\mathbf{A}\mathbf{x} = \mathbf{b}\), \(\mathbf{x} \ge 0\), \(\mathbf{b} \ge 0\).

📋 5. Quick Summary
  • Order of rules: unrestricted variables → negative RHS → inequality → equation → artificial variables.
  • Unrestricted: \(x_j = x_j' - x_j''\); substitutes into all expressions and may flip signs.
  • Negative RHS: multiply constraint by \(-1\); inequality direction flips.
  • Inequality types: \(\le\) gets slack (+), \(\ge\) gets surplus (−), \(=\) gets neither.
  • Artificials: added to every \((\ge)\) and \((=)\) constraint to give a basis; penalised by \(-M\) (max) or \(+M\) (min).
  • Matrix form: \(\max\, Z = \mathbf{c}\mathbf{x}\) s.t. \(\mathbf{A}\mathbf{x} = \mathbf{b}\), \(\mathbf{x} \ge 0\), \(\mathbf{b} \ge 0\).
