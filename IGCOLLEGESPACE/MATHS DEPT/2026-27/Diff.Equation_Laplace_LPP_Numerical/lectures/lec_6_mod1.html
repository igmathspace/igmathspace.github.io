📖 Exact ODEs – Solving Exact Equations with Examples
📚 Kreyszig §1.4 (Exact ODEs) – Problem Set 1.4
👨‍🏫 Faculty: Gafoor I  |  🎯 CO1: Solve exact differential equations
🎯 Learning Outcomes
  • Identify an exact differential equation using the exactness condition
  • Apply the shortcut solution method (Integrate M + Integrate N₁(y))
  • Solve exact ODEs from Kreyszig Problem Set 1.4
  • Solve additional exact ODE problems
⚡ Review: Shortcut Solution Method

For an exact ODE \(M\,dx + N\,dy = 0\), the solution is:

\[ \boxed{\int M\,dx + \int N_1(y)\,dy = C} \]
  • ✅ In \(\int M\,dx\), treat \(y\) as constant.
  • ✅ \(N_1(y)\) = all terms in \(N(x,y)\) that are independent of \(x\) (purely \(y\)-terms).
  • ✅ \(C\) is the arbitrary constant.
  • ✅ Always check exactness first: \(\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\)
💡 Why this works: The shortcut skips the \(\phi(y)\) step. The \(N_1(y)\) terms come from the \(\phi(y)\) integration constant in the standard method.
📖 Worked Example
Solve: \((2xy + 3x^2)\,dx + (x^2 + 4y^3)\,dy = 0\)

Step 1: Check exactness
\(M = 2xy + 3x^2 \Rightarrow M_y = 2x\)
\(N = x^2 + 4y^3 \Rightarrow N_x = 2x\)
\(M_y = N_x\) ✅ Exact.

Step 2: Apply shortcut
\(\int M\,dx = \int (2xy + 3x^2)\,dx = x^2y + x^3\)
\(N_1(y)\) = terms in \(N\) with no \(x\): \(4y^3\)
\(\int N_1(y)\,dy = \int 4y^3\,dy = y^4\)

Solution: \[ x^2y + x^3 + y^4 = C \]
📚 Kreyszig Problem Set 1.4 (Remaining Problems)

These problems are from Kreyszig §1.4 — avoiding the ones already covered in the previous lecture.

Prob. 1: \(2xy\,dx + x^2\,dy = 0\) CO1
✅ Solution:
\(M = 2xy,\; N = x^2\)
\(M_y = 2x,\; N_x = 2x\) ✅ Exact.

\(\int M\,dx = \int 2xy\,dx = x^2y\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
\[ \boxed{x^2y = C} \]
Prob. 2: \(x^3\,dx + y^3\,dy = 0\) CO1
✅ Solution:
\(M = x^3,\; N = y^3\)
\(M_y = 0,\; N_x = 0\) ✅ Exact.

\(\int M\,dx = \int x^3\,dx = \frac{x^4}{4}\)
\(N_1(y)\) = terms in \(N\) with no \(x\): \(y^3\)
\(\int y^3\,dy = \frac{y^4}{4}\)
\[ \boxed{x^4 + y^4 = C} \]
Prob. 3: \(\sin x \cos y\,dx + \cos x \sin y\,dy = 0\) CO1
✅ Solution:
\(M = \sin x \cos y,\; N = \cos x \sin y\)
\(M_y = -\sin x \sin y,\; N_x = -\sin x \sin y\) ✅ Exact.

\(\int M\,dx = \int \sin x \cos y\,dx = -\cos x \cos y\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
\[ \boxed{\cos x \cos y = C} \]
Prob. 4: \(e^{3\theta}(dr + 3r\,d\theta) = 0\) CO1
✅ Solution:
Expand: \(e^{3\theta}\,dr + 3r e^{3\theta}\,d\theta = 0\)
\(M = e^{3\theta},\; N = 3r e^{3\theta}\)
\(M_\theta = 3e^{3\theta},\; N_r = 3e^{3\theta}\) ✅ Exact.

\(\int M\,dr = \int e^{3\theta}\,dr = r e^{3\theta}\)
\(N_1(\theta)\) = terms in \(N\) with no \(r\): none → 0
\[ \boxed{r e^{3\theta} = C} \]
Prob. 5: \((x^2 + y^2)\,dx - 2xy\,dy = 0\) CO1
✅ Solution:
\(M = x^2 + y^2,\; N = -2xy\)
\(M_y = 2y,\; N_x = -2y\) ❌ Not exact.
This is not exact — it requires an integrating factor or can be solved as a homogeneous ODE.
Prob. 6: \(3(y+1)\,dx = 2x\,dy\) CO1
✅ Solution:
Rewrite: \(3(y+1)\,dx - 2x\,dy = 0\)
\(M = 3(y+1),\; N = -2x\)
\(M_y = 3,\; N_x = -2\) ❌ Not exact.
This is separable: \(\frac{3}{2x}\,dx = \frac{1}{y+1}\,dy\)
\[ \boxed{(y+1)^2 = Cx^3} \]
Prob. 7: \(2x \tan y\,dx + \sec^2 y\,dy = 0\) CO1
✅ Solution:
\(M = 2x \tan y,\; N = \sec^2 y\)
\(M_y = 2x \sec^2 y,\; N_x = 0\) ❌ Not exact.
This is separable: \(2x\,dx = -\frac{\sec^2 y}{\tan y}\,dy\)
\[ \boxed{x^2 + \ln|\tan y| = C} \]
Prob. 8: \(e^x(\cos y\,dx - \sin y\,dy) = 0\) CO1
✅ Solution:
\(e^x \cos y\,dx - e^x \sin y\,dy = 0\)
\(M = e^x \cos y,\; N = -e^x \sin y\)
\(M_y = -e^x \sin y,\; N_x = -e^x \sin y\) ✅ Exact.

\(\int M\,dx = \int e^x \cos y\,dx = e^x \cos y\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
\[ \boxed{e^x \cos y = C} \]
Prob. 9 (IVP): \(e^{2x}(2\cos y\,dx - \sin y\,dy) = 0,\; y(0) = 0\) CO1
✅ Solution:
\(2e^{2x}\cos y\,dx - e^{2x}\sin y\,dy = 0\)
\(M = 2e^{2x}\cos y,\; N = -e^{2x}\sin y\)
\(M_y = -2e^{2x}\sin y,\; N_x = -2e^{2x}\sin y\) ✅ Exact.

\(\int M\,dx = \int 2e^{2x}\cos y\,dx = e^{2x}\cos y\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
General solution: \(e^{2x}\cos y = C\)
Apply \(y(0)=0\): \(e^0 \cos 0 = 1 = C\)
\[ \boxed{e^{2x}\cos y = 1} \]
Prob. 12 (IVP): \((2xy\,dx + dy)e^{x^2} = 0,\; y(0) = 2\) CO1
✅ Solution:
\(2x y e^{x^2}\,dx + e^{x^2}\,dy = 0\)
\(M = 2xy e^{x^2},\; N = e^{x^2}\)
\(M_y = 2x e^{x^2},\; N_x = 2x e^{x^2}\) ✅ Exact.

\(\int M\,dx = \int 2xy e^{x^2}\,dx = y e^{x^2}\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
General solution: \(y e^{x^2} = C\)
Apply \(y(0)=2\): \(2 \cdot 1 = C \Rightarrow C = 2\)
\[ \boxed{y e^{x^2} = 2} \]
📝 Additional Exact ODE Problems
Prob. A1: \((e^y + 1)\cos x\,dx + e^y \sin x\,dy = 0\) CO1
✅ Solution:
\(M = (e^y + 1)\cos x,\; N = e^y \sin x\)
\(M_y = e^y \cos x,\; N_x = e^y \cos x\) ✅ Exact.

\(\int M\,dx = \int (e^y + 1)\cos x\,dx = (e^y + 1)\sin x\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
\[ \boxed{(e^y + 1)\sin x = C} \]
Prob. A2: \((y\cos x + \sin y + y)\,dx + (\sin x + x\cos y + x)\,dy = 0\) CO1
✅ Solution:
\(M = y\cos x + \sin y + y,\; N = \sin x + x\cos y + x\)
\(M_y = \cos x + \cos y + 1\)
\(N_x = \cos x + \cos y + 1\) ✅ Exact.

\(\int M\,dx = \int (y\cos x + \sin y + y)\,dx = y\sin x + x(\sin y + y)\)
\(N_1(y)\) = terms in \(N\) with no \(x\): none → 0
\[ \boxed{y\sin x + x(\sin y + y) = C} \]
Prob. A3: \((x^2 - ay)\,dx = (ax - y^2)\,dy\) CO1
✅ Solution:
Rewrite: \((x^2 - ay)\,dx + (y^2 - ax)\,dy = 0\)
\(M = x^2 - ay,\; N = y^2 - ax\)
\(M_y = -a,\; N_x = -a\) ✅ Exact.

\(\int M\,dx = \int (x^2 - ay)\,dx = \frac{x^3}{3} - axy\)
\(N_1(y)\) = terms in \(N\) with no \(x\): \(y^2\)
\(\int y^2\,dy = \frac{y^3}{3}\)
\[ \boxed{x^3 + y^3 - 3axy = C} \]
Prob. A4: \((ax + hy + g)\,dx + (hx + by + f)\,dy = 0\) CO1
✅ Solution:
\(M = ax + hy + g,\; N = hx + by + f\)
\(M_y = h,\; N_x = h\) ✅ Exact.

\(\int M\,dx = \int (ax + hy + g)\,dx = \frac{ax^2}{2} + hxy + gx\)
\(N_1(y)\) = terms in \(N\) with no \(x\): \(by + f\)
\(\int (by + f)\,dy = \frac{by^2}{2} + fy\)
\[ \boxed{\frac{ax^2}{2} + hxy + \frac{by^2}{2} + gx + fy = C} \]
Prob. A5: \((x^2 + y^2 - a^2)x\,dx + (x^2 - y^2 - b^2)y\,dy = 0\) CO1
✅ Solution:
\(M = x(x^2 + y^2 - a^2) = x^3 + xy^2 - a^2x\)
\(N = y(x^2 - y^2 - b^2) = x^2y - y^3 - b^2y\)
\(M_y = 2xy,\; N_x = 2xy\) ✅ Exact.

\(\int M\,dx = \int (x^3 + xy^2 - a^2x)\,dx = \frac{x^4}{4} + \frac{x^2y^2}{2} - \frac{a^2x^2}{2}\)
\(N_1(y)\) = terms in \(N\) with no \(x\): \(-y^3 - b^2y\)
\(\int (-y^3 - b^2y)\,dy = -\frac{y^4}{4} - \frac{b^2y^2}{2}\)
Multiply by 4: \[ \boxed{x^4 + 2x^2y^2 - 2a^2x^2 - y^4 - 2b^2y^2 = 4C} \]
Prob. A6: \((1 + e^{x/y})\,dx + e^{x/y}\left(1 - \frac{x}{y}\right)dy = 0\) CO1
✅ Solution:
\(M = 1 + e^{x/y},\; N = e^{x/y}\left(1 - \frac{x}{y}\right)\)
\(M_y = e^{x/y} \cdot \left(-\frac{x}{y^2}\right) = -\frac{x}{y^2}e^{x/y}\)
\(N_x = e^{x/y} \cdot \frac{1}{y} + e^{x/y}\left(1 - \frac{x}{y}\right)\frac{1}{y} = e^{x/y}\left(\frac{1}{y} + \frac{1}{y} - \frac{x}{y^2}\right) = e^{x/y}\left(\frac{2}{y} - \frac{x}{y^2}\right)\)
❌ Not exact in this form. This requires an integrating factor or a substitution.
(Note: This is a homogeneous ODE; set \(x = vy\) to solve.)
Prob. A7: \((x + 2y - 3)\,dy - (2x - y + 1)\,dx = 0\) CO1
✅ Solution:
Rewrite: \(-(2x - y + 1)\,dx + (x + 2y - 3)\,dy = 0\)
\(M = -2x + y - 1,\; N = x + 2y - 3\)
\(M_y = 1,\; N_x = 1\) ✅ Exact.

\(\int M\,dx = \int (-2x + y - 1)\,dx = -x^2 + xy - x\)
\(N_1(y)\) = terms in \(N\) with no \(x\): \(2y - 3\)
\(\int (2y - 3)\,dy = y^2 - 3y\)
\[ \boxed{-x^2 + xy - x + y^2 - 3y = C} \]
⚠️ Common Mistakes to Avoid
MistakeCorrection
Forgetting to check exactness before applying the shortcutAlways verify \(\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\) first.
Including \(x\)-terms in \(N_1(y)\)Only terms with no \(x\) go into \(N_1(y)\).
Omitting the constant \(C\) in the final solutionAlways write \(u(x,y) = C\).
Forgetting the integration constant when integrating \(N_1(y)\)The constant \(C\) is added at the end of the solution.
📋 Quick Summary
  • Exact ODE form: \(M\,dx + N\,dy = 0\)
  • Condition: \(\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}\)
  • Shortcut solution: \(\int M\,dx + \int N_1(y)\,dy = C\)
  • \(N_1(y)\) = purely \(y\)-terms from \(N\)
  • Always verify the solution by implicit differentiation.
