KU3DSCMAT211 Lecture 34
📌 Module III | Linear Programming
📖 Topic: Graphical Solution Method – Plotting Constraints, Feasible Region
📚 Textbook: Operations Research – Gupta & Hira | §2.9 Graphical Method
👨‍🏫 Faculty: Gafoor I 🎯 CO3: Apply graphical method to solve 2-variable LPPs ⏱️ Lecture duration: 1 Hour
🎯 1. Learning Outcomes (CO3)
  • Plot each linear constraint on the \(x_1 x_2\)-plane
  • Identify the feasible region as the intersection of the half-planes
  • Recognise when the feasible region is a bounded polygon and when it is unbounded
  • Mark the corner (extreme) points of the feasible region
📐 2. Steps of the Graphical Method
Procedure
  1. Write the LPP in mathematical form.
  2. Draw the \(x_1\)- and \(x_2\)-axes. The non-negativity restrictions \(x_1, x_2 \ge 0\) eliminate all but the first quadrant.
  3. Plot each constraint as an equation (a straight line), then use the inequality sign to determine on which side of the line the constraint is satisfied.
  4. Identify the feasible region — the common part of all half-planes (the "solution space" or "convex polygon").
  5. Find the corner points of the feasible region (vertices).
  6. Use the iso-profit / iso-cost line approach (or the corner-point enumeration approach) to locate the optimum.
📊 3. Which Side of the Line?
  • For \(a_1 x_1 + a_2 x_2 \le b\): the feasible side is towards the origin (if \(b \ge 0\)).
  • For \(a_1 x_1 + a_2 x_2 \ge b\): the feasible side is away from the origin (if \(b \ge 0\)).
  • Best practice: test the point \((0,0)\) in the inequality — if it is satisfied, the feasible side contains the origin.
⚠️ CAUTION! Two common mistakes: (i) plotting the inequality rather than the equality line, and (ii) forgetting to intersect all constraints — the feasible region is the common region that satisfies every constraint simultaneously.

Problem 1. Identify the feasible region \(x + y \le 3,\; x \ge 0,\; y \ge 0\). CO3
✅ Step-by-step:
Step 1: The constraint \(x + y \le 3\) is the region below the line \(x + y = 3\), which passes through \((3, 0)\) and \((0, 3)\).
Step 2: The non-negativity restricts us to the first quadrant.
Step 3: The intersection is the closed triangular region with vertices \(O(0,0)\), \(A(3,0)\), \(B(0,3)\).
Fig. 34.1 — Feasible region of \(x + y \le 3,\; x, y \ge 0\)

✅ Feasible region = triangle with vertices \((0,0), (3,0), (0,3)\).

Problem 2. Find the minimum value of \(z = 5x - 2y\), subject to \(2x + 3y \ge 1,\; x, y \ge 0\), using the graphical method. CO3
✅ Step-by-step:
Step 1: Constraint \(2x + 3y \ge 1\) — a \(\ge\)-type, so feasible region is above the line.
Step 2: Intercepts of \(2x + 3y = 1\): \(x = 1/2\) (when \(y=0\)) → \(A(1/2, 0)\); \(y = 1/3\) (when \(x=0\)) → \(B(0, 1/3)\).
Step 3: Feasible region is the unbounded region above \(AB\) in the first quadrant. Corner points: \(A(1/2, 0)\) and \(B(0, 1/3)\).
Step 4: Evaluate \(z\) at corners: \(z(A) = 5/2 = 2.5\); \(z(B) = -2/3 \approx -0.667\).
Step 5: Minimum at \(B\). Along the boundary \(y = (1-2x)/3\): \(z = 5x - 2(1-2x)/3 = (19x-2)/3\), which increases with \(x \ge 0\). So no lower value at infinity.
Step 6: Conclusion: \(x = 0,\; y = 1/3,\; z_{\min} = -2/3\).
Fig. 34.2 — Unbounded feasible region of \(2x + 3y \ge 1\); minimum of \(z = 5x - 2y\) at \(B(0, \tfrac{1}{3})\)

✅ \(x = 0,\; y = 1/3,\; z_{\min} = -2/3\).

Problem 3. Find the maximum value of \(z = 2x_1 + 3x_2\), subject to \(x_1 + x_2 \le 30,\; x_2 \ge 3,\; x_2 \le 12,\; x_1 - x_2 \ge 0,\; 0 \le x_1 \le 20\). CO3
✅ Step-by-step:
Step 1: Plot each constraint line in the first quadrant: \(x_1 + x_2 = 30\), \(x_2 = 3\), \(x_2 = 12\), \(x_1 = x_2\), \(x_1 = 20\), and the axes.
Step 2: The feasible region is a pentagon with five corners:
\(A(3,3)\) — intersection of \(x_1 = x_2\) with \(x_2 = 3\).
\(B(12,12)\) — intersection of \(x_1 = x_2\) with \(x_2 = 12\) (and also on \(x_1+x_2=24<30\)).
\(C(18,12)\) — intersection of \(x_1 + x_2 = 30\) with \(x_2 = 12\).
\(D(20,10)\) — intersection of \(x_1 + x_2 = 30\) with \(x_1 = 20\).
\(E(20,3)\) — intersection of \(x_1 = 20\) with \(x_2 = 3\).
Step 3: Evaluate \(z\) at corners:
\(z(A) = 2(3) + 3(3) = 15\)
\(z(B) = 2(12) + 3(12) = 60\)
\(z(C) = 2(18) + 3(12) = 72\)
\(z(D) = 2(20) + 3(10) = 70\)
\(z(E) = 2(20) + 3(3) = 49\)
Step 4: Maximum is \(z = 72\) at \(C(18, 12)\).
Fig. 34.3 — Feasible pentagon of Problem 3; optimum at \(C(18,12)\) with \(z = 72\)

✅ \(x_1 = 18,\; x_2 = 12,\; z_{\max} = 72\).

Problem 4. Using the graphical method, solve: maximise \(z = 2x + y\), subject to \(x + 2y \le 10,\; x + y \le 6,\; x - y \le 2,\; x - 2y \le 1,\; x, y \ge 0\). CO3
✅ Step-by-step:
Step 1: Plot four lines: \(x + 2y = 10\) (passes (10,0), (0,5)); \(x + y = 6\) (passes (6,0), (0,6)); \(x - y = 2\) (passes (2,0), (0,-2)); \(x - 2y = 1\) (passes (1,0), (0,-0.5)).
Step 2: All four constraints are \(\le\)-type. Feasible region is below each of these lines and above both axes.
Step 3: Corner points of feasible region (marked in figure):
\(O(0,0)\), \(A(0,5)\) (intersection of \(x=0\) with \(x+2y=10\)), \(B(2,4)\) (intersection of \(x+2y=10\) and \(x+y=6\)), \(C(4,2)\) (intersection of \(x+y=6\) and \(x-y=2\)), \(D(3,1)\) (intersection of \(x-y=2\) and \(x-2y=1\)), \(E(1,0)\).
Step 4: Evaluate \(z = 2x + y\):
\(z(O) = 0\), \(z(A) = 5\), \(z(B) = 8\), \(z(C) = 10\), \(z(D) = 7\), \(z(E) = 2\).
Step 5: Maximum is \(z = 10\) at \(C(4,2)\).
Fig. 34.4 — Feasible polygon of Problem 4; optimum at \(C(4,2)\) with \(z = 10\)

✅ \(x = 4,\; y = 2,\; z_{\max} = 10\).

Problem 5. Find the minimum value of \(z\), subject to \(-x_1 + 3x_2 \le 10,\; x_1 + x_2 \le 6,\; x_1 - x_2 \le 2,\; x_1, x_2 \ge 0\), where \(z = -x_1 + 2x_2\). CO3
✅ Step-by-step:
Step 1: Plot the three lines: \(-x_1 + 3x_2 = 10\) (passes \((-10,0)\), \((0, 10/3)\)); \(x_1 + x_2 = 6\) (passes \((6,0)\), \((0,6)\)); \(x_1 - x_2 = 2\) (passes \((2,0)\), \((0,-2)\)).
Step 2: All constraints are \(\le\)-type, so feasible region is towards the origin (below each line) and in the first quadrant.
Step 3: Corner points:
\(O(0,0)\), \(A(0, 10/3)\) (intersection of \(x_1=0\) with \(-x_1+3x_2=10\)), \(B(2,4)\) (intersection of \(-x_1+3x_2=10\) and \(x_1+x_2=6\)), \(C(4,2)\) (intersection of \(x_1+x_2=6\) and \(x_1-x_2=2\)), \(D(2,0)\).
Step 4: Evaluate \(z = -x_1 + 2x_2\):
\(z(O) = 0\), \(z(A) = 20/3\), \(z(B) = 6\), \(z(C) = 0\), \(z(D) = -2\).
Step 5: Minimum is \(z = -2\) at \(D(2,0)\).
Fig. 34.5 — Feasible polygon of Problem 5; minimum at \(D(2,0)\) with \(z = -2\)

✅ \(x_1 = 2,\; x_2 = 0,\; z_{\min} = -2\).

📋 6. Quick Summary
  • Steps: plot constraints → identify feasible region → find corners → evaluate objective.
  • \(\le\)-constraint: feasible side is towards the origin. \(\ge\)-constraint: away from the origin.
  • Corner-point enumeration is exact for a bounded region; for unbounded regions, evaluate at corners + verify no better value at infinity.
  • Optimum (if it exists) always occurs at a corner of the feasible region.
