📐 2. The Composite Simpson's 1/3 Rule
📌 Formula for \(n\) (even) Subintervals

Divide \([a, b]\) into an even number \(n\) of equal subintervals of width \(h = (b-a)/n\), with ordinates \(y_0, y_1, \dots, y_n\). The composite Simpson's 1/3 rule is

\[ \boxed{ \int_a^b f(x)\,dx \approx \frac{h}{3}\Big[ (y_0 + y_n) + 4(y_1 + y_3 + \dots + y_{n-1}) + 2(y_2 + y_4 + \dots + y_{n-2}) \Big] } \]

Pattern of coefficients: \(1, 4, 2, 4, 2, \dots, 4, 1\).

📏 3. Error Term
📌 Error in Composite Simpson's Rule

If \(f(x)\) has a continuous fourth derivative on \([a,b]\), the error is

\[ E_S = -\frac{(b-a)}{180}\,h^4\,f^{(4)}(\xi), \quad a < \xi < b \]

Equivalently, with \(n = (b-a)/h\):

\[ E_S = -\frac{(b-a)^5}{180\,n^4}\,f^{(4)}(\xi) \]

Since the error is \(O(h^4)\), halving \(h\) reduces the error by a factor of \(16\). The rule is exact for cubics.

Bounding the Error. If \(M_4 = \max_{[a,b]} |f^{(4)}(x)|\), then

\[ |E_S| \le \frac{(b-a)}{180}\,h^4\,M_4 \]

To achieve accuracy \(\epsilon\), we need

\[ h^4 \le \frac{180\,\epsilon}{(b-a)M_4} \quad \Longrightarrow \quad n \ge \left( \frac{(b-a)^5 M_4}{180\,\epsilon} \right)^{1/4} \]
⚠️ 4. Handling Odd \(n\)
🚨 What if \(n\) is Odd?

Simpson's 1/3 rule requires an even number of subintervals. If \(n\) is odd:

  • Apply Simpson's 1/3 rule to the first \(n-1\) subintervals (even count).
  • Apply the trapezoidal rule to the last subinterval.
  • Or, if possible, choose a finer grid so that \(n\) is even.

Problem 1 (B3). Evaluate \(I = \int_0^1 \sqrt{1 - x^2}\,dx\) using Simpson's rule. CO4
✅ Solution:
Take \(h = 0.25\), so \(n = 4\) (even). The ordinates are:
\(x\)00.250.500.751.00
\(y = \sqrt{1-x^2}\)1.00000.96820.86600.66140.0000
Apply the composite Simpson's 1/3 rule:
\[ I \approx \frac{0.25}{3}\Big[ (1.0000 + 0.0000) + 4(0.9682 + 0.6614) + 2(0.8660) \Big] \]
\[ = \frac{0.25}{3}\Big[ 1.0000 + 4(1.6296) + 1.7320 \Big] = \frac{0.25}{3}(9.2504) \approx 0.7709 \]

✅ \(I \approx 0.7709\). (Exact value \(\pi/4 \approx 0.7854\).)

Problem 2 (C1). Use Simpson's \(\frac{1}{3}\) rule to compute \(I = \int_0^1 \frac{1}{1+x}\,dx\) correct to three decimal places with (i) \(h = 0.25\) (ii) \(h = 0.125\). CO4
✅ Solution:
Case (i), \(h = 0.25\) (\(n = 4\)):
\(x\)00.250.500.751.00
\(y = \frac{1}{1+x}\)1.00000.80000.66670.57140.5000
\[ I \approx \frac{0.25}{3}\Big[ (1.0000 + 0.5000) + 4(0.8000 + 0.5714) + 2(0.6667) \Big] \]
\[ = \frac{0.25}{3}\Big[ 1.5000 + 5.4856 + 1.3334 \Big] = \frac{0.25}{3}(8.3190) \approx 0.6933 \]
Case (ii), \(h = 0.125\) (\(n = 8\)):
\(x\)00.1250.2500.3750.5000.6250.7500.8751.000
\(y\)1.00000.88890.80000.72730.66670.61540.57140.53330.5000
\[ I \approx \frac{0.125}{3}\Big[ (1.0000 + 0.5000) + 4(0.8889 + 0.7273 + 0.6154 + 0.5333) + 2(0.8000 + 0.6667 + 0.5714) \Big] \]
\[ = \frac{0.125}{3}\Big[ 1.5000 + 4(2.7649) + 2(2.0381) \Big] = \frac{0.125}{3}(16.6358) \approx 0.6931 \]

✅ (i) \(I \approx 0.6933\) (ii) \(I \approx 0.6931\). Exact \(\ln 2 = 0.6931\).

Problem 3 (C2). Estimate the value of \(\int_1^3 \frac{1}{x}\,dx\) by Simpson's rule with 4 strips and 8 strips respectively. Determine the error in each case. CO4
✅ Solution:
The exact value is \(\int_1^3 \frac{1}{x}\,dx = \ln 3 \approx 1.0986\).
With 4 strips (\(h = 0.5\)):
\(x\)1.01.52.02.53.0
\(y = 1/x\)1.00000.66670.50000.40000.3333
\[ I \approx \frac{0.5}{3}\Big[ (1.0000 + 0.3333) + 4(0.6667 + 0.4000) + 2(0.5000) \Big] \]
\[ = \frac{0.5}{3}\Big[ 1.3333 + 4.2668 + 1.0000 \Big] = \frac{0.5}{3}(6.6001) \approx 1.1000 \]
Error \(\approx 1.1000 - 1.0986 = 0.0014\).
With 8 strips (\(h = 0.25\)):
\(x\)1.001.251.501.752.002.252.502.753.00
\(y\)1.00000.80000.66670.57140.50000.44440.40000.36360.3333
\[ I \approx \frac{0.25}{3}\Big[ (1.0000 + 0.3333) + 4(0.8000 + 0.5714 + 0.4444 + 0.3636) + 2(0.6667 + 0.5000 + 0.4000) \Big] \]
\[ = \frac{0.25}{3}\Big[ 1.3333 + 4(2.1794) + 2(1.5667) \Big] = \frac{0.25}{3}(13.1843) \approx 1.0987 \]
Error \(\approx 1.0987 - 1.0986 = 0.0001\).

✅ 4 strips: \(I \approx 1.1000\), error \(0.0014\); 8 strips: \(I \approx 1.0987\), error \(0.0001\).

Problem 4 (B7). Evaluate \(I = \int_0^{\frac{\pi}{2}} \sqrt{\sin x}\,dx\) using Simpson's \(\frac{1}{3}\) rule with \(h = \frac{\pi}{2}\). CO4
🚨 Note: With \(h = \pi/2\), \(n = 1\) (odd), so Simpson's 1/3 rule cannot be applied directly. We use a finer grid.
✅ Solution (with \(h = \pi/4\), \(n = 2\)):
The ordinates are (RADIAN mode):
\(x\)0\(\pi/4\)\(\pi/2\)
\(y = \sqrt{\sin x}\)0.00000.84091.0000
Apply the composite Simpson's 1/3 rule with \(h = \pi/4\):
\[ I \approx \frac{\pi/4}{3}\Big[ 0.0000 + 4(0.8409) + 1.0000 \Big] \]
\[ = \frac{\pi}{12}\Big[ 1.0000 + 3.3636 \Big] = \frac{\pi}{12}(4.3636) \approx 1.1424 \]

✅ \(I \approx 1.1424\).

Problem 5 (B2). A solid of revolution is formed by rotating about the \(x\)-axis the area between the \(x\)-axis, the lines \(x = 0\) and \(x = 1\), and a curve through the points \((0, 1)\), \((0.25, 0.9896)\), \((0.5, 0.9589)\), \((0.75, 0.9089)\), \((1, 0.8415)\). Estimate the volume using Simpson's 1/3 rule, giving the answer to three decimal places. CO4
✅ Solution:
The volume is \(V = \pi \int_0^1 y^2\,dx\). First tabulate \(y^2\):
\(x\)00.250.500.751.00
\(y\)1.00000.98960.95890.90890.8415
\(y^2\)1.00000.97930.91950.82610.7081
Here \(n = 4\) (even) and \(h = 0.25\). Apply the composite Simpson's 1/3 rule:
\[ \int_0^1 y^2\,dx \approx \frac{0.25}{3}\Big[ (1.0000 + 0.7081) + 4(0.9793 + 0.8261) + 2(0.9195) \Big] \]
\[ = \frac{0.25}{3}\Big[ 1.7081 + 7.2216 + 1.8390 \Big] = \frac{0.25}{3}(10.7687) \approx 0.8974 \]
Therefore, the volume is \(V = \pi \times 0.8974 \approx 2.8192\).

✅ Volume \(\approx 2.819\) cubic units.
