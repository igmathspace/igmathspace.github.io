📌 Module II | Laplace Transforms
📖 Topic: Inverse Laplace using Partial Fractions – Distinct Real & Repeated Roots
📚 Textbook: Advanced Engineering Mathematics – E. Kreyszig | Sections 6.1–6.2 (Table 6.1)
👨‍🏫 Faculty: Gafoor I 🎯 CO2: Understand Laplace Transform and inverse transforms ⏱️ Lecture duration: 1 Hour
🎯 1. Learning Outcomes (CO2)
  • Use partial fractions for distinct linear (real) factors
  • Use partial fractions for repeated linear factors (powers of \( (s-a) \))
  • Combine with the shifting theorem and the standard table to invert
  • Handle improper fractions (polynomial division before splitting)
📐 2. Case 1: Distinct Linear (Real) Factors
Partial Fraction Form

If \( Q(s) = (s-a_1)(s-a_2)\cdots(s-a_n) \) with distinct real roots, write

\[ \frac{P(s)}{Q(s)} = \frac{A_1}{s-a_1} + \frac{A_2}{s-a_2} + \cdots + \frac{A_n}{s-a_n} \]

Solve for constants \( A_i \) (cover-up rule or by substitution), then invert each term using \( \mathcal{L}^{-1}\left\{\frac{1}{s-a}\right\} = e^{at} \).

📐 3. Case 2: Repeated Linear Factors
Partial Fraction Form

If \( (s-a)^r \) is a factor of \( Q(s) \), the decomposition must include

\[ \frac{A_1}{s-a} + \frac{A_2}{(s-a)^2} + \cdots + \frac{A_r}{(s-a)^r} \]

Invert using the shifting formula \( \mathcal{L}^{-1}\left\{\frac{1}{(s-a)^n}\right\} = \frac{t^{n-1}e^{at}}{(n-1)!} \).

⚠️ CAUTION! A repeated factor needs all powers from 1 up to the multiplicity. Missing lower powers is a common error.

Problem 1 (Distinct roots). Find \( \mathcal{L}^{-1}\left\{\dfrac{1}{(s+1)(s+2)}\right\} \). CO2
✅ Step-by-step:
Step 1: The roots are distinct: \( s = -1, -2 \). Decompose \( \dfrac{1}{(s+1)(s+2)} = \dfrac{A}{s+1} + \dfrac{B}{s+2} \).
Step 2: Multiply through: \( 1 = A(s+2) + B(s+1) \).
Step 3: Set \( s = -1 \): \( 1 = A(1) \Rightarrow A = 1 \).
Step 4: Set \( s = -2 \): \( 1 = B(-1) \Rightarrow B = -1 \).
Step 5: Thus \( \dfrac{1}{(s+1)(s+2)} = \dfrac{1}{s+1} - \dfrac{1}{s+2} \).
Step 6: Invert each term: \( \mathcal{L}^{-1}\left\{\dfrac{1}{s+1}\right\} = e^{-t} \), \( \mathcal{L}^{-1}\left\{\dfrac{1}{s+2}\right\} = e^{-2t} \).
Step 7: By linearity: \( \mathcal{L}^{-1} = e^{-t} - e^{-2t} \).

✅ \( f(t) = e^{-t} - e^{-2t} \).

Problem 2 (Distinct roots). Find \( \mathcal{L}^{-1}\left\{\dfrac{-s+11}{s^2-2s-3}\right\} \). CO2
✅ Step-by-step:
Step 1: Factor the denominator: \( s^2-2s-3 = (s-3)(s+1) \).
Step 2: Decompose: \( \dfrac{-s+11}{(s-3)(s+1)} = \dfrac{A}{s-3} + \dfrac{B}{s+1} \).
Step 3: Multiply through: \( -s+11 = A(s+1) + B(s-3) \).
Step 4: Set \( s = 3 \): \( -3+11 = 8 = A(4) \Rightarrow A = 2 \).
Step 5: Set \( s = -1 \): \( 1+11 = 12 = B(-4) \Rightarrow B = -3 \).
Step 6: So \( \dfrac{-s+11}{s^2-2s-3} = \dfrac{2}{s-3} - \dfrac{3}{s+1} \).
Step 7: Invert: \( \mathcal{L}^{-1} = 2e^{3t} - 3e^{-t} \).

✅ \( f(t) = 2e^{3t} - 3e^{-t} \).

Problem 3 (Distinct roots, general). Find \( \mathcal{L}^{-1}\left\{\dfrac{1}{(s+a)(s+b)}\right\} \), \( a \neq b \). CO2
✅ Step-by-step:
Step 1: Distinct roots \( s = -a, -b \). Decompose: \( \dfrac{1}{(s+a)(s+b)} = \dfrac{A}{s+a} + \dfrac{B}{s+b} \).
Step 2: Multiply through: \( 1 = A(s+b) + B(s+a) \).
Step 3: Set \( s = -a \): \( 1 = A(b-a) \Rightarrow A = \dfrac{1}{b-a} \).
Step 4: Set \( s = -b \): \( 1 = B(a-b) \Rightarrow B = \dfrac{1}{a-b} = -\dfrac{1}{b-a} \).
Step 5: So \( \dfrac{1}{(s+a)(s+b)} = \dfrac{1}{b-a}\left[\dfrac{1}{s+a} - \dfrac{1}{s+b}\right] \).
Step 6: Invert: \( \mathcal{L}^{-1} = \dfrac{1}{b-a}\left[e^{-at} - e^{-bt}\right] \).

✅ \( f(t) = \dfrac{e^{-at} - e^{-bt}}{b-a} \).

Problem 4 (Mixed factors). Find \( \mathcal{L}^{-1}\left\{\dfrac{1}{s^3-s}\right\} \). CO2
✅ Step-by-step:
Step 1: Factor: \( s^3-s = s(s^2-1) = s(s-1)(s+1) \).
Step 2: Decompose: \( \dfrac{1}{s(s-1)(s+1)} = \dfrac{A}{s} + \dfrac{B}{s-1} + \dfrac{C}{s+1} \).
Step 3: Multiply through: \( 1 = A(s-1)(s+1) + B s(s+1) + C s(s-1) \).
Step 4: Set \( s = 0 \): \( 1 = A(-1)(1) \Rightarrow A = -1 \).
Step 5: Set \( s = 1 \): \( 1 = B(1)(2) \Rightarrow B = \tfrac{1}{2} \).
Step 6: Set \( s = -1 \): \( 1 = C(-1)(-2) \Rightarrow C = \tfrac{1}{2} \).
Step 7: So \( \dfrac{1}{s^3-s} = -\dfrac{1}{s} + \dfrac{1/2}{s-1} + \dfrac{1/2}{s+1} \).
Step 8: Invert: \( \mathcal{L}^{-1} = -1 + \tfrac{1}{2}e^{t} + \tfrac{1}{2}e^{-t} \).
Step 9: Since \( \cosh t = \tfrac{e^t+e^{-t}}{2} \), we get \( = -1 + \cosh t \).

✅ \( f(t) = \cosh t - 1 \).

Problem 5 (Repeated root). Find \( \mathcal{L}^{-1}\left\{\dfrac{1}{s^3-2s^2}\right\} \). CO2
✅ Step-by-step:
Step 1: Factor: \( s^3-2s^2 = s^2(s-2) \). Repeated factor \( s^2 \), simple factor \( (s-2) \).
Step 2: Decompose: \( \dfrac{1}{s^2(s-2)} = \dfrac{A}{s} + \dfrac{B}{s^2} + \dfrac{C}{s-2} \).
Step 3: Multiply through by \( s^2(s-2) \): \( 1 = A s(s-2) + B(s-2) + C s^2 \).
Step 4: Set \( s = 0 \): \( 1 = B(-2) \Rightarrow B = -\tfrac{1}{2} \).
Step 5: Set \( s = 2 \): \( 1 = C(4) \Rightarrow C = \tfrac{1}{4} \).
Step 6: Compare coefficients of \( s^2 \): \( 0 = A + C \Rightarrow A = -\tfrac{1}{4} \).
Step 7: So \( \dfrac{1}{s^3-2s^2} = -\dfrac{1/4}{s} - \dfrac{1/2}{s^2} + \dfrac{1/4}{s-2} \).
Step 8: Invert using \( \mathcal{L}^{-1}\{1/s\} = 1 \), \( \mathcal{L}^{-1}\{1/s^2\} = t \), \( \mathcal{L}^{-1}\{1/(s-2)\} = e^{2t} \):
Step 9: \( \mathcal{L}^{-1} = -\tfrac{1}{4} - \tfrac{1}{2}t + \tfrac{1}{4}e^{2t} \).

✅ \( f(t) = \dfrac{1}{4}e^{2t} - \dfrac{1}{2}t - \dfrac{1}{4} \).

📋 6. Quick Summary
  • Distinct roots: \( \sum \dfrac{A_i}{s-a_i} \to \sum A_i e^{a_i t} \).
  • Repeated roots: include all powers \( \dfrac{A_1}{s-a}+\cdots+\dfrac{A_r}{(s-a)^r} \), invert via \( \dfrac{t^{n-1}e^{at}}{(n-1)!} \).
  • Cover-up rule: set \( s = a_i \) after multiplying through to find \( A_i \) quickly.
  • Improper fraction? Divide first, then split.
