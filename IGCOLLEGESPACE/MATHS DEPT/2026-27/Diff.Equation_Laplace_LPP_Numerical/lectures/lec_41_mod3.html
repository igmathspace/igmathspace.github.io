📌 2. Introduction — Why the Simplex Method?

The graphical method discussed in Lectures 34–36 can be applied only when the number of decision variables is at most two. The simplex method, developed by George B. Dantzig (1947), can be used to solve any LPP (for which the solution exists) involving any number of variables and constraints — hundreds or even thousands.

The computational procedure of the simplex method is based on the fundamental theorem of LPP (Lecture 40): the optimal solution, if it exists, occurs at one of the corner points (basic feasible solutions) of the feasible region. The simplex method starts with the initial BFS (the origin, in the standard form), tests whether improvement is possible by moving to an adjacent corner point, and repeats until no further improvement is possible.

📐 3. Structure of the Simplex Tableau

The initial simplex tableau displays, in compact form, the information contained in the objective function and the standard-form constraint equations. The general layout is shown below:

Basic Variables (B) Cost variables (\(c_B\)) Value of Basic variable (\(x_B\)) Cost \(\to\) \(c_1\) \(c_2\) ... 0 ... 0 Ratio
\(x_1\) \(x_2\) ... \(s_1\) ... \(s_m\)
Row 1 Coef. of \(x_1\) in 1st constraint Coef. of \(x_2\) in 1st constraint ... Coef. of \(s_1\) in 1st constraint ... Coef. of \(s_m\) in 1st constraint
Row 2 Coef. of \(x_1\) in 2nd constraint Coef. of \(x_2\) in 2nd constraint ... Coef. of \(s_1\) in 2nd constraint ... Coef. of \(s_m\) in 2nd constraint
... ... ... ... ... ... ...
Row m Coef. of \(x_1\) in m-th constraint Coef. of \(x_2\) in m-th constraint ... Coef. of \(s_1\) in m-th constraint ... Coef. of \(s_m\) in m-th constraint
Net evaluation \(\to\) \(c_j - Z_j\) \(c_1 - Z_1\) \(c_2 - Z_2\) ... \(0 - Z_{s_1}\) ... \(0 - Z_{s_m}\)
Row-by-row interpretation
  • \(c_j\)-row (top row of the body): the coefficients of each variable in the objective function. These remain fixed across all tableaus.
  • \(c_B\)-column: the coefficients of the current basic variables in the objective function. For the initial tableau, \(c_B\) values are all zero (since slack variables have zero objective coefficient).
  • Basis column: lists the current basic variables — initially the slack variables.
  • Body matrix: the coefficients \(a_{ij}\) of the variables in each constraint. Includes the identity-matrix columns for slack variables.
  • \(b\)-column: the right-hand-side values of the constraints — i.e. the current values of the basic variables.
  • Ratio column (\(\theta\)): used in the leaving-variable test (b column divided by key column, row by row).
  • \(Z_j\)-row: \(Z_j = \sum_i c_{Bi} \cdot a_{ij}\), the contribution lost per unit of the \(j\)-th variable if it is added to the solution.
  • \(c_j - Z_j\) row: the net evaluation row (N.E.R.) — net profit or net marginal improvement per unit of each variable. This is what determines the optimality.
🛠️ 4. Constructing the Initial Tableau
Steps to build the initial tableau
  1. Express the LPP in standard form (all constraints as equations with non-negative RHS).
  2. Add zero-profit (or zero-cost) coefficients in the objective for slack, surplus and artificial variables.
  3. Identify the starting basic variables — typically the slack variables (and artificials, if any).
  4. Fill the tableau: \(c_j\) row at top, \(c_B\) and basis columns on the left, body matrix, \(b\)-column.
  5. Compute the \(Z_j\)-row by \(Z_j = \sum_i c_{Bi} \, a_{ij}\).
  6. Compute the net evaluation row \(c_j - Z_j\).

Optimality condition (maximisation):

If all entries in the \(c_j - Z_j\) row are \(\le 0\), the current BFS is optimal and the computation terminates. If any entry is \(>0\), the solution is not optimal — the variable with the largest positive \(c_j - Z_j\) enters the basis (this is the "entering variable").

Optimality condition (minimisation):

If all entries in the \(c_j - Z_j\) row are \(\ge 0\), the current BFS is optimal. Otherwise, the variable with the most negative \(c_j - Z_j\) enters.

Problem 1. Construct the initial simplex tableau for the LPP: Maximise \(Z = 2x_1 + 5x_2\), subject to \(x_1 + 4x_2 \le 24,\; 3x_1 + x_2 \le 21,\; x_1 + x_2 \le 9,\; x_1, x_2 \ge 0\). Perform the optimality test. CO3
✅ Step-by-step:
Step 1 (Standard form): Introduce slack \(s_1, s_2, s_3 \ge 0\):
Max \(Z = 2x_1 + 5x_2 + 0s_1 + 0s_2 + 0s_3\)
s.t. \(x_1 + 4x_2 + s_1 = 24\)
\(3x_1 + x_2 + s_2 = 21\)
\(x_1 + x_2 + s_3 = 9\)
\(x_1, x_2, s_1, s_2, s_3 \ge 0\).
Step 2 (Identify basic variables): \(s_1, s_2, s_3\) — the identity columns. \(c_B = (0, 0, 0)\).
Step 3 (Initial BFS): \(x_1 = x_2 = 0\); \(s_1 = 24\), \(s_2 = 21\), \(s_3 = 9\); \(Z = 0\).
Step 4 (Initial tableau):
\(c_B\)Basis\(b\) \(x_1\)\(x_2\)\(s_1\)\(s_2\)\(s_3\)
\(c_j \to 2\)\(5\)\(0\)\(0\)\(0\)
0\(s_1\)2414100
0\(s_2\)2131010
0\(s_3\)911001
\(Z_j\)00000
\(c_j - Z_j\)25000
Step 5 (Compute \(Z_j\)): Each \(Z_j = \sum c_{Bi} a_{ij} = 0\) because all \(c_B = 0\).
Step 6 (Compute \(c_j - Z_j\)): \(c_1 - Z_1 = 2\), \(c_2 - Z_2 = 5\), slack columns: \(0\).
Step 7 (Optimality test): Since at least one \(c_j - Z_j > 0\) (in fact, 2 and 5 are positive), the current BFS is not optimal. The variable with the largest positive value (5) is \(x_2\) — so \(x_2\) is the entering variable.

✅ Initial BFS: \(x_1=0, x_2=0, s_1=24, s_2=21, s_3=9\); \(Z=0\). Not optimal; \(x_2\) enters next.

Problem 2. Construct the initial simplex tableau for: Maximise \(Z = 3x_1 + 4x_2\), subject to \(x_1 + x_2 \le 450,\; 2x_1 + x_2 \le 600,\; x_1, x_2 \ge 0\). Identify entering variable from the optimality test. CO3

Max \(Z = 3x_1 + 4x_2 + 0s_1 + 0s_2\)

Step 3 (Initial BFS): \(x_1 = x_2 = 0\), \(s_1 = 450\), \(s_2 = 600\); \(Z = 0\).
Step 4 (Initial tableau):
\(c_B\)Basis\(b\) \(x_1\)\(x_2\)\(s_1\)\(s_2\)

Step 2 (Basic variables): \(s_1, s_2\). \(c_B = (0, 0)\). \(b = (15, 10)\).
Step 3 (Initial BFS): \(x_1 = x_2 = 0\), \(s_1 = 15\), \(s_2 = 10\); \(Z = 0\).
\(c_B\)Basis\(b\) \(x_1\)\(x_2\)\(s_1\)\(s_2\)

0\(s_1\)153510

📋 7. Quick Summary
  • Purpose: solves LPPs with any number of variables (graphical limit is 2).
  • Tableau columns: \(c_B\), Basis, \(b\), body matrix (per variable), Ratio.
  • Tableau rows: constraint rows, \(Z_j\), \(c_j - Z_j\).
  • \(Z_j = \sum c_{Bi} a_{ij}\): contribution lost per unit added of the variable.
  • \(c_j - Z_j\): net profit per unit of variable \(j\).
  • Optimality (max): all \(c_j - Z_j \le 0\) → optimal. Otherwise, largest positive enters.
