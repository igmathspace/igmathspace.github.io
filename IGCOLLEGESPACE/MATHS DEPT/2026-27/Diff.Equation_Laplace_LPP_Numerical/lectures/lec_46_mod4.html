🎯 1. Learning Outcomes (CO4)
  • Distinguish between algebraic and transcendental equations
  • State the theory-of-equations facts that help locate roots of a polynomial
  • Use Descartes' Rule of Signs to bound the number of positive and negative real roots
  • Choose good initial approximations for iterative root-finding methods
📌 2. Algebraic vs Transcendental Equations
Definition

An equation of the form \(f(x) = 0\) is called

  • algebraic, if \(f(x)\) is a polynomial \(f_n(x) = a_0x^n + a_1x^{n-1} + \dots + a_{n-1}x + a_n\);
  • transcendental, if \(f(x)\) is a non-algebraic function, e.g. \(f(x) = \ln x^3 - 0.7\), \(\phi(x) = e^{-0.5x} - 5x\), \(\psi(x) = \sin^2 x - x^2 - 2\).

The roots of \(f(x) = 0\) may be real or complex.

Practical origin.

Rocket studies give the nonlinear equation \[ \frac{M_0}{M_0 - u_f t} = e^{(u + gt)/u_0} \] which must be solved for \(t\) — a transcendental equation.

📐 3. Useful Results from the Theory of Equations
Basic facts
  1. Every polynomial equation of degree \(n\) has exactly \(n\) roots (counting multiplicities).
  2. If \(n\) is odd, the equation has at least one real root whose sign is opposite to that of the last term.
  3. If \(n\) is even and the constant term is negative, the equation has at least one positive and at least one negative root.
  4. If coefficients are (a) real, imaginary roots occur in conjugate pairs; (b) rational, irrational roots occur in pairs.
📊 4. Descartes' Rule of Signs
Statement

Let \(f(x)\) be a polynomial with real coefficients.

  1. \(f(x) = 0\) cannot have more positive real roots than the number of changes of sign in the coefficient sequence of \(f(x)\).
  2. \(f(x) = 0\) cannot have more negative real roots than the number of changes of sign in the coefficient sequence of \(f(-x)\).

Moreover, the number of positive real roots is congruent to the number of sign changes in \(f(x)\) modulo 2.

🔍 5. Finding Initial Approximations

Iterative methods (bisection, false position, Newton–Raphson) require a starting point (or a bracket). The following strategies are standard.

  1. Sign-change (bracketing) test. By the Intermediate Value Theorem, if \(f(a)\) and \(f(b)\) have opposite signs and \(f\) is continuous on \([a, b]\), then a root exists in \((a, b)\).
  2. Geometric insight. Plot \(y = f(x)\) or split it as \(y = g(x)\) and \(y = h(x)\) so that roots correspond to intersection points.
  3. Rough tabulation. Evaluate \(f\) at integer values of \(x\) to locate a change of sign.
  4. Descartes' rule to bound the number of positive and negative roots.
⚠️ CAUTION! A sign change guarantees an odd number of roots in the interval, but the root is not necessarily unique. If the derivative \(f'(x)\) has constant sign on \([a, b]\), uniqueness is guaranteed.

Problem 1. State Descartes' Rule of Signs. Using the rule, show that \(x^3 + 5x + 3 = 0\) has only one real root. CO4
✅ Step-by-step:
Step 1 (Statement): For a polynomial \(f(x)\) with real coefficients: the number of positive real roots is either equal to the number of sign changes in \(f(x)\), or less than it by an even number. The same holds for negative roots using \(f(-x)\).
Step 2: Write \(f(x) = x^3 + 5x + 3\).
Step 3: Coefficient sequence of \(f(x)\): \(+1, +5, +3\). There are no sign changes.
Step 4: By Descartes' rule, \(f(x) = 0\) has no positive real roots.
Step 5: Now compute \(f(-x) = -x^3 - 5x + 3\). Coefficient sequence: \(-1, -5, +3\). One sign change.
Step 6: By Descartes' rule, \(f(x) = 0\) has exactly one negative real root.
Step 7: \(f(x)\) is a cubic with real coefficients, so it has exactly three roots in \(\mathbb{C}\). Since no positive real roots and exactly one negative real root, the remaining two roots are a complex conjugate pair.
Step 8: Conclusion: \(x^3 + 5x + 3 = 0\) has exactly one real root (and it is negative).

✅ Only one real root, which is negative.

Problem 2. Using Descartes' rule of signs, determine the maximum possible number of positive and negative real roots of \(f(x) = x^4 - 4x^3 + 5x^2 - 2x + 1\). CO4
✅ Step-by-step:
Step 1: Write \(f(x) = x^4 - 4x^3 + 5x^2 - 2x + 1\).
Step 2: Coefficient sequence: \(+1, -4, +5, -2, +1\).
Step 3: Count sign changes: \(+\to-\) (1), \(-\to+\) (2), \(+\to-\) (3), \(-\to+\) (4). So 4 sign changes.
Step 4: By Descartes' rule, \(f(x)=0\) has either 4, 2, or 0 positive real roots.
Step 5: Now compute \(f(-x) = x^4 + 4x^3 + 5x^2 + 2x + 1\). Coefficient sequence: \(+1, +4, +5, +2, +1\).
Step 6: No sign changes, so 0 negative real roots.
Step 7: Hence all four roots (counting multiplicity) are positive or in conjugate pairs (real-coefficient quartic). Since no negative real roots, the number of positive real roots is 4, 2, or 0 (even).
Step 8: For example \(f(x) = (x-1)^4 = x^4 - 4x^3 + 6x^2 - 4x + 1\) (different coefficient of \(x^2\)); the given quartic is \((x^2-x+1)^2\), i.e., \(f(x) = (x^2 - x + 1)^2\). So actually there are 0 real roots — they are complex. Descartes' rule allowed 4 or 2 or 0, consistent.

✅ Max positive real roots: 4; max negative: 0. (Actual: 0 real, since \(f = (x^2-x+1)^2\).)

Problem 3. Write Newton–Raphson's formula for finding an approximate root of the equation \(f(x) = 0\). What is the geometric interpretation of the formula? CO4
✅ Step-by-step:
Step 1: Let \(x_n\) be an approximate root of \(f(x)=0\).
Step 2: The next approximation \(x_{n+1}\) is obtained by drawing the tangent at \((x_n, f(x_n))\) and finding its \(x\)-intercept.
Step 3: The tangent equation is \(y - f(x_n) = f'(x_n)(x - x_n)\).
Step 4: Setting \(y = 0\) gives \(x = x_n - \dfrac{f(x_n)}{f'(x_n)}\).
Step 5: The Newton–Raphson iteration formula is therefore \(\boxed{x_{n+1} = x_n - \dfrac{f(x_n)}{f'(x_n)}}\).
Step 6: Geometrically, \(x_{n+1}\) is where the tangent at \((x_n, f(x_n))\) crosses the \(x\)-axis.
Step 7: The method has quadratic convergence, i.e., the number of correct decimal digits roughly doubles at each step — provided \(f'(x_n) \ne 0\) and the starting value \(x_0\) is close enough to the true root.

✅ \(x_{n+1} = x_n - f(x_n)/f'(x_n)\); geometric interpretation = tangent \(x\)-intercept.

Problem 4. Write the bisection-method inequality for the number of iterations required to achieve an accuracy \(\epsilon\) when the initial interval is \([a, b]\). CO4
✅ Step-by-step:
Step 1: In the bisection method the interval length is halved at each step.
Step 2: After \(n\) steps the interval containing the root has length \(\dfrac{|b-a|}{2^n}\).
Step 3: To achieve a desired absolute accuracy \(\epsilon\) we need \(\dfrac{|b-a|}{2^n} \le \epsilon\).
Step 4: Taking logarithms: \(\ln\!\left(\dfrac{|b-a|}{\epsilon}\right) \ge n \ln 2\).
Step 5: So \(\boxed{n \ge \dfrac{\log_e(|b-a|/\epsilon)}{\log_e 2}}\), i.e., \(n \ge \log_2\!\left(\dfrac{|b-a|}{\epsilon}\right)\).
Step 6: Example: if \(|b-a| = 1\) and \(\epsilon = 0.001\), then \(n \ge \dfrac{\ln 1000}{\ln 2} \approx 9.97 \Rightarrow n \ge 10\).

✅ \(n \ge \log_2(|b-a|/\epsilon)\).

📋 8. Quick Summary
  • Algebraic equation: \(f(x)\) is a polynomial.
  • Transcendental equation: \(f(x)\) involves \(\ln x\), \(e^x\), \(\sin x\), etc.
  • Descartes' rule: number of positive roots ≤ sign changes in \(f(x)\); number of negative roots ≤ sign changes in \(f(-x)\).
  • Sign-change test: if \(f(a) f(b) < 0\) and \(f\) is continuous, then a root lies in \((a, b)\).
  • Iteration count (bisection): \(n \ge \log_2(|b-a|/\epsilon)\).
  • Newton–Raphson: \(x_{n+1} = x_n - f(x_n)/f'(x_n)\); geometric meaning = tangent intercept.
