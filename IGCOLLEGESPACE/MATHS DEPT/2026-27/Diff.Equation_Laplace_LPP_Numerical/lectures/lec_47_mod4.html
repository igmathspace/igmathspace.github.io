  • Carry out full bisection iterations on concrete equations using the standard tableau
📌 2. Description of the Bisection Method
Underlying principle (Theorem 1.1 of Sastry)

If \(f(x)\) is continuous on \([a, b]\) and \(f(a)\) and \(f(b)\) have opposite signs, then there exists at least one root \(\xi\) of \(f(x) = 0\) with \(a < \xi < b\).

Step-by-step procedure:

  1. Choose \(a, b\) such that \(f(a) f(b) < 0\).
  2. Set \(x_r = \dfrac{a + b}{2}\).
    • If \(f(a) f(x_r) < 0\): root lies in \((a, x_r)\). Set \(b = x_r\).
    • If \(f(a) f(x_r) > 0\): root lies in \((x_r, b)\). Set \(a = x_r\).
    • If \(f(a) f(x_r) = 0\): \(x_r\) is the root — stop.
  4. Return to Step 2, and continue until the interval is as small as desired, say of width \(\le \epsilon\).
Interval width after \(n\) steps

After \(n\) iterations, the width of the bracketing interval is exactly \(|b - a|/2^n\). Setting this \(\le \epsilon\) and solving for \(n\) gives the iteration-count formula:

\[ \boxed{\; n \ge \frac{\log_e\!\big(|b-a|/\epsilon\big)}{\log_e 2} \; } \]
📐 3. Relative-Error Criterion for Termination

In practice, when the root is not exact, bisection is terminated when the relative error

\[ \epsilon_r = \left|\frac{x_r' - x_r}{x_r'}\right|\times 100\% \]

falls below a prescribed tolerance \(\epsilon_p\) (where \(x_r'\) is the latest and \(x_r\) the previous approximation).

⚠️ CAUTION! Bisection is guaranteed to converge, but only linearly — one binary digit per iteration. It is reliable but slow; Newton–Raphson and the secant method are far faster when a good starting point is available.
🚨 IMPORTANT WARNING: CALCULATOR MODE
For any equation involving trigonometric functions (such as \(\sin x\), \(\cos x\), or problems like \(4e^{-x}\sin x - 1 = 0\) or \(x^2 + x - \cos x = 0\)), you MUST ensure your scientific calculator is set to RADIAN MODE, not Degree Mode. Calculating functions in the wrong mode will result in completely incorrect values for \(f(x)\) and an incorrect interval.

Problem 5. Find the number of iterations required to obtain a root of \(x^3 - x - 1 = 0\) correct to 4 decimal places using bisection on \([1, 2]\). CO4
✅ Step-by-step:
Step 1: Initial bracket \(a = 1\), \(b = 2\), so \(|b - a| = 1\).
Step 2: Required accuracy \(\epsilon = 10^{-4}\) (four decimal places).
Step 3: Iteration-count formula: \(n \ge \dfrac{\log_e(1/\epsilon)}{\log_e 2} = \dfrac{\ln 10^4}{\ln 2}\).
Step 4: \(\ln 10^4 = 4 \ln 10 \approx 4 \times 2.302585 = 9.21034\).
Step 5: \(\ln 2 \approx 0.693147\).
Step 6: \(n \ge 9.21034 / 0.693147 \approx 13.29\).
Step 7: So at least \(n = 14\) iterations are required.

✅ \(n = 14\) iterations.

📋 7. Quick Summary
  • Principle: sign change in \(f(x)\) at endpoints guarantees a root inside.
  • Iteration: \(x_r = (a + b)/2\); replace \(a\) or \(b\) by \(x_r\) according to sign of \(f(a)f(x_r)\).
  • Interval width: \(|b-a|/2^n\).
  • Iteration count: \(n \ge \log_e(|b-a|/\epsilon)/\log_e 2\).
  • Relative error criterion: stop when \(\left|\dfrac{x_r' - x_r}{x_r'}\right| \times 100\% < \epsilon_p\).
  • Trigonometric Warning: Always set the calculator to RADIAN mode for trigonometric equations.
