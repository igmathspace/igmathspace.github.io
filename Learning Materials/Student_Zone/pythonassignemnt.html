01 Questions
  1. Write a Python program to input two numbers from the user and display their sum, difference, product, and quotient.
  2. Write a Python program to input the radius of a circle and compute its area and circumference. (Use the math module and import function.)
  3. Write a Python program to input a list of 5 numbers and print the largest, smallest, and average of the numbers.
  4. Write a Python program to create a tuple of student names and print each name using a for loop.
  5. Write a Python program to input a string and count the number of vowels and consonants in it.
  6. Write a Python program using if-elif-else to input a student's mark and print the grade (A: ≥90, B: 75–89, C: 50–74, Fail: <50).
  7. Write a Python program using a while loop to print the first 10 natural numbers and their squares.
  8. Write a Python program to define a function factorial(n) that returns the factorial of a number, and call it for user input.
  9. Write a Python program to create a dictionary of 3 students (name: mark) and print the name of the student with the highest mark.
  10. Write a Python program using matplotlib to plot the curve y = x² for x values from −5 to 5, with a title and axis labels.
