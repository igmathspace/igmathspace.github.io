12. Explain the difference between integer division (`//`) and float division (`/`) in Python with examples.

22. Differentiate between `random.choice()` and `random.shuffle()` in terms of arguments and return values.

`choice()` takes a sequence and returns a random item. `shuffle()` takes a list, shuffles it in place, and returns `None`.

23. What is the difference between `del` and `remove()` methods of a list?

`del` removes an item by its index (e.g., `del L[0]`). `remove()` removes the first occurrence of a specific value (e.g., `L.remove(20)`).

24. How do you add a single element to a set vs adding multiple elements? Explain with `add()` and `update()`.

98. What does the `popitem()` method do in a dictionary?

99. Provide comparison between Lists, Tuples, Sets, and Dictionaries.

List: Ordered, mutable, allows duplicates (e.g., `[1, 2]`).
Tuple: Ordered, immutable, allows duplicates (e.g., `(1, 2)`).
Set: Unordered, mutable, no duplicates (e.g., `{1, 2}`).
Dictionary: Unordered (pre-3.7), mutable, key-value pairs, unique keys (e.g., `{'a': 1}`).

100. Explain the set operators `|` (union), `&` (intersection), `-` (difference), and `^` (symmetric difference).

`|` combines both sets. `&` gives common elements. `-` gives elements in the first but not the second. `^` gives elements in either but not both.
