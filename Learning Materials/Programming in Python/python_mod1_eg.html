Module I : Introduction to Python - Workout questions and programmes
1. Explain the role of `=` operator in python variable assignment. Consider the code:

x = 2
3 = y
print(x = ,x,y = ,y)

The `=` operator is used to assign values to a variable (Variable on the left, value on the right). The statement `3 = y` is a SyntaxError because a literal (3) cannot be the target of an assignment.

2. What is operator precedence in Python? How can you change the order of evaluation in an expression?

Operator precedence determines the order in which operations are performed (e.g., multiplication before addition). You can change this order by using parentheses `()`.

3. Give an example for single value assignment to several variables in python.
x = y = z = 10
4. What is the difference between the `=` (assignment) and `==` (equality) operators in Python?

`=` assigns a value to a variable. `==` compares two values and returns `True` or `False`.

5. What is indentation in Python and why it is important?

Indentation is the spaces or tabs at the beginning of a line. It is important because Python uses it to define blocks of code (unlike other languages that use curly braces `{}`).

6. What is the difference between an interpreter and a compiler? Which one does Python use?

A compiler translates the whole program into machine code at once. An interpreter translates and executes code line by line. Python uses an interpreter.

7. What you meant by variable. does a variable need a declaration?

A variable is a named memory location used to store data. In Python, variables do not need explicit declaration; they are created when you first assign a value to them.

8. Explain the logical operators (`and`, `or`, `not`) in Python with examples.

and: True if both operands are true.
or: True if at least one operand is true.
not: Reverses the boolean value.

print(True and False) # False
print(True or False)  # True
print(not True)       # False
9. (a) Define indentation in Python and explain its significance. Why is consistent indentation mandatory?
(b) Give an example code with i. Correct indentation ii. Incorrect indentation.

(a) Indentation defines code blocks. Consistent indentation is mandatory to avoid syntax errors and logical bugs.

(b) Correct:

    print("Hello")

10. Who created Python?

Guido van Rossum.

11. Write a short note on Python's standard library and how it is organized.

It is a collection of modules built into Python (like `math`, `random`, `os`) that provide ready-to-use functionality. It is organized into packages and modules.

12. Why does the following code generate an error:

If True:
print("answer")
print("correct")
Else:
print("answer")
Print("correct")

Python is case-sensitive. The keywords `If`, `Else`, and `Print` must be written in lowercase as `if`, `else`, and `print`.

13. Explain the `sep` and `end` parameters of the `print()` function with suitable examples.

sep defines the separator between multiple arguments (default is a space). end defines what is printed at the end (default is a newline).

print("A", "B", sep="-") # A-B
print("Hello", end="!")   # Hello!
14. Compare single value simultaneous assignment and multiple object simultaneous assignment in python.

Single value: `a = b = c = 10` (all variables point to the same object).
Multiple object: `a, b, c = 10, 20, 30` (each variable gets a different value).

15. What happens if you mix tabs and spaces for indentation in Python?

Python 3 raises a `TabError` because mixing tabs and spaces creates ambiguous indentation levels.

16. How do we assign a value to a variable? Explain with an example.

Using the assignment operator `=`.

age = 20
name = "Alice"
17. What are membership operators? Explain `in` and `not in` with examples.

They check if a value exists in a sequence (like a string or list).

print(3 in [1, 2, 3])    # True
print(5 not in [1, 2, 3]) # True
18. (a) Explain the `print()` function in Python with its syntax and all parameters.
(b) Explain the `input()` function with examples to read an integer and decimal number.
(c) Explain the `import` function with an example.

(a) `print()` outputs text. Parameters: `value`, `sep`, `end`, `file`, `flush`.

(b) `input()` takes user input as a string. To read an integer: `int(input())`. For a decimal: `float(input())`.

(c) `import` brings external modules into the script. Example: `import math`.

1. Easy to learn and read.
2. Interpreted language.
3. Dynamically typed.
4. Extensive standard library and open-source.

20. What is type casting? Write a Python code snippet to convert an integer to a string and a float to an integer.

Type casting is converting one data type to another.

a = str(10)    # int to string
b = int(3.14)  # float to int
21. How can you delete a variable in Python? Give an example using the `del` statement.
x = 10
del x
22. Give an example to assign multiple values to multiple variables in a single line.
x, y, z = 10, 20, 30
23. What is the difference between the `/` (division) and `//` (floor division) operators in Python?

`/` returns the exact float result. `//` returns the quotient rounded down to the nearest integer.

print(5 / 2)  # 2.5
print(5 // 2) # 2
24. Describe the process of variable assignment in Python. How does python handle different data types without explicit declaration? Explain with example.

Python is dynamically typed. When you assign a value (e.g., `x = 10`), Python automatically creates the variable and binds it to the data type of the value (integer in this case). No explicit declaration is needed.

25. What are identity operators? Explain `is` and `is not` with examples.

They compare the memory locations of two objects.

a = [1, 2]
b = a
print(a is b) # True

29. Explain dynamic typing in Python with an example.

Dynamic typing means the data type of a variable is determined at runtime, not in advance.

x = 10    # x is int
