2. Explain the concept of meshgrids in detail. Describe the meshgrid() function...

A meshgrid is a grid of coordinates. The meshgrid() function takes two 1D arrays and returns two 2D matrices. It is important for plotting 3D surfaces because it allows us to calculate a Z value for every (X, Y) pair on the grid.

4. Write a Python program to generate a Julia set fractal and visualize it using the imshow() function.
import matplotlib.pyplot as plt
import numpy as np

def julia(c, x, y):
    z = x + 1j*y
    for i in range(100):
        if abs(z) > 2:
            return i
        z = z**2 + c
    return 100

c = complex(-0.8, 0.156)
x = np.linspace(-1.5, 1.5, 200)
y = np.linspace(-1.5, 1.5, 200)
X, Y = np.meshgrid(x, y)
Z = np.zeros_like(X)
for i in range(X.shape[0]):
    for j in range(X.shape[1]):
        Z[i,j] = julia(c, X[i,j], Y[i,j])
        
plt.imshow(Z, cmap='hot')
plt.show()

9. Explain even and odd functions. Determine whether sin x and sin^2 x are even or odd.

Even: f(x) = f(-x) (symmetric to Y-axis). Odd: f(-x) = -f(x) (symmetric to origin).
sin(x) is odd.

26. Write a Python program to evaluate and plot the Maclaurin series expansion of the sine function.
import matplotlib.pyplot as plt
import numpy as np
import math

x = np.linspace(-np.pi, np.pi, 100)
y_series = np.zeros_like(x)
for n in range(5):
    y_series += ((-1)**n * x**(2*n+1)) / math.factorial(2*n+1)

plt.plot(x, np.sin(x), label='sin(x)')
plt.plot(x, y_series, label='series')
plt.legend()
plt.show()
