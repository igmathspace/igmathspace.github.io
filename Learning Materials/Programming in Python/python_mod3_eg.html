4. Draw the flow chart of the `if` statement?

(Textual Description) Start -> Check Condition (Diamond shape) -> If True, Execute Block -> End. If False, go directly to End.

5. Draw the flow chart of the `if...else` statement?

(Textual Description) Start -> Check Condition -> If True, Execute IF Block -> End. If False, Execute ELSE Block -> End.

6. Draw the flow chart of the `for` loop?

(Textual Description) Start -> Initialize loop -> Check if items remain -> If Yes, execute block -> move to next item -> Check again. If No, End.

7. Draw the flow chart of the `while` loop?

(Textual Description) Start -> Check Condition -> If True, execute block -> Loop back to Condition. If False, End.

9. What is decision making in Python?

Decision making is running specific blocks of code only when certain conditions are met (using if, elif, else).

10. Differentiate between `if` and `if...else` statements.

`if` runs code only when the condition is True. `if...else` runs one block if True and a different block if False.

11. What is the use of the `elif` statement?

It allows checking multiple conditions sequentially. If the previous `if` is false, it checks the `elif` condition.

12. What is a nested `if` statement?

An `if` statement placed inside another `if` statement.

13. Define a loop in Python.

A loop is a programming structure that repeats a block of code multiple times.

14. What is meant by traversal of a sequence?

It means visiting each item in a sequence (like a list or string) one by one, usually using a `for` loop.

15. What is the use of the `range()` function? What is the default step size in `range()`?

`range()` generates a sequence of numbers. The default step size is 1.

16. What is the purpose of the `enumerate()` function?

It adds a counter to an iterable and returns it as an enumerate object (giving both index and value).

17. When is the `else` part of a `for` loop executed?

It is executed after the loop finishes normally (i.e., when the loop is not stopped by a `break` statement).

18. When is a `while` loop preferred over a `for` loop?

When the number of iterations is unknown and depends on a condition becoming False.

19. What happens when the condition of a `while` loop becomes False?

The loop stops repeating and the program continues to the next line of code after the loop.

20. When is the `else` block of a `while` loop executed?

It is executed when the while loop ends normally (when the condition becomes False), not when it is broken by `break`.

22. Describe about `range()` and `len()` functions with example?

`range()` generates a sequence of numbers (e.g., `range(5)` gives 0,1,2,3,4).
`len()` gives the number of items in an object (e.g., `len([10,20,30])` gives 3).

While loop: Runs until a condition is false. Syntax: `while condition:`

24. Explain the working of a `for` loop with its syntax and flow of execution. Give a suitable example.

31. What is the purpose of `break` statement in Python?

It immediately stops the loop and exits out of it, skipping any remaining iterations.

32. What is the purpose of `continue` statement in Python?

It skips the rest of the code inside the loop for the current iteration and jumps to the next iteration.

33. What is the purpose of `pass` statement in Python?

It does nothing. It is used as a placeholder when a statement is syntactically required but no action is needed.

54. Explain the concept of short-circuit evaluation in Python logical operators within an `if` statement.

In `A and B`, if A is false, B is not checked. In `A or B`, if A is true, B is not checked. This saves time and prevents errors.
